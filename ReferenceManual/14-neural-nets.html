14. Neural Nets

You keep the weights and the bias yourself. nn.dense is one matrix multiply, plus that bias, then an activation. nn.denseBackward returns the three gradients of that one layer and stops. It does not record an autograd tape, and it does not change your arrays. You subtract learningRate times each gradient, or you hand a fixed stack of layers to 14.9, which applies that same step for you.

A deeper net is the same pair of calls stacked. Run the output layer backward first. Its dInput is the upstream gradient of the layer below it. Both layers need the pre they returned on the way forward, because the activation derivative is evaluated there.

This chapter recomputes one forward, one backward, a two-row batch, the hand-off between two layers, both losses, and one Sequential.fit step. The signature tables are 14.8 and 14.9. 14.6 is the order of the offline programs in Examples/AI_Theory/, which write the same products with named variables before a helper hides them.

14.1 What stays on math

Linear algebra stays on math. A weight matrix is [in, out]: one row per input unit, one column per output unit, the same layout as math.matmul(x, weights). The inner dimensions must match, so a vector of length 2 multiplies a matrix with 2 rows. The product below is the linear part of the layer in 14.2.1, before the bias [0.25, -0.5] is added. Activations and the layer live on nn. Write nn.relu, not relu: there is no flat alias.

CallRole
math.dot / matmul / transposeVectors and matrices. Only on math
math.sigmoid / tanh / softmaxAlso available as nn.sigmoid / tanh / softmax
nn.relu / mse / crossEntropyFromLogitsOnly on nn. There is no math.relu
 
print(math.dot([1.0, 2.0], [3.0, 1.0]));
print(int(math.matmul([1.0, 2.0], [[0.5, -1.0], [1.0, 0.0]])[0] * 10));
print(int(math.matmul([1.0, 2.0], [[0.5, -1.0], [1.0, 0.0]])[1] * 10));

14.2 One dense layer

nn.dense(x, weights, bias?, activation?) accepts one sample as a vector, or several samples as a matrix with one row per sample. The bias has one number per output. Omit it and the bias is zeros. The call returns { pre, out }.

pre is the pre-activation, the linear part before the nonlinearity: pre = xW + b (or XW + b for a batch). out is activation(pre). With no activation, or with "linear", out is a copy of pre and the local derivative is 1. Save pre. The backward step evaluates the activation derivative there, not on out.

14.2.1 Reading the matrix

Take x = [1, 2], weights [[0.5, -1], [1, 0]], and bias [0.25, -0.5]. Column 0 of the matrix is the weights into the first output: 0.5 from the first input and 1 from the second. Column 1 is the weights into the second output: -1 and 0.

The first pre-activation is 1×0.5 + 2×1 + 0.25 = 2.75. The second is 1×(-1) + 2×0 + (-0.5) = -1.5. ReLU leaves 2.75 and replaces -1.5 with 0, so out is [2.75, 0].

var layer = nn.dense([1.0, 2.0], [[0.5, -1.0], [1.0, 0.0]], [0.25, -0.5], "relu");
print(int(layer.pre[0] * 100));
print(int(layer.pre[1] * 100));
print(int(layer.out[0] * 100));
print(int(layer.out[1]));

14.2.2 A batch

Pass a matrix and each row is one sample. The same weights and the same bias apply to every row. pre and out keep that row layout, so pre[0] is the first sample. Two copies of [1, 2] each produce the pre-activation [2.75, -1.5] from 14.2.1.

The matching backward sums over the rows. Each row has dZ = [1, 0], so the bias gradient is [2, 0] and the weight gradient is [[2, 0], [4, 0]], twice the single-sample gradient. dInput stays one row per sample: the first row is still [0.5, 1]. Divide by the row count yourself when you want a mean. A learning rate tuned on one sample is large for many rows unless you scale it.

var x = [[1.0, 2.0], [1.0, 2.0]];
var w = [[0.5, -1.0], [1.0, 0.0]];
var layer = nn.dense(x, w, [0.25, -0.5], "relu");
var back = nn.denseBackward(x, w, [[1.0, 1.0], [1.0, 1.0]], "relu", layer.pre);
print(int(layer.pre[0][0] * 100));
print(int(layer.pre[0][1] * 100));
print(int(back.dBias[0]));
print(int(back.dBias[1]));
print(int(back.dWeights[0][0]));
print(int(back.dWeights[1][0]));
print(int(back.dWeights[0][1]));
print(int(back.dInput[0][0] * 10));
print(int(back.dInput[0][1]));

14.3 Activations

nn.dense accepts these names. The matching nn.d* call is the derivative with respect to the pre-activation z. At z = 0, ReLU's derivative is 0 (the test is z > 0).

NameValueDerivative at z
linearz1. You may omit pre on the backward call
reluz when z > 0, else 01 or 0
leakyReluz when z > 0, else alpha × z1 or alpha. Inside dense, alpha is 0.01
eluz when z > 0, else alpha × (exp(z) − 1)1 or alpha × exp(z). Inside dense, alpha is 1
sigmoid1 / (1 + exp(−z))s × (1 − s) with s = sigmoid(z). A pre-activation past about ±20 saturates, and the derivative is 0
tanhtanh(z)1 − tanh(z)²
siluz × sigmoid(z)nn.dSilu
softpluslog(1 + exp(z)), which approaches z for a large positive zsigmoid(z)
geluthe tanh approximation of GELUnn.dGelu

The standalone calls nn.leakyRelu(x, alpha?) and nn.elu(x, alpha?) take an optional alpha. nn.dense does not: it always uses the defaults above. sigmoid, tanh, and softmax are also on math and call the same functions.

Save pre because several of these derivatives are a test on z, and out has already folded that test. ReLU's derivative at 0 is 0. At 3 it is 1. Sigmoid at 0 is 0.5, and its derivative there is 0.25. A pre-activation past about ±20 makes that derivative 0, which is why a deep stack of sigmoids needs a small initial scale (14.6.3).

print(int(nn.dRelu(0.0)));
print(int(nn.dRelu(3.0)));
print(int(nn.sigmoid(0.0) * 100));
print(int(nn.dSigmoid(0.0) * 100));

14.4 One backward step

nn.denseBackward(x, weights, upstream, activation?, pre?) returns { dInput, dWeights, dBias }. upstream is the gradient of the loss with respect to out, one number per output, in the same shape as out. The layer multiplies that vector by the activation derivative at pre and calls the result dZ. Then:

  • dBias is dZ. On a batch it is the sum of the rows.
  • dWeights[i][j] is input i times dZ[j]. That is the outer product of the input and dZ.
  • dInput[i] is the sum over outputs of dZ[j] × weights[i][j]. That vector is what the previous layer receives as its upstream.

On the same layer as 14.2.1, ReLU's derivative is 1 at 2.75 and 0 at -1.5. An upstream of [1, 1] therefore becomes dZ = [1, 0]. The bias gradient is [1, 0]. The weight gradient is [[1, 0], [2, 0]] because the inputs are 1 and 2. The input gradient is [0.5, 1]: the dead unit drops the second column of W before that multiply. The snippet prints dInput[0] × 10, the two bias entries, then dWeights[0][0], dWeights[1][0], and dWeights[0][1].

var x = [1.0, 2.0];
var w = [[0.5, -1.0], [1.0, 0.0]];
var layer = nn.dense(x, w, [0.25, -0.5], "relu");
var back = nn.denseBackward(x, w, [1.0, 1.0], "relu", layer.pre);
print(int(back.dInput[0] * 10));
print(int(back.dBias[0]));
print(int(back.dBias[1]));
print(int(back.dWeights[0][0]));
print(int(back.dWeights[1][0]));
print(int(back.dWeights[0][1]));

14.4.1 A second layer

Run the output layer backward first. Its dInput is the hidden layer's upstream, and the hidden layer's forward out is the x that the output layer saw. Both layers need the pre they returned.

var hidden = nn.dense(x, w1, b1, "sigmoid");
var out = nn.dense(hidden.out, w2, b2, "sigmoid");
var upstream = nn.mseGrad(out.out, [target]);
var backOut = nn.denseBackward(hidden.out, w2, upstream, "sigmoid", out.pre);
var backHidden = nn.denseBackward(x, w1, backOut.dInput, "sigmoid", hidden.pre);

Examples/AI_Theory/xor_neural_net.malda writes those multiplies with named variables. Examples/AI_Theory/nn_dense.malda trains the same 2-4-1 XOR net with the two calls above.

14.4.2 The weight step

There is no optimizer builtin. After the backward calls, subtract learningRate times dWeights from the weight matrix and learningRate times dBias from the bias, entry by entry. A batch bias gradient is a sum, so a learning rate tuned on one sample is large for many rows unless you scale it.

Take one input 2, weight 1, bias 0, and target 6, with a linear activation. The forward output is 2. nn.mseGrad is 2 − 6 = −4. The weight gradient is 2 × −4 = −8 and the bias gradient is −4. A learning rate of 0.25 moves the weight to 1 − 0.25 × (−8) = 3 and the bias to 1. The next forward is 3 × 2 + 1 = 7, closer to 6. The snippet prints the first output, the weight gradient, the updated weight, the updated bias, and the output after the step.

var w = [[1.0]];
var b = [0.0];
var layer = nn.dense([2.0], w, b, "linear");
var back = nn.denseBackward([2.0], w, nn.mseGrad(layer.out, [6.0]), "linear", layer.pre);
var lr = 0.25;
print(int(layer.out[0]));
print(int(back.dWeights[0][0]));
w[0][0] = w[0][0] - lr * back.dWeights[0][0];
b[0] = b[0] - lr * back.dBias[0];
print(int(w[0][0]));
print(int(b[0]));
var again = nn.dense([2.0], w, b, "linear");
print(int(again.out[0]));

14.5 Losses

On two numbers, nn.mse(pred, target) is the squared difference. On two vectors of the same length it is the mean of those squares. nn.mse(2, 0) is 4. nn.mse([2, 0], [0, 0]) is 2, the mean of 4 and 0.

nn.mseGrad(pred, target) is elementwise pred − target. That is the derivative of 1/2 (pred − target)², which is what nn_dense.malda accumulates as the epoch loss. The derivative of the value nn.mse itself returns is twice as large on one number, and it is also divided by the length on a vector. Pass mseGrad into denseBackward as upstream when the last layer is a regression output.

print(int(nn.mse(2.0, 0.0)));
print(int(nn.mseGrad(2.0, 0.0)));
print(int(nn.mse([2.0, 0.0], [0.0, 0.0])));

14.5.1 Classification

nn.crossEntropyFromLogits(logits, targetIndex) is logSumExp(logits) − logits[targetIndex], the same number as −log(softmax(logits)[targetIndex]). nn.softmaxGrad(logits, target) is softmax(logits) minus a one-hot vector at that class index, or minus a numeric vector of the same length. That gradient is the upstream for a classification layer whose forward activation was "linear": softmax is inside the loss, not a second nonlinearity on pre.

Two equal logits [0, 0] and target class 0 give a softmax of [0.5, 0.5]. The loss is −log(0.5), and int(loss × 1000) prints 693. The gradient is [−0.5, 0.5]. Logits [2, 0] already prefer class 0, so the same scaling prints a loss of 126 and gradient entries −11 and 11 (the truncation of about ±0.119). Leave the last layer "linear" and pass softmaxGrad in as upstream.

var flat = nn.crossEntropyFromLogits([0.0, 0.0], 0);
var flatGrad = nn.softmaxGrad([0.0, 0.0], 0);
print(int(flat * 1000));
print(int(flatGrad[0] * 10));
print(int(flatGrad[1] * 10));
var peaked = nn.crossEntropyFromLogits([2.0, 0.0], 0);
var peakedGrad = nn.softmaxGrad([2.0, 0.0], 0);
print(int(peaked * 1000));
print(int(peakedGrad[0] * 100));
print(int(peakedGrad[1] * 100));

14.6 Examples

Read the files in the order below. Each one seeds the RNG where it draws weights, runs offline, and needs no API key. The calls in this chapter are enough to read them. What changes from file to file is the idea: a hidden layer, a held-out glyph, a velocity you store yourself, one shared kernel, one attention head.

The same folder also holds svm_linear.malda and sarsa_cliff.malda. Those are a margin classifier and a tabular cliff, not a dense stack.

14.6.1 One neuron, then a hidden layer

chain_rule.malda is one multiply, and the reason backprop multiplies local derivatives. perceptron.malda is one neuron: AND and OR are separable, XOR is not. xor_neural_net.malda adds the hidden layer as a 2-4-1 net and names every product, so dZ, dWeights, and dInput are still variables. nn_dense.malda trains that same net with nn.dense and nn.denseBackward, including the in-place learning-rate step from 14.4.2. sequential_xor.malda is the same XOR net through Sequential.fit.

14.6.2 A classifier

softmax_classifier.malda separates three classes in 2D. The loss is nn.crossEntropyFromLogits and the upstream is nn.softmaxGrad, as in 14.5.1. mnist_digits.malda uses ten 5×5 glyphs in the MNIST shape. The hidden nn.dense is "relu". The ten logits are "linear". glyph_holdout.malda trains those ten glyphs, then scores a copy with two flipped pixels. Train is perfect. Holdout is not, because those flips swap the 8 with the 9. There is no MNIST download.

14.6.3 Check the gradient and the scale

gradcheck_dense.malda nudges each weight of one ReLU sample by a central difference and matches nn.denseBackward. init_scale.malda is one forward through a deep stack. A wide uniform draw saturates the sigmoids, so the local derivative from 14.3 collapses. Dividing by sqrt(in) (Xavier) keeps that stack responsive. The He draw keeps a ReLU stack smaller than the same uniform draw. new Dense uses 1/sqrt(inFeatures) by default.

14.6.4 The step you still write

Momentum, a length cap, and Adam are programs. They are not builtins. Each one starts from the subtraction in 14.4.2. momentum_valley.malda keeps a velocity on a quadratic that is steep in one axis. grad_clip.malda uses a steeper quadratic: unclipped, the magnitude grows; a cap on the gradient length walks toward zero. adam_valley.malda keeps m, v, and the step counter. The bias-corrected step finishes near the origin, while plain SGD stays far.

14.6.5 Shapes that are not one dense call

These three files still use the local derivative and the learning-rate step. The layout is the lesson. rnn_delay.malda shows a sigmoid recurrence shrinking its gradient, then a small tanh net that recalls the bit from three steps earlier. conv_stroke.malda reuses one 3×3 kernel at every window of a 5×5 dash, and the backward pass adds into those nine weights. residual_dropout.malda puts a skip next to a deep sigmoid stack, then a train-time mask that eval does not apply.

14.6.6 From one row to one decoder block

embed_row.malda writes the gradient into the selected embedding row and leaves the other rows put. next_char.malda is a bigram on a repeated word: the loss is nn.crossEntropyFromLogits, and the dense gradient scatters back into that one row. next_char_mlp.malda is the case a bigram cannot name. Both samples end on a, one successor is b, the other is c, and a ReLU hidden layer on the two embedding rows names both. layer_norm.malda subtracts the mean and divides by the standard deviation so a deep product stays near 1, then checks the scale with a central difference.

attention_step.malda is one head. Scores are QK^T / sqrt(d). Training puts the mass on a marked token, then a causal mask stops position 0 from reading position 2. positional_encoding.malda adds fixed sinusoids: position 0 is sin(0) and cos(0), and position 1 matches sin(1) and cos(1). sentence_decoder.malda is one causal block: token plus sinusoid, residual attention, one linear readout. It overfits abca to bcab, and the dense gradient is clipped before the step.

attention_is_all_you_need.malda is the step after that block. It stays on math.matmul and adds multi-head attention, the same sinusoids, and the encoder-decoder. microgpt.malda is a tiny character model on that track. embedding_2d.malda projects a hash embedding and lists VectorDB neighbors. onnx_inspect.malda loads new OnnxModel(path) on a small identity model: inspect and one forward, on the host, with no training step. malda play Examples/Games/xor_decision_boundary.malda draws the XOR field. malda play Examples/Games/softmax_decision_boundary.malda draws the three softmax regions. malda play Examples/Games/cartpole_neural.malda trains a policy on the canvas.

14.7 Backends

Interpreter, C# transpile, and JavaScript all run math.dot / matmul / transpose, nn.*, and new Dense / new Sequential. OnnxModel is host-only. There is no tensor type, no autograd tape, and no Adam or data loader in core. There is no flat alias for nn names: write nn.relu, not relu.

14.9 Sequential

new Dense(inFeatures, outFeatures, activation?, scale?) owns one weight matrix [in, out] and one bias. The default scale is 1/sqrt(inFeatures), drawn with the same generator as math.seed. Pass 0 when you want zeros and will write the entries yourself. forward(x) returns the output vector and remembers pre and the input. backward(upstream) calls nn.denseBackward and keeps dWeights and dBias. sgd(lr) subtracts those gradients in place. The input is one vector, not a batch. Call forward before backward, and backward before sgd.

new Sequential([dense, ...]) stacks those layers. forward, backward, and sgd walk the stack. backward starts at the last layer, so you pass only the loss gradient. fit(inputs, targets, epochs, lr, loss?) is online SGD: each sample is a forward, a backward, and an sgd before the next sample is seen. It returns the mean loss of the last epoch, measured before that epoch's steps. loss is "mse" (the default; a target is a number or a vector) or "crossEntropy" (a class index; leave the last layer "linear"). This is still the dense backward pass. It is not a tape, and it is not Adam.

The snippet builds a 1-to-1 linear layer of zeros and fits one sample, input [1] and target 2, for one epoch at learning rate 0.5. The reported loss is 4, the squared error of the zero prediction. The step then sets both the weight and the bias to 1, so the next forward of [1] is 2. The prints are that loss, the weight and the bias times 100, and the forward times 100. The first three lines are a separate layer: weight 2 and bias 1 on input 3 print 7.

nn.sequential([[in, out, activation?, scale?], ...]) builds the same Sequential. Examples/AI_Theory/sequential_xor.malda trains the 2-4-1 XOR net this way. nn_dense.malda still writes each step by hand.
