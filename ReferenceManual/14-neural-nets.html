14. Neural Nets

A dense layer is one matrix multiply, a bias, and an activation. MALDA does not build an autograd tape: you keep the pre-activation from the forward pass and multiply by the local derivative yourself, or you call nn.denseBackward, which does that one step. Signatures live in 13.3.3. The student programs are Examples/AI_Theory/.

14.1 What stays on math

Linear algebra stays on math. A weight matrix is [in, out]: one row per input, one column per output, the same layout as math.matmul(x, weights). Inner dimensions must match.

CallRole
math.dot / matmul / transposeVectors and matrices. Only on math
math.sigmoid / tanh / softmaxAlso available as nn.sigmoid / tanh / softmax
nn.relu / mse / crossEntropyFromLogitsOnly on nn. There is no math.relu
 
print(math.dot([1.0, 2.0], [3.0, 1.0]));

14.2 One dense layer

nn.dense(x, weights, bias?, activation?) accepts a vector or a batch matrix. Bias length equals the number of outputs. It returns { pre, out }.

pre is the pre-activation, the linear part before the nonlinearity: pre = xW + b (or XW + b for a batch). out is activation(pre). With no activation, or with "linear", out is a copy of pre. Save pre. The backward step needs it.

var layer = nn.dense([1.0, 2.0], [[0.5, -1.0], [1.0, 0.0]], [0.25, -0.5], "relu");
print(int(layer.pre[0] * 100));
print(int(layer.pre[1] * 100));
print(int(layer.out[0] * 100));
print(int(layer.out[1]));

Here pre is [2.75, -1.5]. ReLU leaves 2.75 and replaces -1.5 with 0, so out is [2.75, 0].

14.3 Activations

relu, leakyRelu, elu, gelu, silu, softplus, sigmoid, tanh, and linear are the names nn.dense accepts. Inside dense, leakyRelu uses alpha 0.01 and elu uses alpha 1. The standalone calls nn.leakyRelu(x, alpha?) and nn.elu(x, alpha?) take an optional alpha.

Each nn.d* helper is the derivative with respect to the pre-activation, not with respect to the squashed output. dSigmoid(z) = s * (1 - s) with s = sigmoid(z).

14.4 One backward step

nn.denseBackward(x, weights, upstream, activation?, pre?) returns { dInput, dWeights, dBias }. upstream is dL/d(out). Pass the forward pre whenever the activation is not linear: the local derivative is evaluated at pre. For a batch, bias gradients are summed over the batch.

var x = [1.0, 2.0];
var w = [[0.5, -1.0], [1.0, 0.0]];
var layer = nn.dense(x, w, [0.25, -0.5], "relu");
var back = nn.denseBackward(x, w, [1.0, 1.0], "relu", layer.pre);
print(int(back.dInput[0] * 10));
print(int(back.dBias[0]));
print(int(back.dBias[1]));

ReLU's derivative is 0 on the negative unit, so that column of the upstream gradient is dropped before the multiply by W. Examples/AI_Theory/xor_neural_net.malda writes the same chain rule with named variables. Examples/AI_Theory/nn_dense.malda trains the same XOR net through nn.dense and nn.denseBackward.

14.5 Losses

nn.mse(pred, target) is the mean of squared errors. nn.mseGrad(pred, target) is elementwise pred - target, the gradient of 1/2 (pred - target)^2. It is not the gradient of the averaged nn.mse.

nn.crossEntropyFromLogits(logits, targetIndex) is the classification loss for one class index. nn.softmaxGrad(logits, target) is softmax(logits) minus that class (or minus a same-length numeric vector).

14.6 Examples

Read them in this order. Each file seeds the RNG and runs offline.

  1. Examples/AI_Theory/chain_rule.malda — why backprop multiplies local derivatives
  2. Examples/AI_Theory/perceptron.malda — one neuron; AND/OR versus XOR
  3. Examples/AI_Theory/xor_neural_net.malda — a 2-4-1 net with the chain rule written out
  4. Examples/AI_Theory/nn_dense.malda — the same net through nn.dense
  5. Examples/AI_Theory/softmax_classifier.malda — three classes in 2D

attention_is_all_you_need.malda and microgpt.malda stay on the same track. new OnnxModel(path) inspects and runs a small model on the host. It does not train.

14.7 Backends

Interpreter, C# transpile, and JavaScript all run math.dot / matmul / transpose and nn.*. OnnxModel is host-only. There is no flat alias for nn names: write nn.relu, not relu.
