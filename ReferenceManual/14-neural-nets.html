14. Neural Nets

You keep the weights and the bias yourself. A dense layer is one matrix multiply, plus that bias, then an activation. A deeper net is the same pair of calls stacked: the dInput of one layer is the upstream gradient of the layer below it. MALDA does not record an autograd tape and does not apply the step. nn.denseBackward returns the three gradients for that one layer; you subtract learningRate times each gradient from your own arrays.

The signature table is 14.8. The student programs are Examples/AI_Theory/. This chapter walks one forward, one backward, and the hand-off between two layers, on numbers you can check.

14.1 What stays on math

Linear algebra stays on math. A weight matrix is [in, out]: one row per input unit, one column per output unit, the same layout as math.matmul(x, weights). The inner dimensions must match, so a vector of length 2 multiplies a matrix with 2 rows. Activations and the layer live on nn. Write nn.relu, not relu: there is no flat alias.

CallRole
math.dot / matmul / transposeVectors and matrices. Only on math
math.sigmoid / tanh / softmaxAlso available as nn.sigmoid / tanh / softmax
nn.relu / mse / crossEntropyFromLogitsOnly on nn. There is no math.relu
 
print(math.dot([1.0, 2.0], [3.0, 1.0]));

14.2 One dense layer

nn.dense(x, weights, bias?, activation?) accepts one sample as a vector, or several samples as a matrix with one row per sample. The bias has one number per output. Omit it and the bias is zeros. The call returns { pre, out }.

pre is the pre-activation, the linear part before the nonlinearity: pre = xW + b (or XW + b for a batch). out is activation(pre). With no activation, or with "linear", out is a copy of pre and the local derivative is 1. Save pre. The backward step evaluates the activation derivative there, not on out.

14.2.1 Reading the matrix

Take x = [1, 2], weights [[0.5, -1], [1, 0]], and bias [0.25, -0.5]. Column 0 of the matrix is the weights into the first output: 0.5 from the first input and 1 from the second. Column 1 is the weights into the second output: -1 and 0.

The first pre-activation is 1×0.5 + 2×1 + 0.25 = 2.75. The second is 1×(-1) + 2×0 + (-0.5) = -1.5. ReLU leaves 2.75 and replaces -1.5 with 0, so out is [2.75, 0].

var layer = nn.dense([1.0, 2.0], [[0.5, -1.0], [1.0, 0.0]], [0.25, -0.5], "relu");
print(int(layer.pre[0] * 100));
print(int(layer.pre[1] * 100));
print(int(layer.out[0] * 100));
print(int(layer.out[1]));

14.2.2 A batch

Pass a matrix and each row is one sample. The same bias is added to every row. pre and out keep that row layout. A later backward sums the bias gradient over the rows, so two identical samples contribute twice. Divide by the row count yourself when you want a mean.

14.3 Activations

nn.dense accepts these names. The matching nn.d* call is the derivative with respect to the pre-activation z. At z = 0, ReLU's derivative is 0 (the test is z > 0).

NameValueDerivative at z
linearz1. You may omit pre on the backward call
reluz when z > 0, else 01 or 0
leakyReluz when z > 0, else alpha × z1 or alpha. Inside dense, alpha is 0.01
eluz when z > 0, else alpha × (exp(z) − 1)1 or alpha × exp(z). Inside dense, alpha is 1
sigmoid1 / (1 + exp(−z))s × (1 − s) with s = sigmoid(z). A pre-activation past about ±20 saturates, and the derivative is 0
tanhtanh(z)1 − tanh(z)²
siluz × sigmoid(z)nn.dSilu
softpluslog(1 + exp(z)), which approaches z for a large positive zsigmoid(z)
geluthe tanh approximation of GELUnn.dGelu

The standalone calls nn.leakyRelu(x, alpha?) and nn.elu(x, alpha?) take an optional alpha. nn.dense does not: it always uses the defaults above. sigmoid, tanh, and softmax are also on math and call the same functions.

14.4 One backward step

nn.denseBackward(x, weights, upstream, activation?, pre?) returns { dInput, dWeights, dBias }. upstream is the gradient of the loss with respect to out, one number per output, in the same shape as out. The layer multiplies that vector by the activation derivative at pre and calls the result dZ. Then:

  • dBias is dZ. On a batch it is the sum of the rows.
  • dWeights[i][j] is input i times dZ[j]. That is the outer product of the input and dZ.
  • dInput[i] is the sum over outputs of dZ[j] × weights[i][j]. That vector is what the previous layer receives as its upstream.

On the same layer as 14.2.1, ReLU's derivative is 1 at 2.75 and 0 at -1.5. An upstream of [1, 1] therefore becomes dZ = [1, 0]. The bias gradient is [1, 0]. The weight gradient is [[1, 0], [2, 0]] because the inputs are 1 and 2. The input gradient is [0.5, 1]: the dead unit drops the second column of W before that multiply. The snippet prints dInput[0] × 10, then the two bias entries.

var x = [1.0, 2.0];
var w = [[0.5, -1.0], [1.0, 0.0]];
var layer = nn.dense(x, w, [0.25, -0.5], "relu");
var back = nn.denseBackward(x, w, [1.0, 1.0], "relu", layer.pre);
print(int(back.dInput[0] * 10));
print(int(back.dBias[0]));
print(int(back.dBias[1]));

14.4.1 A second layer

Run the output layer backward first. Its dInput is the hidden layer's upstream, and the hidden layer's forward out is the x that the output layer saw. Both layers need the pre they returned.

var hidden = nn.dense(x, w1, b1, "sigmoid");
var out = nn.dense(hidden.out, w2, b2, "sigmoid");
var upstream = nn.mseGrad(out.out, [target]);
var backOut = nn.denseBackward(hidden.out, w2, upstream, "sigmoid", out.pre);
var backHidden = nn.denseBackward(x, w1, backOut.dInput, "sigmoid", hidden.pre);

Examples/AI_Theory/xor_neural_net.malda writes those multiplies with named variables. Examples/AI_Theory/nn_dense.malda trains the same 2-4-1 XOR net with the two calls above.

14.4.2 The weight step

There is no optimizer builtin. After the backward calls, subtract learningRate times dWeights from the weight matrix and learningRate times dBias from the bias, entry by entry. A batch bias gradient is a sum, so a learning rate tuned on one sample is large for many rows unless you scale it.

14.5 Losses

On two numbers, nn.mse(pred, target) is the squared difference. On two vectors of the same length it is the mean of those squares. nn.mse(2, 0) is 4. nn.mse([2, 0], [0, 0]) is 2, the mean of 4 and 0.

nn.mseGrad(pred, target) is elementwise pred − target. That is the derivative of 1/2 (pred − target)², which is what nn_dense.malda accumulates as the epoch loss. The derivative of the value nn.mse itself returns is twice as large on one number, and it is also divided by the length on a vector. Pass mseGrad into denseBackward as upstream when the last layer is a regression output.

print(int(nn.mse(2.0, 0.0)));
print(int(nn.mseGrad(2.0, 0.0)));
print(int(nn.mse([2.0, 0.0], [0.0, 0.0])));

nn.crossEntropyFromLogits(logits, targetIndex) is logSumExp(logits) − logits[targetIndex], the same number as −log(softmax(logits)[targetIndex]). nn.softmaxGrad(logits, target) is softmax(logits) minus a one-hot vector at that class index, or minus a numeric vector of the same length. That gradient is the upstream for a classification layer whose forward activation was "linear": softmax is inside the loss, not a second nonlinearity on pre.

14.6 Examples

Read them in this order. Each file seeds the RNG and runs offline, with no API key.

  1. Examples/AI_Theory/chain_rule.malda — one multiply, and why backprop multiplies local derivatives.
  2. Examples/AI_Theory/perceptron.malda — one neuron. AND and OR are separable; XOR is not, which is why the next file adds a hidden layer.
  3. Examples/AI_Theory/xor_neural_net.malda — a 2-4-1 net. Every chain-rule multiply is a named variable, so you can see dZ, dWeights, and dInput before they disappear into a helper.
  4. Examples/AI_Theory/nn_dense.malda — the same XOR net through nn.dense and nn.denseBackward, including the in-place learning-rate step.
  5. Examples/AI_Theory/softmax_classifier.malda — three classes in 2D. The loss is nn.crossEntropyFromLogits and the upstream is nn.softmaxGrad.
  6. Examples/AI_Theory/mnist_digits.malda — ten 5×5 glyphs in the MNIST shape. The hidden nn.dense is "relu"; the ten logits are "linear", so nn.softmaxGrad is the upstream.
  7. Examples/AI_Theory/gradcheck_dense.malda — one sample. A central difference on each weight matches nn.denseBackward.
  8. Examples/AI_Theory/init_scale.malda — one forward. Uniform saturates a deep sigmoid stack; Xavier does not. He keeps a ReLU stack smaller than that same uniform draw.
  9. Examples/AI_Theory/glyph_holdout.malda — the same ten glyphs, plus a copy with two flipped pixels. Train is perfect. Holdout is not, because those flips swap the 8 with the 9.
  10. Examples/AI_Theory/momentum_valley.malda — the same learning-rate step, with and without a velocity, on a quadratic that is steep in one axis.
  11. Examples/AI_Theory/grad_clip.malda — that same learning rate on a steeper quadratic. Unclipped, the magnitude grows. A cap on the gradient length walks toward zero.
  12. Examples/AI_Theory/adam_valley.malda — the momentum valley again. You keep m, v, and the step counter, and the bias-corrected step finishes near the origin.
  13. Examples/AI_Theory/rnn_delay.malda — a sigmoid recurrence shrinks its gradient. A small tanh net then recalls the bit from three steps earlier.
  14. Examples/AI_Theory/conv_stroke.malda — one 3×3 kernel, reused at every window of a 5×5 dash. The backward pass adds into those nine weights.
  15. Examples/AI_Theory/residual_dropout.malda — a skip connection against a deep sigmoid stack, then a train-time mask that eval does not apply.
  16. Examples/AI_Theory/embed_row.malda — one step writes the gradient into the selected embedding row and leaves the other rows put.
  17. Examples/AI_Theory/next_char.malda — a bigram on a repeated word. The loss is nn.crossEntropyFromLogits, and the dense gradient scatters back into that one row.
  18. Examples/AI_Theory/next_char_mlp.malda — both samples end on a. One successor is b and the other is c. A ReLU hidden layer on the two embedding rows names both.
  19. Examples/AI_Theory/layer_norm.malda — a deep product grows; subtracting the mean and dividing by the standard deviation keeps it near 1. A central difference checks the scale.
  20. Examples/AI_Theory/attention_step.malda — one head. Scores are QK^T / sqrt(d). Training puts the mass on a marked token, then a causal mask stops position 0 from reading position 2.
  21. Examples/AI_Theory/positional_encoding.malda — fixed sinusoids. Position 0 is sin(0) and cos(0). Position 1 matches sin(1) and cos(1).
  22. Examples/AI_Theory/sentence_decoder.malda — one causal block. Token plus sinusoid, residual attention, one linear readout. It overfits abca to bcab, and the dense gradient is clipped before the step.

attention_is_all_you_need.malda is the step after sentence_decoder.malda. It stays on math.matmul and adds multi-head attention, the same sinusoids, and the encoder-decoder. microgpt.malda is a tiny character model on that track. new OnnxModel(path) inspects and runs a small model on the host. It does not train, and it is not a substitute for the files above. malda play Examples/Games/xor_decision_boundary.malda draws the XOR field. malda play Examples/Games/softmax_decision_boundary.malda draws the three softmax regions.

14.7 Backends

Interpreter, C# transpile, and JavaScript all run math.dot / matmul / transpose and nn.*. OnnxModel is host-only. There is no tensor type, no autograd tape, and no Adam or data loader in core. There is no flat alias for nn names: write nn.relu, not relu.
