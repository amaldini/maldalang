11. Input/Output

11.1 Output

Console output uses io.print(...) (preferred) or the deprecated flat alias print(...):

print("Hello, World!");
print(42);
print("Value of x: " + x);  // String concatenation
print($"Value of x: {x}");   // String interpolation (preferred)

11.2 Input

The input() function reads user input from the console:

var name = input("Enter your name: ");
var age = input("Enter your age: ");  // Returns string, convert if needed
var num = int(input("Enter a number: "));  // Type conversion
Input Function Behavior: The input() function is asynchronous and pauses script execution until user input is provided. Execution resumes exactly from the same statement after input is received. Works correctly within loops, functions, and nested control structures.

11.3 Sleep

The sleep() function pauses script execution for the specified number of milliseconds:

sleep(1000);  // Sleep for 1 second (1000 milliseconds)
sleep(500);   // Sleep for 500 milliseconds (0.5 seconds)
Sleep Function Behavior: The sleep() function is asynchronous and doesn't consume CPU while waiting. Useful for keeping scripts alive in loops without CPU spinning. Commonly used with REST servers and long-running processes.

Example: Keep Server Alive

// Keep server alive without consuming CPU
while (server.isRunning) {
    sleep(1000);  // Sleep for 1 second
}
