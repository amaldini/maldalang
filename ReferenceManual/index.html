MALDA™ Reference Manual

The AI-First Programming Language - Version 1.0.27

Welcome to the MALDA Reference Manual

MALDA is an object-oriented language with prompts, agents, and durable workflows as language constructs — not a library bolted onto another stack. The name and runtime architecture are in 1. Introduction.

What ships today: MALDA 1.0.27 (this manual). Tier 0 language semantics are specified in malda-language-1.0. A C# interpreter, a compiler that transpiles to C# or JavaScript, a Windows Desktop IDE, a browser playground, and a language server for cross-platform editors. The interpreter is the full host surface; C# transpile shares it. JavaScript is a subset: dom.* / game.* / three.* / @shader() are JS-only, while agents, HTTP servers, file I/O, VectorDB, and workflows stay on the host. Each chapter states its backends; the table is the backend capability matrix.
Find a concept: Use the sidebar search (press / or Ctrl+K) or browse the glossary. Short names such as cap jump to capability tokens in 13.19.3 and 12.6.
How to get MALDA: on Windows, download the win-x64 zip from GitHub Releases and run MaldaDesktop.bat (CLI + Desktop IDE), then Start With MALDA. Linux: the linux-x64 zip and ./malda. From source: dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda. No install: the Web IDE playground. After that, a student only needs malda file.malda — see Learn MALDA.
Recommended onboarding: MALDA works best with a dual-track start. New programmers should begin with Learn MALDA. Experienced builders can jump straight into prompts, agents, APIs, and full-stack showcases. After the core path, follow Learn MALDA — After the core path (algorithms, then one hub). The from-scratch nets — perceptron, XOR, then chapter 14 — are the AI theory track in Start Here. For runnable example paths and CLI quickstarts, see Start Here.

Quick Start

If you already program, start with the characteristic constructs. -> Review binds the prompt to the schema. Without await, the call is a rendered template (no API key). validate("Review", …) is the same check await would run on the model JSON. Type annotations elsewhere are IDE/LSP hints, not runtime checks. Same file: Examples/Basics/first_look.malda.

1. First Look

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}

Then the syntax path, if you want the core language before agents and APIs. Prefer namespaced calls (io.print, math.sqrt, str.upper); flat print still runs.

2. Print Output

io.print("Hello, World!");

3. Variables and Arithmetic

var price = 12;
var quantity = 3;
var total = price * quantity;

io.print("Total: " + total);

4. Conditionals

var score = 82;

if (score >= 60) {
    io.print("Pass");
} else {
    io.print("Fail");
}

5. Loops and Functions

function printCountdown(start) {
    var current = start;
    while (current > 0) {
        io.print(current);
        current = current - 1;
    }
    io.print("Go!");
}

printCountdown(3);

6. Complete Starter Program

This example combines variables, arrays, a loop, a function, and an if statement in one linear program:

var cart = [12, 18, 7];
var total = 0;

for (var item in cart) {
    total = total + item;
}

function describeTotal(amount) {
    if (amount >= 30) {
        return "big order";
    }
    return "small order";
}

io.print("Items: " + cart.length);
io.print("Total: " + total);
io.print("Summary: " + describeTotal(total));

For more of this, one lesson at a time, see Learn MALDA. The folder catalog is Examples; CLI paths are in Start Here.
