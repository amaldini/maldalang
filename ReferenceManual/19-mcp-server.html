19. MCP Server

The MCPServer class allows MALDA to function as an MCP (Model Context Protocol) tools server, enabling developers to write custom MCP tools in MALDA and expose them to MCP clients like Claude Desktop or ChatGPT.

19.1 Overview

MCP (Model Context Protocol) is a protocol for connecting AI applications with external data sources and tools. MALDA's MCP server implementation allows you to:

  • Define custom tools using the @MCPTool decorator
  • Expose MALDA functions as MCP tools
  • Communicate via JSON-RPC 2.0 over STDIO transport
  • Automatically generate JSON Schema tool definitions

19.2 @MCPTool Decorator

Functions decorated with @MCPTool are automatically discovered and registered as MCP tools when the server starts.

Syntax

@MCPTool("tool_name", "Tool description")
function myTool(param1, param2) {
    return param1 + param2;
}

With Custom Schema

@MCPTool("tool_name", "Tool description", "{\"type\":\"object\",\"properties\":{...}}")
function myTool(param1) {
    // ...
}

19.3 MCPServer Class

Constructor

var server = new MCPServer();                    // STDIO transport (default)
var server = new MCPServer("stdio");            // Explicit STDIO transport

Methods

  • start(): Start the MCP server and discover tools
  • stop(): Stop the MCP server
  • getTools(): Return list of registered tools

19.4 Tool Schema Generation

If no custom schema is provided, the tool schema is automatically generated from function parameters:

  • All parameters default to type "string" in JSON Schema
  • All parameters are marked as required
  • Parameter names from the MALDA function are used as property names

19.5 Complete Example

@MCPTool("add", "Adds two numbers together")
function add(a, b) {
    return int(a) + int(b);
}

@MCPTool("reverse_string", "Reverses a string")
function reverseString(text) {
    var reversed = "";
    var i = length(text) - 1;
    while (i >= 0) {
        reversed = reversed + substring(text, i, 1);
        i = i - 1;
    }
    return reversed;
}

var server = new MCPServer();
server.start();

while (server.isRunning) {
    sleep(1000);
}

19.6 MCP Protocol Support

The MCP server implements the following JSON-RPC 2.0 methods:

  • initialize: Capability negotiation and server initialization
  • tools/list: Returns list of available tools with their schemas
  • tools/call: Executes a tool with provided arguments
  • notifications/initialized: Notification sent after initialization

19.7 MCP Client

The MCPClient class allows MALDA scripts to dynamically connect to MCP servers and use their tools. This enables MALDA agents to connect to external MCP servers programmatically and create wrapper agents with MCP tools.

Overview

The MCPClient class provides:

  • Dynamic connection to MCP servers via STDIO transport
  • Tool discovery from connected MCP servers
  • Direct tool calling without creating tool instances
  • Creation of wrapper agents with all MCP tools automatically added

Constructor

var client = new MCPClient(serverName);

Parameters:

  • serverName (string): A unique identifier for the MCP server connection

Methods

connect(command, args?, env?)

Connects to an MCP server by starting a process and establishing a JSON-RPC connection.

Parameters:

  • command (string, required): Executable command to start the MCP server
  • args (array, optional): Command-line arguments as an array of strings
  • env (object, optional): Environment variables as key-value pairs

Returns: boolean - true if connection succeeded

var client = new MCPClient("my-server");
var connected = client.connect("python", ["-m", "mcp_server"], {"API_KEY": "secret"});

disconnect()

Disconnects from the MCP server and stops the process.

getTools()

Returns an array of all available tools from the connected MCP server.

Returns: array - Array of tool objects with name, description, and schema properties

callTool(toolName, arguments?)

Calls an MCP tool directly without creating a tool instance.

Parameters:

  • toolName (string, required): Name of the tool to call
  • arguments (object, optional): Tool arguments as an object

Returns: Result from the tool call (converted from JSON to MALDA types)

createTool(toolName, registeredName?, register?)

Creates an MCPToolInstance wrapper for a specific tool.

Parameters:

  • toolName (string, required): Name of the tool from the MCP server
  • registeredName (string, optional): Custom name for tool registration (default: mcp:serverName:toolName)
  • register (boolean, optional): Whether to register the tool in ToolRegistry (default: false)

Returns: MCPToolInstance - A tool instance that can be added to agents

refreshTools()

Re-discovers tools from the MCP server. Useful if tools have changed after connection.

Returns: boolean - true if refresh succeeded

createWrapperAgent(name, role, instructions, llmClient?)

Creates an Agent instance with all MCP tools automatically added. This is a convenience method that combines agent creation with tool discovery and registration.

Parameters:

  • name (string, required): Agent name
  • role (string, required): Agent role description
  • instructions (string, required): Agent instructions/system prompt
  • llmClient (optional): LLMClient, LlamaCppClient, or LLMClientBridge instance. If omitted, defaults to a local LLM (Qwen/Qwen2.5-0.5B-Instruct, auto-downloaded as a GGUF build from Hugging Face on first use).

Returns: Agent - A fully configured agent with all MCP tools already added

// Connect to MCP server
var mcpClient = new MCPClient("data-analyst");
mcpClient.connect("./data_analyst_server.exe", [], {});

// Create wrapper agent with all MCP tools automatically added
var agent = mcpClient.createWrapperAgent(
    "DataAnalyst",
    "Data Analysis Specialist",
    "You analyze data and provide insights using MCP tools."
);

// Agent is ready to use - all tools are already added!
var response = agent.think("Analyze sales data: Q1=$100k, Q2=$150k");
print(response.content);

Properties

  • serverName (string): The server name identifier
  • isConnected (boolean): Whether the client is currently connected to an MCP server

Complete Example: Dynamic Agent Creation

// Step 1: Create and compile an MCP agent server (using SPLCodingAgent)
var agentBuilder = new SPLCodingAgent(
    "AgentBuilder",
    "Agent Creation Specialist",
    "You create, compile, and test MCP agent server scripts.",
    client,
    "./agents"
);

// Step 2: Create an MCP server script
var result = createMcpAgentScript(
    "DataAnalyst",
    "Data Analysis Specialist",
    "You analyze data and provide insights.",
    [
        {"name": "analyze_data", "description": "Analyzes data"},
        {"name": "generate_report", "description": "Generates reports"}
    ],
    "./agents/data_analyst_server.malda",
    "openai/gpt-4"
);

// Step 3: Compile the script
var compileResult = compileMALDA(result.outputPath, "./agents/data_analyst_server.exe");

// Step 4: Connect to the MCP server
var mcpClient = new MCPClient("data-analyst");
var connected = mcpClient.connect("./agents/data_analyst_server.exe", [], {});

if (connected) {
    // Step 5: Create wrapper agent with all tools automatically added
    var agent = mcpClient.createWrapperAgent(
        "DataAnalyst",
        "Data Analysis Specialist",
        "You analyze data and generate reports."
    );
    
    // Agent is ready to use!
    var response = agent.think("Analyze this data: Q1=$100k, Q2=$150k, Q3=$180k");
    print(response.content);
    
    // Cleanup
    mcpClient.disconnect();
}
