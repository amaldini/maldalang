7. Expressions

Expressions are combinations of values, variables, operators, and function calls that evaluate to a single value.

7.1 Arithmetic Expressions

Arithmetic expressions perform mathematical operations:

var sum = 10 + 20;        // 30
var product = 5 * 6;      // 30
var quotient = 15 / 3;    // 5
var remainder = 17 % 5;   // 2
var difference = 10 - 3;  // 7

7.2 Comparison Expressions

Comparison expressions return boolean values. Relational operators (<, >, <=, >=) work with both numbers and strings:

// Numeric comparisons
var isEqual = (x == y);
var isGreater = (a > b);
var isLessOrEqual = (x <= 10);
var isNotEqual = (x != y);

// String comparisons (lexicographic/alphabetical order)
var isBefore = ("apple" < "banana");      // true
var isAfter = ("zebra" > "apple");        // true
var isSameOrBefore = ("hello" <= "hello"); // true
var isSameOrAfter = ("hello" >= "hello");  // true

String Comparison Notes:

  • String comparisons use lexicographic (alphabetical) ordering
  • Comparisons are case-sensitive (e.g., "A" < "a" is true)
  • Empty strings are less than any non-empty string
  • Both operands must be strings (or both numbers) - mixing types causes a runtime error

7.3 Logical Expressions

Logical expressions combine boolean values. The language supports both keyword-based and symbol-based logical operators:

var result = (x > 0) and (y < 100);    // or: (x > 0) && (y < 100)
var isValid = not (x == 0);            // or: !(x == 0)
var condition = (a == 1) or (b == 2);  // or: (a == 1) || (b == 2)

7.4 String Concatenation

The + operator concatenates strings:

var greeting = "Hello, " + "World!";
var message = "Value: " + x;

7.5 String Repetition

The * operator repeats strings when one operand is a string and the other is a number:

var stars = "*" * 20;        // "********************"
var dashes = "-" * 10;       // "----------"
var pattern = "abc" * 3;     // "abcabcabc"
var count = 5;
var repeated = "x" * count;  // "xxxxx"

String Repetition Features

  • Use string * number or number * string (both work the same way)
  • The numeric value is coerced to an integer
  • If the count is 0 or negative, an empty string is returned
  • Works with variables and expressions
  • Also supports compound assignment: var s = "x"; s *= 5;

Examples

print("*" * 10);              // Output: **********
print(5 * "-");                // Output: -----
var n = 3;
print("ha" * n);               // Output: hahaha
var s = "=";
s *= 20;                       // s is now "===================="
print("x" * 0);                // Output: (empty string)

7.6 String Interpolation

String interpolation provides a convenient way to embed expressions in strings using $"..." syntax:

var name = "Alice";
var age = 25;
print($"Hello, {name}!");  // Output: Hello, Alice!
print($"Name: {name}, Age: {age}");  // Output: Name: Alice, Age: 25
print($"Sum: {10 + 20}");  // Output: Sum: 30

Interpolation Features

  • Use $"..." prefix to create an interpolated string
  • Embed expressions within {...} braces
  • Supports any valid expression: variables, function calls, arithmetic, etc.
  • Escape sequences work the same as regular strings
  • To include literal { or }, use \{ or \}
  • To include literal $, use \$
  • String literals in expressions can use either single or double quotes: $"Value: {'test'}" or $"Value: {\"test\"}"

Examples with Single Quotes

var name = 'Alice';
print($"Hello, {name}!");           // Single quotes in variable
print($"Text: {'value'}");          // Single quotes in expression
print($"Nested: {'He said "hello"'");  // Single quotes avoid escaping

7.7 Increment and Decrement Operators

The increment (++) and decrement (--) operators modify a variable's value by 1. They can be used as prefix or postfix operators:

var x = 5;
++x;        // Prefix: x is now 6, expression evaluates to 6
x++;        // Postfix: x is now 7, expression evaluates to 6 (old value)
--x;        // Prefix: x is now 6, expression evaluates to 6
x--;        // Postfix: x is now 5, expression evaluates to 6 (old value)

Prefix vs Postfix

  • Prefix (++x, --x): Increments/decrements the variable first, then returns the new value
  • Postfix (x++, x--): Returns the current value first, then increments/decrements the variable

These operators can be used with variables, object properties, and array elements:

var arr = [10, 20, 30];
arr[0]++;           // arr[0] is now 11

var obj = { count: 5 };
obj.count++;        // obj.count is now 6

7.8 Compound Assignment Operators

Compound assignment operators combine an arithmetic operation with assignment:

var x = 10;
x += 5;     // Equivalent to: x = x + 5;  (x is now 15)
x -= 3;     // Equivalent to: x = x - 3;  (x is now 12)
x *= 2;     // Equivalent to: x = x * 2;  (x is now 24)
x /= 4;     // Equivalent to: x = x / 4;  (x is now 6)

Available Operators

  • += - Add and assign
  • -= - Subtract and assign
  • *= - Multiply and assign
  • /= - Divide and assign

Compound assignment operators work with variables, object properties, and array elements:

var arr = [10, 20];
arr[0] += 5;        // arr[0] is now 15

var obj = { value: 100 };
obj.value *= 2;     // obj.value is now 200

var d = dict { "count": 1 };
d["count"] += 1;    // d["count"] is now 2

Note: For string concatenation, += appends to the string:

var str = "Hello";
str += " World";    // str is now "Hello World"

Note: For string repetition, *= repeats the string:

var str = "x";
str *= 5;           // str is now "xxxxx"

7.9 Ternary Conditional Expression

The ternary operator (? :) provides a concise way to write conditional expressions. It evaluates a condition and returns one of two values based on whether the condition is true or false.

Syntax

condition ? valueIfTrue : valueIfFalse

Behavior

  • If the condition evaluates to a truthy value, the expression returns valueIfTrue
  • If the condition evaluates to a falsy value, the expression returns valueIfFalse
  • Only the selected branch is evaluated (short-circuit evaluation)

Examples

var age = 18;
var status = age >= 18 ? "adult" : "minor";
print(status);  // Output: "adult"

var score = 85;
var grade = score >= 90 ? "A" : (score >= 80 ? "B" : "C");
print(grade);  // Output: "B"

var max = a > b ? a : b;  // Find maximum of two values

var unit = "fahrenheit";
var symbol = unit == "fahrenheit" ? "F" : "C";
print(symbol);  // Output: "F"

Nested Ternary Expressions

Ternary expressions can be nested, but for readability, consider using if-else statements for complex conditions:

// Nested ternary (works but can be hard to read)
var result = x > 0 ? (y > 0 ? "both positive" : "x positive") : "x not positive";

// Equivalent if-else (more readable)
var result;
if (x > 0) {
    if (y > 0) {
        result = "both positive";
    } else {
        result = "x positive";
    }
} else {
    result = "x not positive";
}

Operator Precedence

The ternary operator has lower precedence than logical operators (and, or) but higher than assignment. Use parentheses when mixing with other operators:

var result = (x > 0 and y > 0) ? "both positive" : "at least one non-positive";
var value = condition ? a + b : c - d;  // Parentheses not needed here

7.10 Dictionary Literals and Indexing

Dictionaries use the dict { ... } literal syntax and are indexed with square brackets, similar to arrays but with string keys.

Dictionary Literal Syntax

var d = dict { "a": 1, "b": 2 };
print(d["a"]);      // 1
print(d["b"]);      // 2

// Add or update entries
d["c"] = 3;
print(d["c"]);      // 3

// Missing keys return null
print(d["missing"] == null);  // true

Dictionary Methods in Expressions

var d = dict { "x": 10 };
print(d.get("x"));           // 10
print(d.containsKey("x"));   // true
d.set("y", 20);
print(d["y"]);               // 20

var keys = d.keys();
var values = d.values();

7.11 List and Dictionary Comprehensions

A comprehension builds a collection from an existing iterable in a single expression, with an optional filter.

List Comprehensions

The syntax is [ resultExpression for variable in iterable ], optionally followed by if condition:

var numbers = [1, 2, 3, 4, 5];

var squares = [n * n for n in numbers];
print(squares);        // [1, 4, 9, 16, 25]

var evens = [n for n in numbers if n % 2 == 0];
print(evens);          // [2, 4]

var labels = ["item-" + n for n in numbers if n > 3];
print(labels);         // ["item-4", "item-5"]

The loop variable is scoped to the comprehension and does not leak into the surrounding scope. The filter, when present, is evaluated before the result expression, so elements that fail the condition never reach it.

Dictionary Comprehensions

The dictionary form uses dict { keyExpression: valueExpression for variable in iterable }, again with an optional if filter:

var words = ["alpha", "beta", "gamma"];

var lengths = dict { w: length(w) for w in words };
print(lengths["alpha"]);   // 5

var longOnly = dict { w: length(w) for w in words if length(w) > 4 };
print(longOnly.containsKey("beta"));   // false

Keys must evaluate to strings, as with any dictionary. When two iterations produce the same key, the later one wins.

Comprehensions are supported by the interpreter, the C# transpiler, and the JavaScript transpiler.

7.12 Null-Conditional Access

?. and ?[ perform a member or index access only when the receiver is not null. When it is null, the access evaluates to null instead of raising Accessing members of null:

var user = null;

print(user?.name);        // null
print(user?["name"]);     // null

// Without the operator this is a runtime error:
// print(user.name);

Each operator guards its own receiver, so a chain needs the operator at every step that can be null:

var config = dict { "db": null };

print(config["db"]?.host);       // null: the ?. guards the null value
// print(config["db"].host);     // runtime error

var response = dict { "items": null };
print(response["items"]?[0]);    // null

Null-conditional access reads a value; it is not an assignment form. Use it to traverse optional data such as parsed JSON, dictionary lookups that may miss, and object fields that are only populated in some code paths.

7.12.1 Null-Coalescing ??

a ?? b evaluates to a when a is not null; otherwise it evaluates b. Unlike or/||, only null triggers the right side — 0, false, and "" are kept:

print(0 ?? 1);
print(false ?? true);
print("hi" ?? "x");
print(null ?? "fallback");

Combine with null-conditional access for optional chains:

var user = null;
print(user?.name ?? "guest");
print("|" + str.trimText(user?.name) + "|");

Precedence sits between logical OR and the ternary conditional; ?? is right-associative.

7.14 Async and Await Expressions

MALDA supports first-class asynchronous operations through async and await expressions. These allow you to work with asynchronous operations without blocking execution.

Async Expression

The async keyword creates a Task value from an expression. When applied to a function call, it starts the asynchronous operation and returns immediately with a Task that represents the ongoing operation:

var task = async sleep(100);  // Start sleep, get Task immediately
var task2 = async fetchData(url);  // Start async function call

When applied to a non-call expression, it wraps the value in a completed Task:

var task = async 42;  // Creates a Task that immediately completes with 42

Await Expression

The await keyword waits for a Task to complete and returns its result:

var task = async sleep(100);
await task;  // Wait for sleep to complete

var dataTask = async fetchData(url);
var data = await dataTask;  // Wait and get the result

Important: await can only be used with Task values. Attempting to await a non-Task value will throw a runtime error.

Complete Example

// Start an async operation
var delayTask = async sleep(50);

// Do other work here if needed...

// Wait for the operation to complete
await delayTask;
print("Done!");

// Chain async operations
var result = await async someAsyncFunction(arg1, arg2);

Use Cases

  • Concurrent execution: Start multiple async operations and await them later
  • Non-blocking I/O: Perform file operations, network requests, etc. without blocking
  • Timing operations: Use with sleep() for delays
  • Integration with async built-in functions and prompts

Structured Concurrency with all()

The built-in all() function composes multiple Tasks into a single Task that completes when all of its children have finished.

Basic Usage

// Variadic form: pass tasks as separate arguments
var t1 = async fetchData(url1);
var t2 = async fetchData(url2);
var allTask = all(t1, t2);
var results = await allTask;   // results is an array [data1, data2]

// Array form: pass an array of tasks
var tasks = [async sleep(10), async sleep(20)];
var allTask2 = all(tasks);
await allTask2;

Semantics

  • Input: all() accepts either a single array of values or multiple arguments.
  • Task coercion: Each element/argument that is already a Task is awaited; non-task values are treated as already-completed tasks.
  • Return value: all() returns a Task. When awaited, it yields an array of results in the same order as the inputs.
  • Best-effort completion: All child tasks are allowed to run to completion. all() does not cancel other tasks when one fails.
  • Error behavior: If one or more children fail, await all(...) throws the first error after all children have completed.

Example: Parallel Work then Aggregate

function computeA() {
    sleep(10);
    return 1;
}

function computeB() {
    sleep(20);
    return 2;
}

var tA = async computeA();
var tB = async computeB();

var allTask = all(tA, tB);
var results = await allTask;      // [1, 2]
var sum = results[0] + results[1];
print(sum);                       // 3

Overlapping hot-started user functions that call sleep (or otherwise await) before the next var binding keep isolated locals, this, and defer stacks. The caller environment is restored after scheduling each task, so var tA = async computeA(); var tB = async computeB(); binds on the caller. Built-in async sleep(...) is the same. See Examples/Basics/async_all_example.malda.

Note: all() is a compositional building block: it does not start tasks itself, it only combines tasks you create (for example with async).

7.15 Pipe Operator (|>)

The pipe operator passes the value on the left as the first argument to the callable on the right. It enables left-to-right data flow for AI pipelines, prompts, and built-in functions.

// Prompt: left value becomes the first parameter
prompt greet(name) {
    user: "Hello, {name}!"
}
var p = "Alice" |> greet;

// Built-in: parse JSON after an LLM response string
schema Answer { text: string; sources: string[]; }
var parsed = llmOutput |> parseJson("Answer");

// Retriever chain
var context = question |> retriever.get |> formatRetrievedDocs;

// Lambda adapter in the middle of a chain
var p = question
    |> retriever.get
    |> formatRetrievedDocs
    |> (ctx) => answerPrompt(question, ctx);

Rules:

  • a |> f is equivalent to f(a) when f is a function, prompt, or built-in name
  • a |> f(b) passes a as the first argument: f(a, b)
  • Member access on the right (e.g. retriever.get) is supported; the left value is passed as the query argument
  • await applies to the entire pipe expression: await (x |> f |> g) evaluates the chain and awaits async steps (e.g. runPrompt)
  • Pass { onToken: (token) => ... } to runPrompt for streamed content tokens; { onReasoning: (token) => ... } for reasoning/thinking deltas
  • Pipe has lower precedence than most operators; use parentheses when mixing with arithmetic or logical expressions

See 13. Built-in Functions (AI pipeline helpers) and 15. VectorDB (asRetriever) for RAG examples. Full walkthrough: Examples/Prompts/rag_pipeline.malda.

Advanced composition: use composePipe(f, g, …) to build a reusable sequence function; parallelRun(input, { branch: fn, … }) for parallel fan-out; mergeRetrievedDocs to combine parallel retrieval hits before formatRetrievedDocs. Example: Examples/Prompts/rag_compose_pipeline.malda.

To name and reuse a pipeline, wrap the pipe expression in an ordinary function and return the result. See Examples/Prompts/rag_function_pipeline.malda and 10. Prompts.
