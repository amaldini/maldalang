13.1.1 Safe Integer Conversion Helpers

Use these helpers when input may be empty, null, or malformed.

var page = toIntOr(query.page, 1);          // Fallback when null/empty/unparseable
var limit = toIntOr(query.limit, 50);       // Always returns integer
var ownerId = toIntOrNull(query.ownerId);   // Returns null when missing/unparseable
  • toIntOr(value, fallback) - returns parsed integer when possible, otherwise fallback.
  • toIntOrNull(value) - returns parsed integer or null when value is null/empty/unparseable.
  • Both functions accept integer, float, boolean, and numeric string values.

13.2 Stdlib Namespaces and Flat Aliases

Most of the standard library is reachable in two spellings: a namespaced call through a module object, and a flat global of the same name. Both resolve to the same implementation and behave identically at runtime.

print(math.sqrt(16));                          // namespaced
print(sqrt(16));                               // flat alias, same result

print(str.join(str.split("a,b", ","), "|"));   // a|b
print(io.readFile("config.json"));

The module objects

mathRounding, trigonometry, aggregates, random helpers, LLM math, linear algebra, and the constants math.PI, math.E, math.TAU, math.INF, math.NaN

strCase, trimming, splitting and joining, padding, regex helpers, similarity, base64, md5 / sha256

Math (capital M) is a deprecated alias for the same object as math.

Which flat names are deprecated

Only the flat names that have a math., str., or io. counterpart are considered deprecated aliases. Calling one produces an IDE and language-server warning from source malda-style, in the form Prefer 'io.print(...)' instead of 'print(...)' (deprecated flat alias). The warning is advisory: nothing is removed at runtime and the transpilers accept both spellings.

The affected names, mirroring MaldaLang/BuiltIns/StdLibNamespaces.cs:

  • math: abs, sum, average, max, min, pow, sqrt, floor, ceil, round, trunc, sign, exp, log, log10, log2, sin, cos, tan, asin, acos, atan, atan2, hypot, clamp, degToRad, radToDeg, zeros, rsqrt, randn, argmax, argmin, logSumExp, softmax, dot, matmul, transpose, sigmoid, tanh, randomChoiceWeighted, seed, random, randomInt, randomFloat, anneal
  • str: length, upper, lower, trim, text, trimText, substring, indexOf, replace, split, normalizeText, tokenize, tokenOverlap, similarity, extractNumbers, regexMatch, regexReplace, regexFind, startsWith, endsWith, padStart, padEnd, includes, join, repeat, base64Encode, base64Decode, md5, sha256
  • io: print, input, readFile, writeFile, copyFile, readFileBase64, writeFileBase64, readTextFileLines, deleteFile, hasFile, hasDirectory, ensureDir, listDirectory, hasEmbeddedFolder, embeddedFolderRoot, glob, grep, replaceInFile, pathExists, pathJoin, pathNormalize, pathGetExtension, isPathUnder, getEnv, getEnvOr, hasEnv, getFileName, getDirectoryName, gitStatus, gitAdd, gitCommit, gitDiff, gitLog, gitBranch, gitCheckout, gitPull, gitPush

Every other built-in in this chapter — sleep, runCommand, parseJson, the agent and workflow helpers, and so on — has no module counterpart and no deprecation attached to it.

Convention used in this manual: examples throughout the manual and in Examples/ use the flat spelling (print(...), sqrt(...)) because it is shorter and it is what existing MALDA code looks like. Read those as equivalent to the namespaced form. In new code, prefer the namespaced spelling if you want the editor to stay warning-free.

math.max and math.min accept (a, b) or a non-empty numeric array. Aggregates are also methods: values.sum(), values.average(), values.min(), values.max(). Trigonometry is in radians; out-of-domain input is NaN, not an error. math.round uses banker's rounding.

math.zeros(n) / math.zeros(rows, cols)

Builds a 1D vector or a 2D nested array filled with 0.0. The two-argument form allocates a fresh row per row, so writing m[0][0] does not change other rows. Dimensions must be integers >= 0. Empty sizes are allowed: math.zeros(0) is [], and math.zeros(2, 0) is two empty rows.

var w = math.zeros(2);        // [0, 0]
var g = math.zeros(3, 4);     // 3 rows, 4 columns
g[0][0] = 1.0;                // other rows stay zero

13.3.1 LLM-oriented Math Helpers (Reference)

See math.seed through math.anneal in the table. Invalid counts or types, empty arrays, a non-positive softmax temperature, or zero total weight throw. math.seed pins math.random, math.randomInt, math.randomFloat, math.randn, math.randomChoiceWeighted, and math.anneal.

13.3.2 Simulated annealing

math.anneal(initial, cost, neighbor, options?) runs Metropolis simulated annealing. cost and neighbor are unary lambdas (or named functions): cost returns a finite number to minimize, neighbor returns a candidate state. Optional options:

  • steps — iteration count (default 1000)
  • temp / temperature — initial temperature (default 1.0)
  • cooling — geometric factor (default 0.995) or a unary lambda t => nextTemp
  • schedule — same as a function cooling
  • maximize — true to maximize cost (default false)
  • copy — clone arrays/dicts before each neighbor call and when saving the best state (default true)

Returns { state, cost, steps }. Acceptance uses math.random(), so math.seed(n) makes a run reproducible. Like other RNG helpers, anneal is WF1001 outside a workflow step.

math.seed(1);
var result = math.anneal(0.0, x => x * x, x => x, { steps: 5 });
print(result.cost == 0.0);
print(result.steps);
math.seed(7);
var result = math.anneal(
    10.0,
    x => (x - 3.0) * (x - 3.0),
    x => x + math.randomFloat(-1.0, 1.0),
    { steps: 800, temp: 2.0, cooling: t => t * 0.995 }
);
print(result.state);
print(result.cost);

Extension-style string methods

The functions length, upper, lower, trim, substring, indexOf, replace, split, startsWith, endsWith, padStart, padEnd, and repeat can also be called as methods on any string value. The receiver is the first argument.

print("hello".upper());                 // HELLO
print("HELLO".lower());                 // hello
var s = "Hello";
print(s.substring(0, 3));               // Hel
print("abc".repeat(2));                 // abcabc
var f = "world".upper;                  // method as value
print(f());                             // WORLD

Calling an unsupported member on a string (e.g. s.foo()) is a runtime error. Path helpers (io.pathJoin, io.isPathUnder, …) are in 13.8. ~/.malda helpers are in 13.5.

13.5.1 Host Information

Argument-less built-ins describe the machine and invocation the program is running under. Passing any argument raises an error.

var host = getHostPlatform();
print(host.os);              // Operating system identifier
print(host.arch);            // Process architecture
print(host.pathSeparator);   // "\" on Windows, "/" elsewhere
print(host.description);     // Full OS description string

var args = getCommandLineArgs();
// Arguments passed to the program, excluding the program name itself
if (args.length > 0) {
    print("first argument: " + args[0]);
}

// Folder of the .malda script (interpreter) or of the compiled .exe (transpile)
var programDir = getProgramDirectory();
var modelPath = io.pathJoin(programDir, "bge-m3-Q4_K_M.gguf");

getHostPlatform() returns an object with the four fields shown above. getCommandLineArgs() returns an array of strings and is the way to read CLI arguments from a MALDA program, in both interpreted and transpiled runs. getProgramDirectory() returns the absolute directory of the running .malda source file under the interpreter, or AppContext.BaseDirectory (the folder containing the compiled executable) after malda compile.

13.5.2 Web search (Brave Search API)

webSearch(query, apiKey?) — Performs a web search using the Brave Search API. query is the search string. apiKey is optional; if omitted, the key is taken from (in order) the apiKey argument, the BRAVE_SEARCH_API_KEY environment variable, or tools.web.search.apiKey in ~/.malda/config.json (see Personal Assistant and CLI). Returns an object: { ok: true, results: [{ title, url, description }, ...], moreResultsAvailable: bool } on success, or { ok: false, error: "message" } on failure.

var r = webSearch("MALDA programming language");           // Uses BRAVE_SEARCH_API_KEY or config
var r2 = webSearch("weather London", "your-brave-api-key"); // Explicit key
if (r.ok) { for (var i = 0; i < r.results.length; i++) print(r.results[i].title); }

13.5.3 HTTP auth token helpers

These helpers extract tokens from request-like objects used by HttpServer handlers.

var bearer = httpBearerToken(req); // Reads Authorization: Bearer <token>
var cookie = httpCookieToken(req, "app_session", "cookie-secret"); // Signed cookie token

var token = httpAuthToken(req, {
  "allowBearer": true,
  "allowCookie": true,
  "allowBody": true,
  "cookieName": "app_session",
  "cookieSecret": "cookie-secret",
  "bodyKey": "auth"
});
  • httpBearerToken(request) - returns bearer token string or empty string.
  • httpCookieToken(request, cookieName, cookieSecret?) - returns decoded cookie token (or verified secure-cookie value when secret is provided), otherwise empty string.
  • httpAuthToken(request, options?) - tries bearer/cookie/body in order and returns first non-empty token.

Wire these into handlers with req.auth — see 13.25 and 29.6.2.

toJSON writes dicts, arrays, and the public instance fields of a class (including a primary constructor). Methods and private fields are omitted. A cycle throws. parseJSON always returns a dict — it does not reconstruct the class. Build a new instance yourself if you need methods again.

class Point(x, y);
var d = parseJSON(toJSON(new Point(3, 4)));
print(d.x);
print(d.y);

parseJSON parses arbitrary JSON into MALDA values. parseJson(jsonString, schemaName) parses JSON and validates it against a registered schema declaration, throwing on mismatch.

schema Answer {
    text: string;
    sources: string[];
}

var parsed = parseJson('{"text":"ok","sources":["a.md"]}', "Answer");
print(parsed.text);           // ok
print(parsed.sources[0]);       // a.md

Array field types use type[] syntax (e.g. string[], int[], or OtherSchema[]). Field types may also name another declared schema (nested object shapes are expanded for validation and typed prompts) or a declared sum type (tagged oneOf JSON). Optional fields append ? after the type. Unknown field type names and cyclic schema references raise an error when the schema is resolved.

13.7.1 validate(schema, value)

Checks a value that you already have against a schema, without parsing JSON. Unlike parseJson, a validation failure is not an exception: the result is always an object reporting the outcome.

  • On success: { ok: true, data: value }
  • On failure: { ok: false, error: "message" }

The first argument is either the name of a registered schema or sum type, or an inline schema object. An unknown name raises Unknown schema 'Name'. On success, data is the original value — a tagged dict stays a dict (it is not coerced to a variant). Use asVariant("Intent", dict) or await prompt … -> Intent when you need a variant for match. The agent factory is createValidateJsonTool (no working directory; parallel-safe); it returns the same { ok, data } / { ok: false, error } object.

schema Answer {
    text: string;
    sources: string[];
}

var candidate = dict { "text": "ok", "sources": ["a.md"] };

var checked = validate("Answer", candidate);
if (checked.ok) {
    print(checked.data.text);      // ok
} else {
    print("invalid: " + checked.error);
}
type Intent = Search(query) | Buy(sku, qty);
var tagged = dict { "tag": "Buy", "sku": "SKU-9", "qty": 2 };
var checkedIntent = validate("Intent", tagged);
if (checkedIntent.ok) {
    print(checkedIntent.data.tag);
}
type Intent = Search(query: string) | Buy(sku: string, qty: int);
var tagged = dict { "tag": "Buy", "sku": "SKU-9", "qty": "x" };
var checkedTyped = validate("Intent", tagged);
print(checkedTyped.ok);
Not to be confused with: memory.validate() on a GraphMemory instance, which checks graph integrity rather than a schema. The two share a name but are unrelated.

13.7.1.1 asVariant(typeName, value)

Turns a tagged dict into a sum-type variant so match can bind constructors. validate("Intent", dict) never does this. An already-built variant is returned as-is when its tag belongs to the type. Mismatch (unknown type name, object schema, bad tag, typed payload that fails JSON Schema) throws — unlike validate.

type Intent = Search(query: string) | Buy(sku: string, qty: int) | Help();
var tagged = dict { "tag": "Buy", "sku": "SKU-9", "qty": 2 };
var checked = validate("Intent", tagged);
var label = match asVariant("Intent", checked.data) {
    case Search(q): "search " + q;
    case Buy(sku, qty): "buy " + sku + " x " + qty;
    case Help(): "help";
};
print(label);

See Examples/Basics/as_variant.malda and docs/llm/few-shot/25_as_variant.malda.

13.7.1.2 evalPrompt(prompt, fixture, typeName?)

Offline fixture in/out on a PromptInstance. Does not call an LLM, consume @budget, or run a gather tool round. The fixture is a dict/object or an LLM-shaped JSON string (markdown fences and a surrounding { … } extract the same way await does). The result shape matches validate:

  • On success: { ok: true, data } — data is what await prompt … -> Type would have returned (object for a schema, variant for a sum type, program value for program(Api)).
  • On extract / parse / schema failure: { ok: false, error }. There is no repair loop.

The type comes from the instance’s declared -> Type (instance.returnType), including Mode C gather: instances that have not attached response_format yet. Pass optional typeName to override. instance.eval(fixture, typeName?) is the same helper. Pipe-friendly: p |> evalPrompt(fixture).

schema Card {
    name: string;
}

prompt extract(raw) -> Card {
    user: raw;
}

var p = extract("Ada Lovelace");
var checked = evalPrompt(p, dict { "name": "Ada" });
if (checked.ok) {
    print(checked.data.name);
}

13.8.0 Embedded folders (embed:)

Compile with malda compile … --embed-folder <dir[=alias]> to pack a directory into the executable as assembly resources. At runtime, read those files with the virtual scheme embed:<alias>/<relative> — nothing is extracted to disk. Writes (writeFile, ensureDir, …) reject embed: paths.

if (io.hasEmbeddedFolder("secondbrain")) {
    var root = io.embeddedFolderRoot("secondbrain");   // "embed:secondbrain"
    var catalog = io.readFile(io.pathJoin(root, "brain.json"));
    var entries = io.listDirectory(root);
}

hasEmbeddedFolder(alias) returns whether that alias was embedded. embeddedFolderRoot(alias) returns embed:<alias>, or null when the alias is missing. Agent tools such as createReadFileTool, createGrepTool, and createListDirectoryTool accept an embed:<alias> working directory.

13.8.2 Searching Files: glob and grep

glob finds paths by pattern, and grep searches file contents. Both take a required argument first and then a series of optional, positional arguments.

glob(pattern, dirPath?, maxResults?, includeDirectories?, excludeDirs?, workingDirectory?)
  • dirPath defaults to ".", maxResults to 200 (capped at 500), includeDirectories to false, and the two remaining string arguments to "".
  • On success it returns an object { items, count, truncated }, where each item is { name, type, path } and truncated reports whether the result hit maxResults.
var found = glob("**/*.malda", "Examples");
print(found.count);
print(found.truncated);

var first = found.items[0];
print(first.path + " (" + first.type + ")");
grep(pattern, filePath, useRegex?, caseInsensitive?, includeLineNumbers?, contextLines?, countOnly?, recursive?, workingDirectory?)
  • Defaults: useRegex false, caseInsensitive false, includeLineNumbers true, contextLines 3, countOnly false, recursive true.
  • Normally returns an array of matches shaped { filePath, content, lineNumber, contextBefore, contextAfter }. With countOnly set it returns { count, filesSearched } instead.
  • Files that cannot be read are skipped silently.
var matches = grep("function ", "Examples");
for (var m in matches) {
    print(m.filePath + ":" + m.lineNumber + " " + m.content);
}

var summary = grep("TODO", "Examples", false, true, true, 0, true);
print(summary.count + " hits in " + summary.filesSearched + " files");
Errors are returned as strings: when the path does not exist, or a regular expression is invalid, glob and grep return an error message instead of their normal result. Guard with typeOf(result) == "string" before treating the value as a collection. 
var result = grep("needle", "does-not-exist");
if (typeOf(result) == "string") {
    print("search failed: " + result);
}

13.11.1 getSymbols(sourceOrFilePath)

Parses MALDA code and extracts structured symbol information (classes, functions, actors, prompts) with line numbers and signatures. Accepts one string argument: a file path to a .malda file or MALDA source code. If the string looks like a file path (contains path separators or ends with .malda) and the file exists, the file is read and its content is parsed; otherwise the argument is treated as source code. Path traversal (.., ~) is rejected. Returns an object with classes, functions, actors, prompts, imports, and parseErrors (all arrays). Each class/actor has name, line, column, members; each function has name, line, column, parameters, signature; each prompt has name, line, column, parameters, returnType?, signature. Each import has file?, resolvedPath?, package?, alias?; unresolved modules are not flagged here (use checkMalda, whose malda-import warning names the missing path). Parse errors have line, column, message.

var sym = getSymbols("Examples/OOP/classes_objects.malda");   // From file
var sym2 = getSymbols("function f() { } class C { }");        // From source
// sym.classes, sym.functions, sym.actors, sym.prompts, sym.imports, sym.parseErrors

13.11.2 getParseErrors(sourceOrFilePath)

Parses MALDA code and returns only parse errors (no execution). Accepts the same argument as getSymbols: file path or source string. Path resolution and security checks are the same. Returns { parseErrors: [{ line, column, message }, ...] }. Use to validate syntax without running or compiling.

var errs = getParseErrors("var x = ;");   // Invalid: empty rhs
// errs.parseErrors is non-empty with line, column, message
var ok = getParseErrors("var x = 1;");   // Valid: parseErrors is []

13.11.3 checkMalda(sourceOrFilePath, typeMode?, workingDir?)

Diagnoses MALDA code with the same LanguageService diagnostics as malda check --json (parser, types, schema/sum-type names, interpolation). Does not execute the program. Accepts a file path or inline source (same path heuristic as getParseErrors). Optional typeMode is default (IDE: type mismatches are errors), strict (full CLI suite), or lenient (type mismatches as warnings). Returns { ok, executed: false, file, errorCount, warningCount, infoCount, error?, diagnostics }. Each diagnostic has severity, code, message, file?, line, column (1-based), length, hint?, suggestedFix?. The agent factory is createCheckMaldaTool.

var report = checkMalda("var x = 1;");
print(report.ok);          // true
var typed = checkMalda("var n: int = \"abc\";", "lenient");
print(typed.ok);           // true (mismatch is a warning)
Command Execution Safety: The runCommand function includes comprehensive safety checks:
  • Dangerous commands are blocked (e.g., rm, del, format, shutdown, powershell, cmd, etc.)
  • Working directory is validated and normalized to prevent path traversal
  • Maximum timeout limit of 1 hour (3,600,000ms) to prevent indefinite waits
  • Command paths are validated for absolute paths
  • Path traversal attempts (.., ~) are detected and blocked

13.12 Spectre.Console Integration

MALDA exposes a global AnsiConsole object that wraps the .NET Spectre.Console library and provides rich console output:

// Markup (colors, bold, links, etc.)
AnsiConsole.markupLine("[green]Hello[/] [bold red]Spectre.Console[/]!");   // Appends a newline
AnsiConsole.markup("[dim]no newline, [/]");                                // Stays on the same line
AnsiConsole.markupLine("[cyan]rest of the line[/]");

// Tables
var rows = [
    {"Name": "Alice", "Score": 95},
    {"Name": "Bob", "Score": 88}
];
AnsiConsole.table(rows, "Scores");

// Panels (body and title accept markup)
AnsiConsole.panel("[bold]Important[/] message", "Info", "rounded");

// Trees
var treeData = {
    "root": "Project",
    "children": [
        {"label": "src"},
        {"label": "tests"}
    ]
};
AnsiConsole.tree("Project", treeData);

// Status
AnsiConsole.status("Processing...", () => {
    // Long-running work here
});

// Prompt (configuration object)
AnsiConsole.prompt({
    "type": "text",
    "message": "Enter your name"
});

// Progress - New callback-based syntax (recommended)
AnsiConsole.progress((ctx) => {
    ctx.addTask("Loading World Map", 100);
    
    while (!ctx.isFinished()) {
        ctx.increment("Loading World Map", 1.5);
        sleep(50);
    }
});

// Progress - Object-based syntax (legacy)
AnsiConsole.progress({
    "tasks": [
        {"name": "Task 1", "maxValue": 100}
    ],
    "action": (progressObj) => {
        var current = 0;
        while (current < 100) {
            current = current + 10;
            // Update progress by setting the value
            progressObj["Task 1"] = current;
            sleep(50);
        }
    }
});
Markup and Line Endings:
  • AnsiConsole.markupLine(text) writes the text and appends a newline. It is the right call for a standalone line of output.
  • AnsiConsole.markup(text) writes the text with no trailing newline, so consecutive calls run together on one line. Use it to compose a line from several styled fragments, then close the line with markupLine.
  • Both parse markup tags such as [bold], [green] and [/]. To print a literal bracket, double it: [[ and ]].
  • AnsiConsole.panel(body, title?, border?) parses markup in both the body and the title. Content that is not valid markup — arbitrary JSON, code, or error text containing brackets — is rendered literally instead of raising an error.
Progress API:
  • Callback-based syntax: Pass a function that receives a context object with methods:
    • ctx.addTask(name, maxValue) - Add a progress task
    • ctx.increment(taskName, value) - Increment a task's progress by the given value
    • ctx.isFinished() - Check if all tasks are finished
  • Object-based syntax: Pass an object with a tasks array and an action callback. The callback receives a progress object where you can read and update progress values by setting properties: progressObj["Task Name"] = value
Where Spectre.Console Renders:
  • Command-line interpreter: When you run malda in a real terminal, MALDA configures UTF-8 and enables ANSI escape sequences on supported Windows consoles so Spectre.Console markup renders with full colors and styling.
  • Transpiled executables: Generated C# executables enable ANSI escape sequences at startup on Windows, so AnsiConsole.* calls render correctly in compatible terminals.
  • Desktop IDE: The IDE output panel is plain text. On first use of AnsiConsole, MALDA automatically opens a separate console window and routes output to both the IDE panel (plain text) and the console (rich Spectre.Console rendering).

13.19.1 result and option

Prefer these modules when a function should report success or absence without throwing. They return variants with tags Ok/Err and Some/None — the same shape as a type Result = Ok(value) | Err(message) declaration, but you do not need to declare the type. The module names are lowercase (result, option); a user-declared type Result is a different name.

Use try/catch for unexpected failures (see 8. Control Structures). Use result/option for expected outcomes in the return value.

function parseAge(raw) {
    var n = toIntOrNull(raw);
    if (n == null) {
        return result.err("not an int");
    }
    return result.ok(n);
}

print(result.unwrapOr(parseAge("12"), 0));
print(result.isErr(parseAge("x")));

var present = option.some("hi");
var missing = option.none();
print(option.unwrapOr(present, "no"));
print(option.isNone(missing));
  • result.ok(value) / result.err(value) — construct an Ok or Err variant
  • result.isOk(r) / result.isErr(r) — tag tests
  • result.unwrapOr(r, fallback) — payload of Ok, otherwise fallback
  • result.map(r, fn) — apply fn to an Ok payload; leave Err unchanged
  • result.andThen(r, fn) — if Ok, call fn(payload) and return that Result; if Err, skip fn. fn must return Ok/Err (use map to transform a bare payload)
  • option.some(value) / option.none() — construct a Some or None variant
  • option.isSome(o) / option.isNone(o) / option.unwrapOr(o, fallback) / option.map(o, fn) / option.andThen(o, fn) — the same pattern for optional values
function parseAge(raw) {
    var n = toIntOrNull(raw);
    if (n == null) {
        return result.err("not an int");
    }
    return result.ok(n);
}
function doubleAge(n) {
    return result.ok(n * 2);
}
print(result.unwrapOr(parseAge("12") |> result.andThen(doubleAge), 0));
print(result.isErr(parseAge("x") |> result.andThen(doubleAge)));

Do not treat type hints (var n: int = …) as runtime validation. For JSON-shaped payloads use schema and validate(). Tutorial: errors, Result/Option, and schema validate.

  • Each citation is { source, id?, span? }. A string citation becomes { source }. There is no flat grounded() alias.
  • GraphMemory opt-in ASK: memory.ask(query, maxResults?, options?) (or query(..., { grounded: true })) wraps hits with citations from filePath / source / nodeId. Plain query() still returns an array. See 20. GraphMemory §20.3.15.

13.19.3 cap.fileRead

This subsection is the signature catalog. If you have not used tokens before, start with the how-to in 12.6 Capability tokens — why they exist, the key analogy, cap.confine, and the host-mint pattern for tools.

A token is a sealed host object with kind and path (and name for an MCP tool). JSON and object literals cannot rehydrate one. @effects("io") only names the effect; it does not bind a path, URL, tool, or argv.

var notes = cap.fileRead("notes.md");
print(notes.kind);
print(cap.is(notes, "fileRead"));
var forged = false;
try {
    cap.read({ "kind": "fileRead", "path": "notes.md" });
} catch (e) {
    forged = true;
}
print(forged);
  • cap.fileRead(path) / cap.fileWrite(path) / cap.dirList(path) / cap.httpGet(origin) / cap.mcpCall(server, tool?) / cap.shell(prefix) — mint a token. There is no flat cap() alias.
  • cap.read(token, startLine?, endLine?) / cap.write(token, content) / cap.list(token) / cap.fetch(token, urlOrPath?, maxBytes?, timeoutMs?) / cap.invoke(token, server, args?) / cap.run(token, extraArgs?, workingDir?, timeout?) — consume a matching kind only. Strings and { kind, path } dicts throw. Wrong-origin / wrong-tool / .. / absolute extras throw before HTTP, MCP, or process start.
  • cap.is(value, kind?) — true only for a real token. Omit kind to accept any token kind.
  • cap.confine(token, relative) — same kind, narrower path / URL prefix / MCP tool / argv prefix; values outside the parent throw.
  • io.readFile / io.writeFile / io.listDirectory / webFetch / callTool / runCommand also accept a matching token. Ordinary strings still work for non-tool code. createWebFetchTool(httpCap?) / createRunCommandTool(workingDir?, shellCap?) bind a token so model-supplied URLs / commands stay under it.
  • Mark handlers that mint or consume tokens @effects("cap") (or list both "io" and "cap"). JavaScript can mint / is / confine; consume is host-only.
  • Do not pass a token through LLM JSON. Host-mint a workspace root and cap.confine a relative path / URL / tool / extra argv from tool args. Scaffold: malda new agent.
  • Examples: Examples/Tools/capability_tokens.malda, Examples/Tools/capability_http_mcp_shell.malda.

AgentError = Refused(reason) | Unparsable(raw, attempts) | SchemaMismatch(schema, error)
           | BudgetExceeded(kind, limit) | ToolDenied(tool, reason) | Timeout(ms)
           | Upstream(status, body)
