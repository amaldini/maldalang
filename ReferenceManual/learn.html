Learn MALDA

A short course through the core language. Each lesson is one idea, one runnable file, and one chapter section. The numbered chapters stay the reference; this page is the spine.

The same order is Desktop Start With MALDA, the Web IDE student track, and Start Here.

How to run a file

The interpreter is the default. From the repo root:

malda Examples/Basics/hello_world.malda

That prints Hello, World! and exits. You do not need compile, an API key, or a project scaffold for this path. Diagnose without running with malda check. Editors: Desktop IDE is the Windows reference; Web IDE is a browser playground (not Desktop parity); VS Code + LSP is the cross-platform editor. The full command index is 2. Tools & Tooling.

Prefer namespaced calls (io.print, math.sqrt, str.upper). Flat print still runs.

Lesson 0 — First Look (optional)

If you already program, start here. -> Review binds the prompt to the schema. Without await, the call is a rendered template (no API key). validate("Review", …) is the same check await would run on the model JSON. Schema syntax: 4.6. Same file: Examples/Basics/first_look.malda.

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}
Try this: Change the validated summary to "Needs work" and re-run. What is the last printed line?
Answer

schema ok: Needs work

Lesson 2 — Variables and arithmetic

var declares a binding. The type comes from the value. Chapter: 5.1 Variable declaration. Same file: Examples/Basics/variables_arithmetic.malda.

var x = 10;
var y = 20;
var sum = x + y;
var product = x * y;
io.print($"Sum: {sum}");
io.print($"Product: {product}");
Try this: Change 10 to 7 and re-run. What is the new sum?
Answer

27 (7 + 20).

Lesson 3 — Conditionals

if / else if / else choose a branch. Chapter: 8.1 Conditional statements. Same file: Examples/Basics/conditionals.malda.

var age = 18;
if (age >= 18) {
    io.print("You are an adult");
} else {
    io.print("You are a minor");
}

var score = 85;
if (score >= 90) {
    io.print("Grade: A");
} else if (score >= 80) {
    io.print("Grade: B");
} else if (score >= 70) {
    io.print("Grade: C");
} else {
    io.print("Grade: F");
}
Try this: Change age to 16. What prints first?
Answer

You are a minor

Lesson 4 — While loop

A while loop repeats while the condition is true. Update the loop variable yourself. Chapter: 8.2 While. Same file: Examples/Basics/while_loop.malda.

var i = 1;
while (i <= 10) {
    io.print($"Count: {i}");
    i = i + 1;
}
io.print("Done!");
Try this: Change the loop to stop at 5. How many Count: lines print?
Answer

Five lines: Count: 1 through Count: 5.

Lesson 5 — For loop

A C-style for packs init, condition, and increment. Chapter: 8.2 For. Same file: Examples/Basics/for_loop.malda.

for (var i = 1; i <= 10; i = i + 1) {
    io.print($"Number: {i}");
}
io.print("Loop finished!");
Try this: Change the loop to start at 5. What is the first Number: line?
Answer

Number: 5

Lesson 6 — Functions

The only function keyword is function. fn and def are syntax errors. Chapter: 9.1 Function declaration. Same file: Examples/Basics/functions.malda.

function add(a, b) {
    return a + b;
}

var result1 = add(5, 3);
io.print($"5 + 3 = {result1}");

var result2 = add(10, 2);
io.print($"10 + 2 = {result2}");
Try this: Add io.print(add(1, 1)); after the existing prints. What is the last line?
Answer

2

Lesson 7 — Complete starter

Variables, a for-in loop, a function, and an if in one linear program. Catalog note: 34.1. Same file: Examples/Basics/complete_starter_program.malda.

var cart = [12, 18, 7];
var total = 0;

for (var item in cart) {
    total = total + item;
}

function describeTotal(amount) {
    if (amount >= 30) {
        return "big order";
    }

    return "small order";
}

io.print($"Items: {cart.length}");
io.print($"Total: {total}");
io.print($"Summary: {describeTotal(total)}");
Try this: Change the last cart item from 7 to 4. Is it still a big order?
Answer

Yes. The total becomes 34, which is still >= 30.

Try this: Keep the original cart and change the threshold from 30 to 40. What is the summary?
Answer

small order (37 is below 40).

Lesson 8 — Input

io.input reads one line from stdin and always returns a string. Convert it if you need a number. This snippet waits for a keyboard, so it is not marked runnable here. Chapter: 12.2 Console input. Same file: Examples/Basics/input_example.malda.

var name = io.input("Enter your name: ");
var ageStr = io.input("Enter your age: ");
var age = int(ageStr);
io.print($"Hello, {name}. You are {age} years old.");

At end of input every later io.input returns "", not null. Prefer toIntOr(raw, fallback) over bare int(...) when the line may be blank.

Try this: What does every later io.input return at end of file?
Answer

An empty string "", not null.

Lesson 9 — Lists and indexing

Arrays are zero-indexed and grow with append. A counted for walks indexes; for-in walks values. Chapter: 6. Arrays. Same file: Examples/Basics/lists_indexing.malda.

var scores = [88, 92, 75];
io.print("first=" + string(scores[0]));
io.print("length=" + string(scores.length));

scores.append(80);
io.print("after append length=" + string(scores.length));

var last = scores.pop();
io.print("popped=" + string(last));
io.print("length after pop=" + string(scores.length));

var total = 0;
for (var i = 0; i < scores.length; i = i + 1) {
    io.print("scores[" + string(i) + "]=" + string(scores[i]));
    total = total + scores[i];
}

var walked = 0;
for (var score in scores) {
    walked = walked + 1;
}

io.print("sum=" + string(total));
io.print("for-in count=" + string(walked));
io.print("lists ok");
Try this: After the existing append, append another score 100 and do not pop it. What is the new printed sum?
Answer

355 (88 + 92 + 75 + 100). The original file pops the appended 80 before summing.

Lesson 10 — Dictionaries

A dict maps string keys to values. Index to read or write; containsKey, keys, and values inspect the map. Chapter: 4.4 Dictionaries. Same file: Examples/Basics/dictionary_example.malda.

var d = dict { "a": 1, "b": 2 };
io.print("a = " + d["a"]);
io.print("b = " + d["b"]);

d["c"] = 3;
io.print("c = " + d["c"]);

io.print("has b: " + d.containsKey("b"));
io.print("has missing: " + d.containsKey("missing"));

var keys = d.keys();
var values = d.values();

io.print("keys length: " + keys.length);
io.print("values length: " + values.length);
Try this: Add d["d"] = 4; and print it. What is keys.length after that?
Answer

4

Lesson 11 — Recursion

A function may call itself. Write a base case that stops, then a smaller argument. Chapter: 9.4 Recursion. Same file: Examples/Basics/recursion.malda.

function factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

function countdown(n) {
    if (n <= 0) {
        io.print("liftoff");
        return 0;
    }
    io.print(n);
    return countdown(n - 1);
}

io.print("factorial(5)=" + string(factorial(5)));
io.print("countdown from 3:");
countdown(3);
io.print("recursion ok");
Try this: Print factorial(7). What is the value?
Answer

5040

Lesson 12 — Classes

A class is a named type with fields and methods. new ClassName(...) runs the constructor. Chapter: 11.1 A working class. Same file: Examples/Basics/classes_intro.malda.

class Person {
    public var name;
    public var age;

    function Person(name, age) {
        this.name = name;
        this.age = age;
    }

    public function introduce() {
        io.print("Hi, I'm " + name + " and I'm " + string(age) + " years old.");
    }
}

var alice = new Person("Alice", 30);
alice.introduce();
io.print("age=" + string(alice.age));
Try this: Construct a second person new Person("Bob", 25) and call introduce(). What is the new last introduce line?
Answer

Hi, I'm Bob and I'm 25 years old.

Lesson 13 — try / catch

try runs code that may fail. catch handles the thrown value. finally always runs. Chapter: 8.4 Exception handling. Same file: Examples/Basics/try_catch.malda.

try {
    throw "something went wrong";
} catch (error) {
    io.print("caught: " + error);
}

try {
    io.print("in try");
} catch (error) {
    io.print("caught: " + error);
} finally {
    io.print("cleanup");
}
Try this: Change the thrown string to "disk full". What is the first printed line?
Answer

caught: disk full

Lesson 14 — Prompt as a template

A prompt is a callable template. Without await it does not call a model. Chapter: 10.1 Overview step 1. Same file: Examples/Basics/prompt_template.malda.

prompt greet(name) {
    user: "Hello, {name}! How are you today?"
}

var greeting = greet("Alice");
io.print(greeting.user);
Try this: Call greet("MALDA") instead. What prints?
Answer

Hello, MALDA! How are you today?

Lesson 15 — Mini project

A class, a try, and offline schema + validate in one linear program. Catalog note: 34.1. Same file: Examples/Basics/gradebook.malda.

schema Score {
    name: string;
    points: int;
}

class Grade {
    public var name;
    public var points;

    function Grade(name, points) {
        this.name = name;
        this.points = points;
    }

    public function label() {
        if (points >= 90) {
            return "A";
        }

        return "B";
    }
}

var ada = new Grade("Ada", 92);
io.print(ada.name + ": " + ada.label());

try {
    int("not-a-number");
} catch (error) {
    io.print("caught bad score");
}

var checked = validate("Score", {
    "name": "Ada",
    "points": 92
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.name);
} else {
    io.print("schema failed: " + checked.error);
}
Try this: Change Ada's points from 92 to 88. What is the first printed line?
Answer

Ada: B
