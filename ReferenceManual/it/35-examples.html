35.0 First Look

Costrutti caratteristici, senza API key. Stesso programma di Examples/Basics/first_look.malda e del Quick Start in Indice. -> Review lega il prompt allo schema. Senza await la chiamata è un template reso; validate("Review", …) è lo stesso controllo che await eseguirebbe sul JSON del modello. Sintassi dello schema: 4.6.

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}

35.3 Game

Solo target JavaScript. Anteprima con malda play app.malda (reload live salvo --no-watch). Canvas / three.* / @shader() restano in 28. Stesso paddle di Examples/Games/game_bounce.malda:

var x = 100;
var speed = 220;

function update(dtMs) {
    var step = (speed * dtMs) / 1000;
    if (game.isKeyDown("arrowleft")) {
        x = x - step;
    }
    if (game.isKeyDown("arrowright")) {
        x = x + step;
    }
}

function render() {
    game.clear();
    game.fillRect(x, 140, 40, 40, "#33cc66");
    game.drawText("Use arrows", 10, 24, "#ffffff", "14px monospace");
}

game.createCanvas(640, 360, "#app");
game.setBackground("#202830");
game.start(update, render);

Crea il canvas prima di disegnare. Scala il movimento con dtMs. Carica malda-js-runtime.js prima dello script compilato. Biliardo GPU giocabile: 39.

35.6 Scaffolding

Indice CLI: 2.0. Flusso full-stack: 31.

malda new webapi my-api
malda new fullstack my-app
malda new game my-game
malda new game my-scores --fullstack
malda new agent my-agent
malda new webapi my-api --name SalesPortal
malda new fullstack . --force
malda new webapi api-lite --no-tests

Gli starter generati includono le convenzioni di default di malda test e placeholder di config. Il passo successivo del template game è malda play app.malda. malda new game --fullstack è un'API punteggi compilata con --mode fullstack, non malda play. Il template agent è offline e cap-confined; il passo successivo è malda app.malda.
