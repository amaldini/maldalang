9. Funzioni

9.1 Dichiarazione di funzione

function functionName(param1, param2) {
    // function body
    return value;  // optional
}

Per le funzioni che consistono in una sola espressione, puoi omettere le graffe e usare un punto e virgola:

function square(x) x*x;
function double(n) -> int n * 2;

È equivalente a function square(x) { return x*x; }.

L'unica keyword per le funzioni è function. fn e def sono errori di sintassi (alias rimossi).

Puoi aggiungere in modo opzionale type hint informativi ai parametri e un tipo di ritorno. Non sono applicati a tempo di interpretazione, a meno che non si passi il flag CLI --strict-types. malda compile --mode transpile / publish rifiutano l'emit quando l'analisi riporta Error (--lenient-types salta il gate). I nomi noti includono i primitivi Tier 0, i nomi di class/schema/sum-type dichiarati (compresi quelli importati da altri moduli) e le classi host built-in. Le incongruenze su letterali, new ClassName(), identificatori con type hint noti, argomenti delle chiamate, return rispetto a -> T e i risultati delle chiamate il cui callee dichiara un type hint di ritorno producono di default un Error IDE/LSP. I tipi di ritorno di operatori e built-in non vengono inferiti. I type hint sono usati anche da tool (es. getSymbols), IDE e documentazione.

function name(param: Type?, ...) -> ReturnType? {
    // param and return type hints are optional and informational only
}

Esempio:

function greet(name: string) -> string {
    return "Hello, " + name;
}
function add(a: int, b: int) -> int {
    return a + b;
}

9.2 Chiamata di funzione

var result = functionName(arg1, arg2);
functionName();  // No return value needed

9.3 Istruzione return

Le istruzioni return sono opzionali nelle funzioni MALDA. Una funzione può:

  • Avere return value; - restituisce il valore specificato
  • Non avere istruzione return - vale l'ultima espressione: se l'ultima istruzione è un'espressione, il suo valore viene restituito in modo implicito; altrimenti restituisce null
  • Avere return; - restituisce esplicitamente null

Questo vale per funzioni, metodi e lambda (ma non per i costruttori). La stessa regola vale per i corpi dei case di match quando il match è usato come espressione (vedi 8. Strutture di controllo).

Esempi

// Function with explicit return
function add(a, b) {
    return a + b;
}

// Last expression wins: no explicit return needed
function process(x) {
    var doubled = x * 2;
    doubled + 1;   // implicitly returned
}
print(process(5));  // Prints 11

// Function without return (last statement is not an expression)
function printMessage(msg) {
    print(msg);
    // No return - function returns null
}

// Function with explicit null return
function logInfo(message) {
    print("Info: " + message);
    return;  // Explicitly return null
}

// Function that may or may not return a value
function findValue(arr, target) {
    var i = 0;
    while (i < length(arr)) {
        if (arr[i] == target) {
            return i;  // Return index if found
        }
        i = i + 1;
    }
    // No return statement - returns null if not found
}

Uso dei valori di ritorno

Quando chiami una funzione, puoi:

  • Ignorare il valore di ritorno: printMessage("Hello");
  • Catturare il valore di ritorno: var sum = add(5, 3);
  • Usare il valore di ritorno in un'espressione: print("Sum: " + add(5, 3));
Nota: Con vale l'ultima espressione, una funzione che termina con un'espressione restituisce quel valore anche senza return. Solo quando l'ultima istruzione non è un'espressione (es. print(...)) la funzione restituisce null. Puoi controllare il null con result == null oppure usare il valore di ritorno in espressioni condizionali.

9.4 Ricorsione

Le funzioni possono chiamare se stesse in modo ricorsivo:

function factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

9.5 Funzioni autonome e metodi

  • Le funzioni autonome (definite fuori dalle classi) sono funzioni globali
  • I metodi sono funzioni definite all'interno delle classi
  • Entrambi usano la stessa sintassi, ma i metodi hanno accesso a this

9.6 Espressioni lambda

MALDA supporta le espressioni lambda (funzioni anonime) con la sintassi arrow function. Le lambda sono valori first-class: si possono assegnare a variabili, passare come argomenti e restituire dalle funzioni.

Corpo espressione

Le lambda con una sola espressione restituiscono automaticamente quella espressione:

var add = (a, b) => a + b;
var square = x => x * x;
var getValue = () => 42;
print(add(2, 3));
print(square(3));
print(getValue());

Corpo a blocco

Le lambda con più istruzioni usano le graffe. Puoi usare un return esplicito, oppure affidarti a vale l'ultima espressione: se l'ultima istruzione è un'espressione, il suo valore viene restituito in modo implicito.

var process = (x) => {
    var result = x * 2;
    return result + 1;
};

// Last expression wins: no explicit return needed
var process2 = (x) => {
    print("processing " + x);
    x * 2;   // implicitly returned
};
print(process2(5));  // Prints "processing 5" then 10

Cattura nelle closure

Le lambda catturano le variabili dallo scope circostante, e così abilitano pattern di programmazione funzionale:

function makeMultiplier(factor) {
    return (x) => x * factor;  // Captures 'factor' in closure
}

var double = makeMultiplier(2);
print(double(5));  // Prints 10

var triple = makeMultiplier(3);
print(triple(4));  // Prints 12

Esempi d'uso

// Assign to variable
var comparator = (a, b) => a < b;

// Pass as argument to functions that accept callbacks
function transformArray(arr, transformer) {
    var result = [];
    for (var i = 0; i < arr.length; i = i + 1) {
        result.append(transformer(arr[i]));
    }
    return result;
}

var numbers = [1, 2, 3, 4];
var doubled = transformArray(numbers, (x) => x * 2);
var squared = transformArray(numbers, (x) => x * x);
print(doubled);  // [2, 4, 6, 8]
print(squared);  // [1, 4, 9, 16]

// Return from function
function createAdder(n) {
    return (x) => x + n;
}

var addFive = createAdder(5);
print(addFive(10));  // Prints 15
Nota: Le lambda non hanno un proprio contesto this. Se ti serve il binding di this, usa una funzione o un metodo normale.

9.7 Decoratori

MALDA supporta i decoratori sulle funzioni, per funzionalità come tool personalizzati ed endpoint REST API:

@within e @budget

Usa @within(ms) per una scadenza a orologio reale su un corpo di funzione o su un turno await prompt(...) / agent.think(). Usa @budget(tokens: N, tools: N, cost: N?) per i limiti di risorse sulle stesse dichiarazioni. Non sovraccaricare l'argomento posizionale in millisecondi di @within — le chiavi di budget sono nominate. Le chiavi @budget sconosciute sono errori sotto il flag CLI --strict-types (malda-bounds), con la stessa strictness di @within.

@within(5000)
@budget(tokens: 4000, tools: 8)
prompt answer(q) -> Answer {
    user: "Question: {q}"
}
  • tokens — prompt+completion quando il backend riporta l'usage; altrimenti un conteggio best-effort ceil(chars / 4). Abort, non trim del contesto.
  • tools — numero di invocazioni in quel turno prompt/agente, non la lunghezza dell'allow-list tools: / gather:.
  • cost — opzionale; applicato solo quando il backend espone già il costo di usage. Ometti la chiave se non la usi.

MALDA_AGENT_CONTEXT_BUDGET_TOKENS continua a fare trim del contesto agente non dichiarato. Non è una seconda API di abort; dichiara @budget quando vuoi un bound rigido. Vedi Examples/Prompts/prompt_budget.malda. I bound specifici dei prompt sono nel resto della superficie prompt in 10. Prompt.

@pure e @effects

Usa @pure() sugli helper che non devono fare I/O. Usa @effects("print", …) per dichiarare un allow-list di side effect su un handler. Vengono controllati sotto il flag CLI --strict-types / analisi strict completa (malda-pure / malda-effects). Preferisci validate() sui payload a forma di tool o LLM prima del lavoro impuro — vedi Examples/Agents/agent_governance_golden.malda e 18. Orchestrazione di agenti. @effects("io") è un allow-list di nomi e non impedisce a un tool di inventare un path; passa invece un token cap.fileRead all'handler.

@pure()
function normalizeName(name) {
    return upper(trim(name));
}

@effects("print")
function handleToolArgs(raw) {
    var check = validate("ToolInput", raw);
    if (!check.ok) {
        print("invalid: " + check.error);
        return;
    }
    print(normalizeName(check.data.name));
}

Decoratore @Tool

Questo è il decoratore sulla funzione. Come gli agenti chiamano i tool è in 18. Orchestrazione di agenti.

@Tool("tool_name", "Tool description")
function myTool(param1, param2) {
    return param1 + param2;
}

Decoratori REST API

Routing, middleware e un server completo sono in 27. Server REST API.

@GET("/api/users")
function getUsers() {
    return [{"id": 1, "name": "Alice"}];
}

@POST("/api/users")
function createUser(body) {
    return {"id": 2, "name": body.name};
}
