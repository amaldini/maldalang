Imparare MALDA

Un corso breve sul linguaggio core. Ogni lezione è un'idea, un file eseguibile e una sezione di capitolo. I capitoli numerati restano il riferimento; questa pagina è la spina dorsale.

Lo stesso ordine è Start With MALDA nel Desktop, il percorso student della Web IDE e Start Here.

Come eseguire un file

L'interprete è il default. Dalla root del repository:

malda Examples/Basics/hello_world.malda

Stampa Hello, World! e termina. Per questo percorso non servono compile, una API key o uno scaffold di progetto. Diagnostica senza eseguire con malda check. Editor: il Desktop IDE è il riferimento Windows; la Web IDE è un playground nel browser (non ha la parità con il Desktop); VS Code + LSP è l'editor cross-platform. L'indice completo dei comandi è 2. Strumenti e toolchain.

Preferisci le chiamate con namespace (io.print, math.sqrt, str.upper). Il print piatto continua a funzionare.

Lezione 0 — First Look (opzionale)

Se programmi già, parti da qui. -> Review lega il prompt allo schema. Senza await la chiamata è un template reso (niente API key). validate("Review", …) è lo stesso controllo che await eseguirebbe sul JSON del modello. Sintassi dello schema: 4.6. Stesso file: Examples/Basics/first_look.malda.

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}
Prova così: Cambia lo summary validato in "Needs work" e rilancia. Qual è l'ultima riga stampata?
Risposta

schema ok: Needs work

Lezione 1 — Hello World

Una chiamata scrive una riga. Capitolo: 12.1 Output sulla console. Stesso file: Examples/Basics/hello_world.malda.

io.print("Hello, World!");
Prova così: Cambia la stringa in "Hello, MALDA!" e rilancia.
Risposta

Il programma stampa Hello, MALDA! e termina.

Lezione 2 — Variabili e aritmetica

var dichiara un binding. Il tipo arriva dal valore. Capitolo: 5.1 Dichiarazione di variabili. Stesso file: Examples/Basics/variables_arithmetic.malda.

var x = 10;
var y = 20;
var sum = x + y;
var product = x * y;
io.print($"Sum: {sum}");
io.print($"Product: {product}");
Prova così: Cambia 10 in 7 e rilancia. Qual è la nuova somma?
Risposta

27 (7 + 20).

Lezione 3 — Condizionali

if / else if / else scelgono un ramo. Capitolo: 8.1 Istruzioni condizionali. Stesso file: Examples/Basics/conditionals.malda.

var age = 18;
if (age >= 18) {
    io.print("You are an adult");
} else {
    io.print("You are a minor");
}

var score = 85;
if (score >= 90) {
    io.print("Grade: A");
} else if (score >= 80) {
    io.print("Grade: B");
} else if (score >= 70) {
    io.print("Grade: C");
} else {
    io.print("Grade: F");
}
Prova così: Cambia age in 16. Che cosa stampa per primo?
Risposta

You are a minor

Lezione 4 — Ciclo while

Un ciclo while si ripete finché la condizione è vera. Aggiorna tu la variabile di ciclo. Capitolo: 8.2 While. Stesso file: Examples/Basics/while_loop.malda.

var i = 1;
while (i <= 10) {
    io.print($"Count: {i}");
    i = i + 1;
}
io.print("Done!");
Prova così: Fai terminare il ciclo a 5. Quante righe Count: stampa?
Risposta

Cinque righe: Count: 1 fino a Count: 5.

Lezione 5 — Ciclo for

Un for in stile C raccoglie init, condizione e incremento. Capitolo: 8.2 For. Stesso file: Examples/Basics/for_loop.malda.

for (var i = 1; i <= 10; i = i + 1) {
    io.print($"Number: {i}");
}
io.print("Loop finished!");
Prova così: Fai partire il ciclo da 5. Qual è la prima riga Number:?
Risposta

Number: 5

Lezione 6 — Funzioni

L'unica keyword per le funzioni è function. fn e def sono errori di sintassi. Capitolo: 9.1 Dichiarazione di funzione. Stesso file: Examples/Basics/functions.malda.

function add(a, b) {
    return a + b;
}

var result1 = add(5, 3);
io.print($"5 + 3 = {result1}");

var result2 = add(10, 2);
io.print($"10 + 2 = {result2}");
Prova così: Aggiungi io.print(add(1, 1)); dopo le stampe esistenti. Qual è l'ultima riga?
Risposta

2

Lezione 7 — Starter completo

Variabili, un ciclo for-in, una funzione e un if in un programma lineare. Nota di catalogo: 34.1. Stesso file: Examples/Basics/complete_starter_program.malda.

var cart = [12, 18, 7];
var total = 0;

for (var item in cart) {
    total = total + item;
}

function describeTotal(amount) {
    if (amount >= 30) {
        return "big order";
    }

    return "small order";
}

io.print($"Items: {cart.length}");
io.print($"Total: {total}");
io.print($"Summary: {describeTotal(total)}");
Prova così: Cambia l'ultimo elemento del carrello da 7 a 4. È ancora un big order?
Risposta

Sì. Il totale diventa 34, che è ancora >= 30.

Prova così: Lascia il carrello originale e cambia la soglia da 30 a 40. Qual è il summary?
Risposta

small order (37 è sotto 40).

Lezione 8 — Input

io.input legge una riga da stdin e restituisce sempre una string. Convertila se ti serve un numero. Questo snippet aspetta la tastiera, quindi qui non è marcato eseguibile. Capitolo: 12.2 Input dalla console. Stesso file: Examples/Basics/input_example.malda.

var name = io.input("Enter your name: ");
var ageStr = io.input("Enter your age: ");
var age = int(ageStr);
io.print($"Hello, {name}. You are {age} years old.");

A fine input ogni io.input successivo restituisce "", non null. Preferisci toIntOr(raw, fallback) rispetto a un int(...) nudo quando la riga può essere vuota.

Prova così: Che cosa restituisce ogni io.input successivo a fine file?
Risposta

Una stringa vuota "", non null.

Lezione 9 — Liste e indicizzazione

Gli array sono indicizzati da zero e crescono con append. Un for contato percorre gli indici; for-in percorre i valori. Capitolo: 6. Array. Stesso file: Examples/Basics/lists_indexing.malda.

var scores = [88, 92, 75];
io.print("first=" + string(scores[0]));
io.print("length=" + string(scores.length));

scores.append(80);
io.print("after append length=" + string(scores.length));

var last = scores.pop();
io.print("popped=" + string(last));
io.print("length after pop=" + string(scores.length));

var total = 0;
for (var i = 0; i < scores.length; i = i + 1) {
    io.print("scores[" + string(i) + "]=" + string(scores[i]));
    total = total + scores[i];
}

var walked = 0;
for (var score in scores) {
    walked = walked + 1;
}

io.print("sum=" + string(total));
io.print("for-in count=" + string(walked));
io.print("lists ok");
Prova così: Dopo l'append esistente, aggiungi un altro punteggio 100 e non fare pop. Qual è la nuova somma stampata?
Risposta

355 (88 + 92 + 75 + 100). Il file originale fa pop dell'80 aggiunto prima di sommare.

Lezione 10 — Dizionari

Un dict associa chiavi stringa a valori. Indicizza per leggere o scrivere; containsKey, keys e values ispezionano la mappa. Capitolo: 4.4 Dizionari. Stesso file: Examples/Basics/dictionary_example.malda.

var d = dict { "a": 1, "b": 2 };
io.print("a = " + d["a"]);
io.print("b = " + d["b"]);

d["c"] = 3;
io.print("c = " + d["c"]);

io.print("has b: " + d.containsKey("b"));
io.print("has missing: " + d.containsKey("missing"));

var keys = d.keys();
var values = d.values();

io.print("keys length: " + keys.length);
io.print("values length: " + values.length);
Prova così: Aggiungi d["d"] = 4; e stampalo. Qual è keys.length dopo?
Risposta

4

Lezione 11 — Ricorsione

Una funzione può chiamare se stessa. Scrivi un caso base che si ferma, poi un argomento più piccolo. Capitolo: 9.4 Ricorsione. Stesso file: Examples/Basics/recursion.malda.

function factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

function countdown(n) {
    if (n <= 0) {
        io.print("liftoff");
        return 0;
    }
    io.print(n);
    return countdown(n - 1);
}

io.print("factorial(5)=" + string(factorial(5)));
io.print("countdown from 3:");
countdown(3);
io.print("recursion ok");
Prova così: Stampa factorial(7). Qual è il valore?
Risposta

5040

Lezione 12 — Classi

Una classe è un tipo con nome, campi e metodi. new ClassName(...) esegue il costruttore. Capitolo: 11.1 Una classe funzionante. Stesso file: Examples/Basics/classes_intro.malda.

class Person {
    public var name;
    public var age;

    function Person(name, age) {
        this.name = name;
        this.age = age;
    }

    public function introduce() {
        io.print("Hi, I'm " + name + " and I'm " + string(age) + " years old.");
    }
}

var alice = new Person("Alice", 30);
alice.introduce();
io.print("age=" + string(alice.age));
Prova così: Crea una seconda persona new Person("Bob", 25) e chiama introduce(). Qual è la nuova ultima riga di introduce?
Risposta

Hi, I'm Bob and I'm 25 years old.

Lezione 13 — try / catch

try esegue codice che può fallire. catch gestisce il valore lanciato. finally viene eseguito sempre. Capitolo: 8.4 Gestione delle eccezioni. Stesso file: Examples/Basics/try_catch.malda.

try {
    throw "something went wrong";
} catch (error) {
    io.print("caught: " + error);
}

try {
    io.print("in try");
} catch (error) {
    io.print("caught: " + error);
} finally {
    io.print("cleanup");
}
Prova così: Cambia la stringa lanciata in "disk full". Qual è la prima riga stampata?
Risposta

caught: disk full

Lezione 14 — Prompt come template

Un prompt è un template richiamabile. Senza await non chiama un modello. Capitolo: 10.1 Panoramica passo 1. Stesso file: Examples/Basics/prompt_template.malda.

prompt greet(name) {
    user: "Hello, {name}! How are you today?"
}

var greeting = greet("Alice");
io.print(greeting.user);
Prova così: Chiama greet("MALDA") al posto di Alice. Cosa stampa?
Risposta

Hello, MALDA! How are you today?

Lezione 15 — Mini progetto

Una classe, un try e schema + validate offline in un programma lineare. Nota di catalogo: 34.1. Stesso file: Examples/Basics/gradebook.malda.

schema Score {
    name: string;
    points: int;
}

class Grade {
    public var name;
    public var points;

    function Grade(name, points) {
        this.name = name;
        this.points = points;
    }

    public function label() {
        if (points >= 90) {
            return "A";
        }

        return "B";
    }
}

var ada = new Grade("Ada", 92);
io.print(ada.name + ": " + ada.label());

try {
    int("not-a-number");
} catch (error) {
    io.print("caught bad score");
}

var checked = validate("Score", {
    "name": "Ada",
    "points": 92
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.name);
} else {
    io.print("schema failed: " + checked.error);
}
Prova così: Cambia i punti di Ada da 92 a 88. Qual è la prima riga stampata?
Risposta

Ada: B
