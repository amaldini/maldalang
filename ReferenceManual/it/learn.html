Imparare MALDA

Un corso breve sul linguaggio core. Ogni lezione è un'idea, un file eseguibile e una sezione di capitolo. I capitoli numerati restano il riferimento; questa pagina è la spina dorsale.

Lo stesso ordine è Start With MALDA nel Desktop, il percorso student della Web IDE e Start Here.

Come eseguire un file

Come ottenere MALDA

Ti serve il comando malda, oppure un IDE che lo include già:

  • Zip di release — scarica da GitHub Releases (vedi il README in root, «Install without cloning»). Decomprimi ed esegui malda.bat (Windows) o ./malda (Linux). Opzionale: aggiungi bin/malda al PATH.
  • Dai sorgenti — clona questo repository, poi dalla root: dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda.
  • Senza installazione — Desktop Start With MALDA (Windows) o il playground della Web IDE (browser; non ha la parità con il Desktop).

L'interprete è il default. Dopo che malda è nel path, dalla root del repository:

malda Examples/Basics/hello_world.malda

Stampa Hello, World! e termina. Per questo percorso non servono compile, una API key o uno scaffold di progetto. Diagnostica senza eseguire con malda check. Editor: il Desktop IDE è il riferimento Windows; la Web IDE è un playground nel browser (non ha la parità con il Desktop); VS Code + LSP è l'editor cross-platform. L'indice completo dei comandi è 2. Strumenti e toolchain.

Preferisci le chiamate con namespace (io.print, math.sqrt, str.upper). Il print piatto continua a funzionare.

Lezione 0 — First Look (opzionale)

Se programmi già, parti da qui. -> Review lega il prompt allo schema. Senza await la chiamata è un template reso (niente API key). validate("Review", …) è lo stesso controllo che await eseguirebbe sul JSON del modello. Sintassi dello schema: 4.6. Stesso file: Examples/Basics/first_look.malda.

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}
Prova così: Cambia lo summary validato in "Needs work" e rilancia. Qual è l'ultima riga stampata?
Risposta

schema ok: Needs work

Scrivi questo: Dichiara schema Item { name: string; }. Valida { "name": "pen" }. Se ha successo, stampa schema ok: più il nome. Ultima riga: schema ok: pen.
Risposta 
schema Item {
    name: string;
}

var checked = validate("Item", {
    "name": "pen"
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.name);
} else {
    io.print("schema failed: " + checked.error);
}

Lezione 1 — Hello World

Una chiamata scrive una riga. Capitolo: 12.1 Output sulla console. Stesso file: Examples/Basics/hello_world.malda.

io.print("Hello, World!");
Prova così: Cambia la stringa in "Hello, MALDA!" e rilancia.
Risposta

Il programma stampa Hello, MALDA! e termina.

Scrivi questo: Stampa Good morning. sulla prima riga e Ready. sulla seconda. Ultima riga: Ready.
Risposta 
io.print("Good morning.");
io.print("Ready.");

Lezione 2 — Variabili e aritmetica

var dichiara un binding. Il tipo arriva dal valore. $"Sum: {sum}" inserisce l'espressione nella stringa; "Sum: " + string(sum) è lo stesso. Capitolo: 5.1 Dichiarazione di variabili. Stesso file: Examples/Basics/variables_arithmetic.malda.

var x = 10;
var y = 20;
var sum = x + y;
var product = x * y;
io.print($"Sum: {sum}");
io.print($"Product: {product}");
Prova così: Cambia 10 in 7 e rilancia. Qual è la nuova somma?
Risposta

27 (7 + 20).

Scrivi questo: Imposta var width = 4 e var height = 5. Stampa il prodotto come Area: 20. Ultima riga: Area: 20.
Risposta 
var width = 4;
var height = 5;
io.print("Area: " + string(width * height));

Lezione 3 — Condizionali

if / else if / else scelgono un ramo. Capitolo: 8.1 Istruzioni condizionali. Stesso file: Examples/Basics/conditionals.malda.

var age = 18;
if (age >= 18) {
    io.print("You are an adult");
} else {
    io.print("You are a minor");
}

var score = 85;
if (score >= 90) {
    io.print("Grade: A");
} else if (score >= 80) {
    io.print("Grade: B");
} else if (score >= 70) {
    io.print("Grade: C");
} else {
    io.print("Grade: F");
}
Prova così: Cambia age in 16. Che cosa stampa per primo?
Risposta

You are a minor

Scrivi questo: Imposta var temp = 3. Se temp < 0 stampa ice, altrimenti se temp < 10 stampa cold, altrimenti stampa warm. Ultima riga: cold.
Risposta 
var temp = 3;
if (temp < 0) {
    io.print("ice");
} else if (temp < 10) {
    io.print("cold");
} else {
    io.print("warm");
}

Lezione 4 — Ciclo while

Un ciclo while si ripete finché la condizione è vera. Aggiorna tu la variabile di ciclo. Capitolo: 8.2 While. Stesso file: Examples/Basics/while_loop.malda.

var i = 1;
while (i <= 10) {
    io.print($"Count: {i}");
    i = i + 1;
}
io.print("Done!");
Prova così: Fai terminare il ciclo a 5. Quante righe Count: stampa?
Risposta

Cinque righe: Count: 1 fino a Count: 5.

Scrivi questo: Usa while per stampare 2, poi 4, poi 6, poi done. Ultima riga: done.
Risposta 
var n = 2;
while (n <= 6) {
    io.print(n);
    n = n + 2;
}
io.print("done");

Lezione 5 — Ciclo for

Un for in stile C raccoglie init, condizione e incremento. Capitolo: 8.2 For. Stesso file: Examples/Basics/for_loop.malda.

for (var i = 1; i <= 10; i = i + 1) {
    io.print($"Number: {i}");
}
io.print("Loop finished!");
Prova così: Fai partire il ciclo da 5. Qual è la prima riga Number:?
Risposta

Number: 5

Scrivi questo: Usa un for contato per stampare 10, poi 9, poi 8. Ultima riga: 8.
Risposta 
for (var i = 10; i >= 8; i = i - 1) {
    io.print(i);
}

Lezione 6 — Funzioni

L'unica keyword per le funzioni è function. fn e def sono errori di sintassi. Capitolo: 9.1 Dichiarazione di funzione. Stesso file: Examples/Basics/functions.malda.

function add(a, b) {
    return a + b;
}

var result1 = add(5, 3);
io.print($"5 + 3 = {result1}");

var result2 = add(10, 2);
io.print($"10 + 2 = {result2}");
Prova così: Aggiungi io.print(add(1, 1)); dopo le stampe esistenti. Qual è l'ultima riga?
Risposta

2

Scrivi questo: Scrivi function greet(name) che restituisce "Hi, " + name. Stampa greet("Ada"). Ultima riga: Hi, Ada.
Risposta 
function greet(name) {
    return "Hi, " + name;
}

io.print(greet("Ada"));

Lezione 7 — Liste e indicizzazione

Gli array sono indicizzati da zero e crescono con append. Un for contato percorre gli indici; for-in percorre i valori. Capitolo: 6. Array. Stesso file: Examples/Basics/lists_indexing.malda.

var scores = [88, 92, 75];
io.print("first=" + string(scores[0]));
io.print("length=" + string(scores.length));

scores.append(80);
io.print("after append length=" + string(scores.length));

var last = scores.pop();
io.print("popped=" + string(last));
io.print("length after pop=" + string(scores.length));

var total = 0;
for (var i = 0; i < scores.length; i = i + 1) {
    io.print("scores[" + string(i) + "]=" + string(scores[i]));
    total = total + scores[i];
}

var walked = 0;
for (var score in scores) {
    walked = walked + 1;
}

io.print("sum=" + string(total));
io.print("for-in count=" + string(walked));
io.print("lists ok");
Prova così: Dopo l'append esistente, aggiungi un altro punteggio 100 e non fare pop. Qual è la nuova somma stampata?
Risposta

355 (88 + 92 + 75 + 100). Il file originale fa pop dell'80 aggiunto prima di sommare.

Scrivi questo: Parti da var nums = [1, 2, 3]. Aggiungi 4 con append. Stampa last= più l'ultimo valore. Ultima riga: last=4.
Risposta 
var nums = [1, 2, 3];
nums.append(4);
io.print("last=" + string(nums[nums.length - 1]));

Lezione 8 — Starter completo

Variabili, un ciclo for-in, una funzione e un if in un programma lineare — ora che le liste sono familiari. Nota di catalogo: 34.1. Stesso file: Examples/Basics/complete_starter_program.malda.

var cart = [12, 18, 7];
var total = 0;

for (var item in cart) {
    total = total + item;
}

function describeTotal(amount) {
    if (amount >= 30) {
        return "big order";
    }

    return "small order";
}

io.print($"Items: {cart.length}");
io.print($"Total: {total}");
io.print($"Summary: {describeTotal(total)}");
Prova così: Cambia l'ultimo elemento del carrello da 7 a 4. È ancora un big order?
Risposta

Sì. Il totale diventa 34, che è ancora >= 30.

Prova così: Lascia il carrello originale e cambia la soglia da 30 a 40. Qual è il summary?
Risposta

small order (37 è sotto 40).

Scrivi questo: Somma var prices = [5, 5, 5] con for-in e stampa Total: 15. Ultima riga: Total: 15.
Risposta 
var prices = [5, 5, 5];
var total = 0;
for (var price in prices) {
    total = total + price;
}
io.print("Total: " + string(total));

Lezione 9 — Input

io.input legge una riga da stdin e restituisce sempre una string. Convertila se ti serve un numero. Questo snippet aspetta la tastiera, quindi qui non è marcato eseguibile. Capitolo: 12.2 Input dalla console. Stesso file: Examples/Basics/input_example.malda.

var name = io.input("Enter your name: ");
var ageStr = io.input("Enter your age: ");
var age = int(ageStr);
io.print($"Hello, {name}. You are {age} years old.");

A fine input ogni io.input successivo restituisce "", non null. Preferisci toIntOr(raw, fallback) rispetto a un int(...) nudo quando la riga può essere vuota.

Prova così: Che cosa restituisce ogni io.input successivo a fine file?
Risposta

Una stringa vuota "", non null.

Scrivi questo: Leggi una riga con io.input("City: ") in city e stampa You live in più quella stringa. Attende la tastiera, quindi qui non è marcato eseguibile. A fine file city è "".
Risposta 
var city = io.input("City: ");
io.print("You live in " + city);

Lezione 10 — Dizionari

Un dict associa chiavi stringa a valori. Indicizza per leggere o scrivere; containsKey, keys e values ispezionano la mappa. Capitolo: 4.4 Dizionari. Stesso file: Examples/Basics/dictionary_example.malda.

var d = dict { "a": 1, "b": 2 };
io.print("a = " + d["a"]);
io.print("b = " + d["b"]);

d["c"] = 3;
io.print("c = " + d["c"]);

io.print("has b: " + d.containsKey("b"));
io.print("has missing: " + d.containsKey("missing"));

var keys = d.keys();
var values = d.values();

io.print("keys length: " + keys.length);
io.print("values length: " + values.length);
Prova così: Aggiungi d["d"] = 4; e stampalo. Qual è keys.length dopo?
Risposta

4

Scrivi questo: Crea un dict con chiave "ok" impostata a true. Stampa ok= più il valore. Ultima riga: ok=true.
Risposta 
var flags = dict { "ok": true };
io.print("ok=" + flags["ok"]);

Lezione 11 — Ricorsione

Una funzione può chiamare se stessa. Scrivi un caso base che si ferma, poi un argomento più piccolo. Capitolo: 9.4 Ricorsione. Stesso file: Examples/Basics/recursion.malda.

function factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

function countdown(n) {
    if (n <= 0) {
        io.print("liftoff");
        return 0;
    }
    io.print(n);
    return countdown(n - 1);
}

io.print("factorial(5)=" + string(factorial(5)));
io.print("countdown from 3:");
countdown(3);
io.print("recursion ok");
Prova così: Stampa factorial(7). Qual è il valore?
Risposta

5040

Scrivi questo: Scrivi function sumTo(n) che restituisce 1 quando n <= 1, altrimenti n + sumTo(n - 1). Stampa sumTo(4). Ultima riga: 10.
Risposta 
function sumTo(n) {
    if (n <= 1) {
        return 1;
    }
    return n + sumTo(n - 1);
}

io.print(sumTo(4));

Lezione 12 — Classi

Una classe è un tipo con nome, campi e metodi. new ClassName(...) esegue il costruttore. Dentro un metodo puoi leggere un campo come name; scrivi this.name quando un parametro maschera il campo (come fa il costruttore). Capitolo: 11.1 Una classe funzionante. Stesso file: Examples/Basics/classes_intro.malda.

class Person {
    public var name;
    public var age;

    function Person(name, age) {
        this.name = name;
        this.age = age;
    }

    public function introduce() {
        io.print("Hi, I'm " + name + " and I'm " + string(age) + " years old.");
    }
}

var alice = new Person("Alice", 30);
alice.introduce();
io.print("age=" + string(alice.age));
Prova così: Crea una seconda persona new Person("Bob", 25) e chiama introduce(). Qual è la nuova ultima riga di introduce?
Risposta

Hi, I'm Bob and I'm 25 years old.

Scrivi questo: Scrivi la classe Box con public var w, costruttore Box(w) e public function area() che restituisce w * w. Stampa new Box(3).area(). Ultima riga: 9.
Risposta 
class Box {
    public var w;

    function Box(w) {
        this.w = w;
    }

    public function area() {
        return w * w;
    }
}

io.print(new Box(3).area());

Lezione 13 — try / catch

try esegue codice che può fallire. catch gestisce il valore lanciato. finally viene eseguito sempre. Capitolo: 8.4 Gestione delle eccezioni. Stesso file: Examples/Basics/try_catch.malda.

try {
    throw "something went wrong";
} catch (error) {
    io.print("caught: " + error);
}

try {
    io.print("in try");
} catch (error) {
    io.print("caught: " + error);
} finally {
    io.print("cleanup");
}
Prova così: Cambia la stringa lanciata in "disk full". Qual è la prima riga stampata?
Risposta

caught: disk full

Correggi così: Sposta throw "something went wrong"; prima del blocco try. Che cosa succede?
Risposta

Il programma si ferma con un errore non catturato. catch gestisce solo i throw eseguiti dentro il suo try.

Scrivi questo: In un try, lancia "nope". In catch, stampa err= più il valore lanciato. Ultima riga: err=nope.
Risposta 
try {
    throw "nope";
} catch (error) {
    io.print("err=" + error);
}

Lezione 14 — Prompt come template

Un prompt è un template richiamabile. Senza await non chiama un modello. Capitolo: 10.1 Panoramica passo 1. Stesso file: Examples/Basics/prompt_template.malda.

prompt greet(name) {
    user: "Hello, {name}! How are you today?"
}

var greeting = greet("Alice");
io.print(greeting.user);
Prova così: Chiama greet("MALDA") al posto di Alice. Cosa stampa?
Risposta

Hello, MALDA! How are you today?

Scrivi questo: Scrivi prompt bye(name) con user: "Goodbye, {name}.". Stampa bye("Ada").user. Ultima riga: Goodbye, Ada.
Risposta 
prompt bye(name) {
    user: "Goodbye, {name}."
}

io.print(bye("Ada").user);

Lezione 15 — Mini progetto

Una classe, un try e schema + validate offline in un programma lineare. Nota di catalogo: 34.1. Stesso file: Examples/Basics/gradebook.malda.

schema Score {
    name: string;
    points: int;
}

class Grade {
    public var name;
    public var points;

    function Grade(name, points) {
        this.name = name;
        this.points = points;
    }

    public function label() {
        if (points >= 90) {
            return "A";
        }

        return "B";
    }
}

var ada = new Grade("Ada", 92);
io.print(ada.name + ": " + ada.label());

try {
    int("not-a-number");
} catch (error) {
    io.print("caught bad score");
}

var checked = validate("Score", {
    "name": "Ada",
    "points": 92
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.name);
} else {
    io.print("schema failed: " + checked.error);
}
Prova così: Cambia i punti di Ada da 92 a 88. Qual è la prima riga stampata?
Risposta

Ada: B

Scrivi questo: Dichiara schema Item { label: string; }. Valida { "label": "pen" }. Se ha successo, stampa schema ok: più l'etichetta. Ultima riga: schema ok: pen.
Risposta 
schema Item {
    label: string;
}

var checked = validate("Item", {
    "label": "pen"
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.label);
} else {
    io.print("schema failed: " + checked.error);
}

Lezione 16 — Controlla un errore

malda check diagnostica un file e non lo esegue. fn e def non sono keyword di funzione — check le nomina. Capitolo: 2.1.2 Diagnosi senza eseguire. Stesso file (il programma corretto): Examples/Basics/check_a_mistake.malda.

Incolla questo gemello rotto in un file scratch e lancia malda check scratch.malda. Qui non è marcato eseguibile.

fn add(a, b) {
    return a + b;
}

var nums = [1, 2, 3];
io.print(nums.length());

Check segnala 'fn' is not a function keyword. Use 'function'. Poi apri il file corretto e lancialo:

function add(a, b) {
    return a + b;
}

var nums = [1, 2, 3];
io.print("sum=" + string(add(2, 3)));
io.print("len=" + string(nums.length));
Prova così: Dopo aver cambiato fn in function, che cosa segnala ancora malda check su nums.length()?
Risposta

.length() deve essere .length (una proprietà, non una chiamata). malda check --fix può riscrivere quello.

Scrivi questo: Scrivi function double(n) che restituisce n * 2. Stampa double(4) e la lunghezza di [1, 2] come len=2. Ultima riga: len=2.
Risposta 
function double(n) {
    return n * 2;
}

io.print(double(4));
io.print("len=" + string([1, 2].length));

Lezione 17 — Due file e un test

include "path"; unisce un altro file .malda al livello top (relativo a questo file). Non è import / export. Capitolo: 1.6 Composizione del sorgente. Stesso file: Examples/Basics/modules_include.malda (helper: Examples/Basics/helpers/greet_lib.malda).

include "helpers/greet_lib.malda";

io.print(greet("MALDA"));
io.print("2 + 3 = " + add(2, 3));
io.print("Done.");

Il malda ordinario è il comando sbagliato per i test. Esegui:

malda test Examples/Testing/unit_test_basics.test.malda

Quel file usa assert. Prima sezione del capitolo sui test: 35. Property testing.

function add(a, b) {
    return a + b;
}

function factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

function bound(value, lo, hi) {
    if (value < lo) {
        return lo;
    }
    if (value > hi) {
        return hi;
    }
    return value;
}

assert(add(2, 3) == 5, "add(2, 3) should be 5");
assert(factorial(5) == 120, "factorial(5) should be 120");
assert(bound(15, 0, 10) == 10, "bound should cap at hi");
assert(bound(-3, 0, 10) == 0, "bound should floor at lo");
assert(bound(7, 0, 10) == 7, "bound should pass through in-range values");

io.print("unit_test_basics: all asserts passed");
Scrivi questo: Tieni function add(a, b). Aggiungi assert(add(10, 5) == 15, "add(10, 5) should be 15"); e stampa extra assert ok. Ultima riga: extra assert ok.
Risposta 
function add(a, b) {
    return a + b;
}

assert(add(10, 5) == 15, "add(10, 5) should be 15");
io.print("extra assert ok");

Lezione 18 — Eval offline di un prompt

evalPrompt esegue lo stesso percorso di validate di await, con un fixture al posto di un modello. Niente API key. Capitolo: 10. Prompt dopo lo stop first-read (fixture / evalPrompt, non Mode B/C). Stesso file: Examples/Basics/prompt_eval.malda. Extra opzionale: Examples/Prompts/eval_prompt.malda.

schema Card {
    name: string;
    email: string;
}

prompt extractCard(raw) -> Card {
    system: "Extract a contact. JSON only.";
    user: raw;
}

var instance = extractCard("Ada Lovelace — ada@example.com");

var ok = evalPrompt(instance, dict { "name": "Ada", "email": "ada@example.com" });
if (ok.ok) {
    io.print("card: " + ok.data.name);
} else {
    io.print("card fail");
}

var bad = evalPrompt(instance, dict { "email": "nope" });
if (!bad.ok) {
    io.print("card expected failure");
}
Scrivi questo: Dichiara schema Note { text: string; } e prompt makeNote(raw) -> Note con user: raw. Chiama evalPrompt(makeNote("x"), dict { "text": "hi" }). Se ha successo, stampa note: hi. Ultima riga: note: hi.
Risposta 
schema Note {
    text: string;
}

prompt makeNote(raw) -> Note {
    user: raw;
}

var checked = evalPrompt(makeNote("x"), dict { "text": "hi" });
if (checked.ok) {
    io.print("note: " + checked.data.text);
} else {
    io.print("note fail");
}
