Imparare MALDA

Un corso breve sul linguaggio core. Ogni lezione è un'idea, un file eseguibile e una sezione di capitolo. I capitoli numerati restano il riferimento; questa pagina è la spina dorsale.

Lo stesso ordine è Start With MALDA nel Desktop, il percorso student della Web IDE e Start Here.

Come eseguire un file

L'interprete è il default. Dalla root del repository:

malda Examples/Basics/hello_world.malda

Stampa Hello, World! e termina. Per questo percorso non servono compile, una API key o uno scaffold di progetto. Diagnostica senza eseguire con malda check. Editor: il Desktop IDE è il riferimento Windows; la Web IDE è un playground nel browser (non ha la parità con il Desktop); VS Code + LSP è l'editor cross-platform. L'indice completo dei comandi è 2. Strumenti e toolchain.

Preferisci le chiamate con namespace (io.print, math.sqrt, str.upper). Il print piatto continua a funzionare.

Lezione 0 — First Look (opzionale)

Se programmi già, parti da qui. -> Review lega il prompt allo schema. Senza await la chiamata è un template reso (niente API key). validate("Review", …) è lo stesso controllo che await eseguirebbe sul JSON del modello. Sintassi dello schema: 4.6. Stesso file: Examples/Basics/first_look.malda.

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}

Lezione 1 — Hello World

Una chiamata scrive una riga. Capitolo: 12.1 Output sulla console. Stesso file: Examples/Basics/hello_world.malda.

io.print("Hello, World!");

Lezione 2 — Variabili e aritmetica

var dichiara un binding. Il tipo arriva dal valore. Capitolo: 5.1 Dichiarazione di variabili. Stesso file: Examples/Basics/variables_arithmetic.malda.

var x = 10;
var y = 20;
var sum = x + y;
var product = x * y;
io.print($"Sum: {sum}");
io.print($"Product: {product}");

Lezione 3 — Condizionali

if / else if / else scelgono un ramo. Capitolo: 8.1 Istruzioni condizionali. Stesso file: Examples/Basics/conditionals.malda.

var age = 18;
if (age >= 18) {
    io.print("You are an adult");
} else {
    io.print("You are a minor");
}

var score = 85;
if (score >= 90) {
    io.print("Grade: A");
} else if (score >= 80) {
    io.print("Grade: B");
} else if (score >= 70) {
    io.print("Grade: C");
} else {
    io.print("Grade: F");
}

Lezione 4 — Ciclo while

Un ciclo while si ripete finché la condizione è vera. Aggiorna tu la variabile di ciclo. Capitolo: 8.2 While. Stesso file: Examples/Basics/while_loop.malda.

var i = 1;
while (i <= 10) {
    io.print($"Count: {i}");
    i = i + 1;
}
io.print("Done!");

Lezione 5 — Ciclo for

Un for in stile C raccoglie init, condizione e incremento. Capitolo: 8.2 For. Stesso file: Examples/Basics/for_loop.malda.

for (var i = 1; i <= 10; i = i + 1) {
    io.print($"Number: {i}");
}
io.print("Loop finished!");

Lezione 6 — Funzioni

L'unica keyword per le funzioni è function. fn e def sono errori di sintassi. Capitolo: 9.1 Dichiarazione di funzione. Stesso file: Examples/Basics/functions.malda.

function add(a, b) {
    return a + b;
}

var result1 = add(5, 3);
io.print($"5 + 3 = {result1}");

var result2 = add(10, 2);
io.print($"10 + 2 = {result2}");

Lezione 7 — Starter completo

Variabili, un ciclo for-in, una funzione e un if in un programma lineare. Nota di catalogo: 34.1. Stesso file: Examples/Basics/complete_starter_program.malda.

var cart = [12, 18, 7];
var total = 0;

for (var item in cart) {
    total = total + item;
}

function describeTotal(amount) {
    if (amount >= 30) {
        return "big order";
    }

    return "small order";
}

io.print($"Items: {cart.length}");
io.print($"Total: {total}");
io.print($"Summary: {describeTotal(total)}");

Lezione 8 — Input

io.input legge una riga da stdin e restituisce sempre una string. Convertila se ti serve un numero. Questo snippet aspetta la tastiera, quindi qui non è marcato eseguibile. Capitolo: 12.2 Input dalla console. Stesso file: Examples/Basics/input_example.malda.

var name = io.input("Enter your name: ");
var ageStr = io.input("Enter your age: ");
var age = int(ageStr);
io.print($"Hello, {name}. You are {age} years old.");

A fine input ogni io.input successivo restituisce "", non null. Preferisci toIntOr(raw, fallback) rispetto a un int(...) nudo quando la riga può essere vuota.
