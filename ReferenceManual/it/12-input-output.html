12. Input/Output

Questo capitolo è la guida pratica all'I/O: console, file, path, variabili d'ambiente e fatti sul processo host. Preferisci il namespace io.*. Gli alias piatti come print e readFile continuano a funzionare, ma l'editor avvisa con malda-style. Firme, helper git, glob / grep, estrattori di documenti e Spectre.Console stanno in 13. Funzioni built-in.

L'I/O su file è una capacità dell'host. L'interprete e il transpile C# la supportano; il backend JavaScript no (file-io è no nella matrice delle capacità dei backend).

12.1 Output sulla console

io.print(value) prende esattamente un argomento, lo converte con string(value) e scrive una riga (con newline finale). Non esiste println. Concatena o interpola prima della chiamata se ti servono più pezzi sulla stessa riga.

io.print("Hello, World!");

var name = "Alice";
io.print($"Hello, {name}!");   // interpolation — the $ is required
io.print("n is {n}");          // literal braces: a plain string does not interpolate
  • Usa $"…" oppure "Value of x: " + string(x). Una stringa semplice "n is {n}" stampa le parentesi graffe.
  • Numeri, boolean, array e oggetti stampano la loro forma stringa. Per testo JSON, chiama prima toJSON(value).
  • Colori ricchi, tabelle, pannelli e barre di avanzamento sono AnsiConsole.* — vedi 13.12 Spectre.Console. AnsiConsole.markup non aggiunge una newline; usa markupLine per una riga autonoma.
  • Quando stdout non è un terminale, Spectre.Console toglie l'ANSI e i bordi Unicode dei pannelli tornano agli angoli a squadra. È il comportamento atteso per pipe e file reindirizzati.

12.2 Input dalla console

io.input(prompt?) scrive un prompt opzionale (senza newline extra) e legge una riga da stdin. Il risultato è sempre una string. Convertilo se ti serve un numero.

var name = io.input("Enter your name: ");
var age = int(io.input("Enter your age: "));
io.print($"Hello, {name}. Next year you will be {age + 1}.");
La fine dell'input è una stringa vuota, non null. A EOF ogni io.input successivo restituisce anch'esso "". Un ciclo che avanza solo su input non vuoto non termina mai. Tratta il vuoto come uscita: 
while (true) {
    var raw = io.input("? ");
    if (str.trim(raw) == "") {
        break;
    }
    io.print(raw);
}

La chiamata è asincrona: l'esecuzione si ferma finché non arriva una riga, poi riprende sulla stessa istruzione. Funziona dentro cicli, funzioni e strutture di controllo annidate.

Per numeri malformati preferisci toIntOr(raw, fallback) o toIntOrNull(raw) rispetto a un int(...) nudo, che lancia. Vedi 13.1 Conversioni di tipo.

12.3 File

I path sono stringhe (o un token di capability corrispondente). I fallimenti ordinari restituiscono null o false; non lanciano. Controlla il risultato.

12.3.1 Lettura e scrittura

io.writeFile(path, content) sovrascrive il file e restituisce true in caso di successo, false in caso di fallimento I/O. Le stringhe vengono scritte come UTF-8. Oggetti e array vengono prima serializzati con toJSON. io.readFile(path) restituisce l'intero file come stringa, oppure null quando il path manca o non è leggibile.

io.writeFile("_rm_io_notes.txt", "hello");
io.print(io.hasFile("_rm_io_notes.txt"));
io.print(io.readFile("_rm_io_notes.txt"));
io.deleteFile("_rm_io_notes.txt");
io.print(io.hasFile("_rm_io_notes.txt"));
io.writeFile("_rm_io_json.txt", dict { "ok": true });
var obj = parseJSON(io.readFile("_rm_io_json.txt"));
io.print(obj.ok);
io.deleteFile("_rm_io_json.txt");
io.print(io.readFile("_rm_io_missing.txt") == null);

12.3.2 Intervalli di righe e array di righe

I numeri di riga sono 1-based.

  • io.readFile(path, start) — da quella riga fino alla fine. Un start negativo indica le ultime N righe (-30 sono le ultime 30).
  • io.readFile(path, start, end) — intervallo inclusivo. Un end negativo conta dalla fine del file.
  • Se start è oltre l'ultima riga, il risultato è "" (stringa vuota), non null.
  • io.readTextFileLines(path) — righe UTF-8 come array, oppure null se il file non si può leggere. Preferiscilo a str.split(io.readFile(path), "\n") per i file grandi.
io.writeFile("_rm_io_lines.txt", "a\nb\nc\nd");
io.print(io.readFile("_rm_io_lines.txt", 2, 3));
io.deleteFile("_rm_io_lines.txt");

12.3.3 Directory, eliminazione e binari

ChiamataRisultato
io.hasFile(path)true quando esiste un file (disco o embed:)
io.hasDirectory(path)true quando esiste una directory
io.ensureDir(path)Crea la directory e i genitori mancanti; no-op se esiste già. Lancia in caso di fallimento. Rifiuta embed:
io.listDirectory(path)Array di { name, type, path }. type è "file" o "directory". Directory mancanti producono []. Un path vuoto significa "."
io.deleteFile(path)true se il file è stato eliminato oppure era già assente; false su un path vuoto o un fallimento I/O
io.readFileBase64(path) / io.writeFileBase64(path, b64)Byte grezzi come base64. La lettura restituisce null se manca; la scrittura restituisce false su base64 non valido
 
io.writeFile("_rm_io_list.txt", "x");
var items = io.listDirectory(".");
var found = false;
for (var item in items) {
    if (item.name == "_rm_io_list.txt") {
        found = true;
    }
}
io.print(found);
io.deleteFile("_rm_io_list.txt");

insertAtLine, replaceInFile e editFile modificano il testo in place — catalogo e stile dei fallimenti in 13.8. insertAtLine è solo sull'interprete.

Testo digitale dai documenti: pdf.extractText(path, password?) (layer di testo PdfPig, senza OCR) e doc.extractText(path) (solo .docx). Quelli lanciano se il file manca. Vedi 13.8.1.

12.3.4 Cartelle incorporate (embed:)

Compila con malda compile … --embed-folder <dir[=alias]> per impacchettare una directory nell'eseguibile. A runtime, leggi con lo schema virtuale embed:<alias>/<relative>. Niente viene estratto su disco. Le scritture (io.writeFile, io.ensureDir, io.deleteFile, …) rifiutano i path embed:. io.hasEmbeddedFolder(alias) / io.embeddedFolderRoot(alias) ispezionano ciò che è stato impacchettato. Esempio completo in 13.8.0.

12.4 Path

Unisci e ispeziona i path invece di concatenare gli slash. io.pathJoin usa il separatore dell'host. io.pathNormalize restituisce un path assoluto.

io.print(io.getFileName("docs/notes.md"));
io.print(io.pathGetExtension("docs/notes.md"));
io.print(io.isPathUnder("brain", "brain/notes/a.md"));
  • io.getDirectoryName(path) — directory padre, oppure "" per un nome file nudo.
  • io.pathExists(path) — file o directory.
  • io.isPathUnder(root, path) — true quando path si risolve a root o a un discendente. Usa un confine sul separatore di directory (demo non corrisponde a demo-evil). Funziona per path su disco e root embed:. Traversal come brain/../secret.txt è false.
  • getProgramDirectory() — cartella del .malda in esecuzione sotto l'interprete, o la directory dell'eseguibile compilato dopo malda compile. Non è sull'oggetto io.

12.5 Ambiente e host

Queste funzioni leggono l'ambiente del processo e la macchina su cui gira il programma. Non sono I/O su file, ma sono il modo in cui i programmi trovano chiavi, argomenti e un posto da cui caricare file sidecar.

io.print(io.getEnvOr("MALDA_RM_IO_MISSING_VAR_7D05", "fallback"));
var host = getHostPlatform();
io.print(str.length(host.pathSeparator));
  • io.getEnv(name) — stringa, oppure null se non impostata. Non passare quel null a str.trim; usa io.getEnvOr(name, default?) (stringa vuota se il default è omesso) oppure str.trimText.
  • io.hasEnv(name) — se la variabile è impostata.
  • getHostPlatform() — { os, arch, pathSeparator, description }. Nessun argomento.
  • getCommandLineArgs() — array di stringhe passate al programma, escluso il nome del programma. Uguale nelle esecuzioni interpretate e transpile.

La config dell'assistente sotto ~/.malda (getMaldaHome, getMaldaConfig) è documentata con l'assistente personale.

12.6 Token di capability

@effects("io") è un allow-list di nomi. A un tool che accetta una stringa path si può comunque passare "/etc/passwd". Emetti un token non contraffabile e passa quello. I token sono oggetti host sigillati — un dict { kind, path } non è un token.

var notes = cap.fileRead("notes.md");
io.print(notes.kind);
io.print(cap.is(notes, "fileRead"));
  • Emetti: cap.fileRead(path), cap.fileWrite(path), cap.dirList(path).
  • Consuma: cap.read / cap.write / cap.list, oppure passa il token a io.readFile / io.writeFile / io.listDirectory. I path stringa ordinari continuano a funzionare per il codice che non è un tool.
  • cap.confine(token, relativePath) restringe un token; i path fuori dal padre lanciano.

Contratto completo e un test con dict contraffatto: 13.19.3 e Examples/Tools/capability_tokens.malda.

12.7 Ricerca nei file

io.glob(pattern, dirPath?) trova i path. io.grep(pattern, filePath) cerca nei contenuti. Entrambi prendono un primo argomento obbligatorio e poi argomenti posizionali opzionali. Su un path mancante o una regex non valida restituiscono una stringa di errore, non una collezione — proteggi con typeOf(result) == "string".

io.writeFile("_rm_io_glob.txt", "needle");
var found = io.glob("_rm_io_glob.txt", ".");
io.print(found.count);
io.deleteFile("_rm_io_glob.txt");

Il cap di default di glob è 200 risultati (cap rigido 500); il risultato è { items, count, truncated } con ogni item { name, type, path }. grep di default cerca in modo ricorsivo con numeri di riga. Le liste di argomenti e la forma solo-conteggio sono in 13.8.2.

12.8 Sleep

sleep(milliseconds) mette in pausa senza far girare la CPU a vuoto. L'argomento deve essere un intero non negativo. È un built-in, non un membro io.*. Utile per i cicli keep-alive intorno a un server.

sleep(0);
io.print("awake");
while (server.isRunning) {
    sleep(1000);
}
Workflow: sleep, io.writeFile e altri effetti in deny-list sollevano WF1001 / WF1002 quando girano in una sezione deterministica di un workflow — anche se annidati in un helper. Metti orologio, sleep e I/O dentro uno step. Vedi 22. Workflow durevoli.
