Benvenuti nel manuale di riferimento MALDA

MALDA è un linguaggio orientato agli oggetti in cui prompt, agenti e workflow durevoli sono costrutti del linguaggio — non una libreria innestata su un altro stack. Il nome e l'architettura del runtime sono in 1. Introduzione.

Cosa viene distribuito oggi: MALDA 1.0.29 (questo manuale). La semantica del linguaggio Tier 0 è specificata in malda-language-1.0. Un interprete C#, un compilatore che fa transpile verso C# o JavaScript, un Desktop IDE Windows, un playground nel browser e un language server per editor cross-platform. L'interprete è la superficie host completa; il transpile C# la condivide. JavaScript è un sottoinsieme: dom.* / game.* / three.* / @shader() sono solo JS, mentre agenti, server HTTP, I/O su file, VectorDB e workflow restano sull'host. Ogni capitolo indica i propri backend; la tabella è la matrice delle capacità dei backend.
Trovare un concetto: Usa la ricerca nella barra laterale (premi / oppure Ctrl+K) o sfoglia il glossario. Nomi brevi come cap portano ai token di capability in 13.19.3 e 12.6.
Come ottenere MALDA: su Windows, scarica lo zip win-x64 da GitHub Releases e avvia MaldaDesktop.bat (CLI + Desktop IDE), poi Start With MALDA. Linux: lo zip linux-x64 e ./malda. Dai sorgenti: dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda. Senza installazione: il playground della Web IDE. Dopo, a uno studente basta malda file.malda — vedi Imparare MALDA.
Onboarding consigliato: MALDA funziona meglio con un avvio a due binari. Chi programma per la prima volta dovrebbe iniziare da Imparare MALDA. Chi ha già esperienza può entrare subito nei prompt, negli agenti, nelle API e negli esempi full-stack. Dopo il percorso core, segui Imparare MALDA — Dopo il percorso core (algoritmi, poi un hub). Le reti da zero — percettrone, XOR, poi il capitolo 14 — sono il percorso di teoria AI in Start Here. Per path di esempi eseguibili e quickstart CLI, vedi Start Here.

Avvio rapido

Se programmi già, parti dai costrutti caratteristici. -> Review lega il prompt allo schema. Senza await, la chiamata è un template reso (nessuna API key). validate("Review", …) è lo stesso controllo che await eseguirebbe sul JSON del modello. Le annotazioni di tipo altrove sono type hint IDE/LSP, non controlli a runtime. Stesso file: Examples/Basics/first_look.malda.

1. First Look

schema Review {
    summary: string;
    issues: string[];
}

prompt codeReview(code, language) -> Review {
    system: "You are an expert reviewer of {language}.",
    user: "Review this {language} code:\n\n{code}"
}

var rendered = codeReview("function add(a, b) { return a + b; }", "javascript");
io.print(rendered.user);

var checked = validate("Review", {
    "summary": "Looks fine",
    "issues": []
});
if (checked.ok) {
    io.print("schema ok: " + checked.data.summary);
} else {
    io.print("schema failed: " + checked.error);
}

Poi il percorso della sintassi, se vuoi il linguaggio core prima di agenti e API. Preferisci le chiamate namespaced (io.print, math.sqrt, str.upper); il print piatto continua a funzionare.

2. Output a stampa

io.print("Hello, World!");

3. Variabili e aritmetica

var price = 12;
var quantity = 3;
var total = price * quantity;

io.print("Total: " + total);

4. Condizionali

var score = 82;

if (score >= 60) {
    io.print("Pass");
} else {
    io.print("Fail");
}

5. Cicli e funzioni

function printCountdown(start) {
    var current = start;
    while (current > 0) {
        io.print(current);
        current = current - 1;
    }
    io.print("Go!");
}

printCountdown(3);

6. Programma iniziale completo

Questo esempio combina variabili, array, un ciclo, una funzione e un'if in un unico programma lineare:

var cart = [12, 18, 7];
var total = 0;

for (var item in cart) {
    total = total + item;
}

function describeTotal(amount) {
    if (amount >= 30) {
        return "big order";
    }
    return "small order";
}

io.print("Items: " + cart.length);
io.print("Total: " + total);
io.print("Summary: " + describeTotal(total));

Per altro materiale nello stesso stile, una lezione alla volta, vedi Imparare MALDA. Il catalogo delle cartelle è Esempi; i path CLI sono in Start Here.
