19. Server MCP

MCP (Model Context Protocol) consente a un host AI — Claude Desktop, Cursor, ChatGPT o un MCPClient MALDA — di lanciare il tuo processo e parlare JSON-RPC 2.0 su STDIO (stdin/stdout). Decora funzioni ordinarie con @MCPTool, chiama new MCPServer().start() e l'host può elencarle e invocarle. Stesso file: Examples/MCP/mcp_tools_server.malda.

19.1 Un server minimo

@MCPTool("add", "Adds two numbers together")
function add(a, b) {
    return int(a) + int(b);
}

@MCPTool("reverse_string", "Reverses a string")
function reverseString(text) {
    var reversed = "";
    var i = length(text) - 1;
    while (i >= 0) {
        reversed = reversed + substring(text, i, 1);
        i = i - 1;
    }
    return reversed;
}

var server = new MCPServer();
server.start();

while (server.isRunning) {
    sleep(1000);
}

Eseguilo come un programma MALDA normale. Deve essere l'host, non tu, ad avviare quel processo quando vuole i tool:

malda Examples/MCP/mcp_tools_server.malda

Una config host MCP (Claude Desktop claude_desktop_config.json, Cursor mcp.json) è fatta così — punta command a un eseguibile malda sul PATH, o a un path assoluto:

{
  "mcpServers": {
    "malda-tools": {
      "command": "malda",
      "args": ["C:/path/to/Examples/MCP/mcp_tools_server.malda"]
    }
  }
}
Non stampare banner su stdout dopo start() se un host è collegato: STDIO è il protocollo. Scrivi i log su stderr o su file. Il server di esempio in Examples/MCP/ stampa prima dell'handshake in un loop dimostrativo; un server di produzione deve restare silenzioso su stdout.

19.2 @MCPTool e schema

@MCPTool("tool_name", "Tool description")
function myTool(param1, param2) {
    return param1 + param2;
}

Se ometti uno schema, MALDA costruisce il JSON Schema dai nomi dei parametri: ogni property ha tipo "string" ed è required. Passa una stringa JSON Schema come terzo argomento quando ti servono enum, numeri o campi opzionali:

@MCPTool("tool_name", "Tool description", "{\"type\":\"object\",\"properties\":{...}}")
function myTool(param1) {
    // ...
}

19.3 MCPServer

var server = new MCPServer();                    // STDIO transport (default)
var server = new MCPServer("stdio");            // Explicit STDIO transport
  • start(): scopre le funzioni @MCPTool e serve JSON-RPC
  • stop(): arresta il server
  • getTools(): elenca i tool registrati
  • isRunning: resta in loop finché l'host non si disconnette

Metodi JSON-RPC implementati: initialize, tools/list, tools/call, notifications/initialized.

19.4 MCPClient: chiamare un altro server

MCPClient avvia un processo figlio e parla lo stesso protocollo STDIO. Stesso file: Examples/MCP/mcp_client_example.malda. Esegui il client dalla root del repo così malda trova lo script del server.

var client = new MCPClient("example-server");
var connected = client.connect("malda", ["Examples/MCP/mcp_tools_server.malda"]);
if (!connected) {
    print("Failed to connect");
    return;
}

var tools = client.getTools();
print("Tool count: " + string(tools.length));

var sum = client.callTool("add", {"a": 5, "b": 3});
print(string(sum));

client.disconnect();

connect(command, args?, env?) restituisce true se la connessione riesce. callTool(name, arguments?) converte il risultato JSON in valori MALDA. Ogni tool di getTools() ha name, description e schema.

var client = new MCPClient("my-server");
var connected = client.connect("python", ["-m", "mcp_server"], {"API_KEY": "secret"});
  • createTool(toolName, registeredName?, register?) avvolge un tool in un MCPToolInstance che puoi passare a agent.addTool(...) (vedi 17. Orchestrazione di agenti)
  • refreshTools() riscopre i tool dopo che il server è cambiato
  • serverName / isConnected sono property

19.5 Agente wrapper (opzionale)

createWrapperAgent costruisce un Agent con già attaccati tutti i tool del server collegato. Se ometti llmClient, MALDA usa un modello GGUF locale (scaricato al primo uso). Preferisci l'esempio callTool sopra finché non ti serve un LLM nel giro.

var mcpClient = new MCPClient("example-server");
mcpClient.connect("malda", ["Examples/MCP/mcp_tools_server.malda"]);

var agent = mcpClient.createWrapperAgent(
    "Helper",
    "assistant",
    "You use MCP tools to answer questions."
);

var response = agent.think("Add 5 and 3");
print(response.content);
mcpClient.disconnect();

19.6 Avanzato: generare uno script

createMcpAgentScript(agentName, agentRole, agentInstructions, tools, outputPath, model?) scrive un file .malda che espone un agente come tool MCP. È un generatore di codice, non una sessione STDIO live: preferisci callTool o createWrapperAgent finché non ti serve emettere un file. Abbinalo a MALDACodingAgent in 17. Orchestrazione di agenti e a compileMALDA in 12. Funzioni built-in solo quando un agente deve generare e compilare MALDA.
