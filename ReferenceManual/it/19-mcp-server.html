19. Server MCP

La classe MCPServer consente a MALDA di funzionare come server di tool MCP (Model Context Protocol): gli sviluppatori possono scrivere tool MCP personalizzati in MALDA e esporli a client MCP come Claude Desktop o ChatGPT.

19.1 Panoramica

MCP (Model Context Protocol) è un protocollo per collegare applicazioni AI a origini dati e tool esterni. L'implementazione del server MCP di MALDA consente di:

  • Definire tool personalizzati con il decoratore @MCPTool
  • Esporre funzioni MALDA come tool MCP
  • Comunicare tramite JSON-RPC 2.0 sul transport STDIO
  • Generare automaticamente le definizioni dei tool in JSON Schema

19.2 Decoratore @MCPTool

Le funzioni decorate con @MCPTool vengono scoperte e registrate automaticamente come tool MCP all'avvio del server.

Sintassi

@MCPTool("tool_name", "Tool description")
function myTool(param1, param2) {
    return param1 + param2;
}

Con schema personalizzato

@MCPTool("tool_name", "Tool description", "{\"type\":\"object\",\"properties\":{...}}")
function myTool(param1) {
    // ...
}

19.3 Classe MCPServer

Costruttore

var server = new MCPServer();                    // STDIO transport (default)
var server = new MCPServer("stdio");            // Explicit STDIO transport

Metodi

  • start(): Avvia il server MCP e scopre i tool
  • stop(): Arresta il server MCP
  • getTools(): Restituisce l'elenco dei tool registrati

19.4 Generazione dello schema dei tool

Se non viene fornito uno schema personalizzato, lo schema del tool è generato automaticamente dai parametri della funzione:

  • Tutti i parametri hanno tipo predefinito "string" in JSON Schema
  • Tutti i parametri sono marcati come required
  • I nomi dei parametri della funzione MALDA diventano i nomi delle property

19.5 Esempio completo

@MCPTool("add", "Adds two numbers together")
function add(a, b) {
    return int(a) + int(b);
}

@MCPTool("reverse_string", "Reverses a string")
function reverseString(text) {
    var reversed = "";
    var i = length(text) - 1;
    while (i >= 0) {
        reversed = reversed + substring(text, i, 1);
        i = i - 1;
    }
    return reversed;
}

var server = new MCPServer();
server.start();

while (server.isRunning) {
    sleep(1000);
}

19.6 Supporto del protocollo MCP

Il server MCP implementa i seguenti metodi JSON-RPC 2.0:

  • initialize: Negoziazione delle capability e inizializzazione del server
  • tools/list: Restituisce l'elenco dei tool disponibili con i rispettivi schema
  • tools/call: Esegue un tool con gli argomenti forniti
  • notifications/initialized: Notifica inviata dopo l'inizializzazione

19.7 Client MCP

La classe MCPClient consente agli script MALDA di collegarsi dinamicamente a server MCP e usare i loro tool. Così gli agenti MALDA possono connettersi a server MCP esterni in modo programmatico e creare agenti wrapper con i tool MCP.

Panoramica

La classe MCPClient offre:

  • Connessione dinamica a server MCP tramite transport STDIO
  • Scoperta dei tool dai server MCP collegati
  • Chiamata diretta dei tool senza creare istanze di tool
  • Creazione di agenti wrapper con tutti i tool MCP già aggiunti

Costruttore

var client = new MCPClient(serverName);

Parametri:

  • serverName (string): Un identificatore univoco per la connessione al server MCP

Metodi

connect(command, args?, env?)

Si collega a un server MCP avviando un processo e stabilendo una connessione JSON-RPC.

Parametri:

  • command (string, obbligatorio): Comando eseguibile per avviare il server MCP
  • args (array, opzionale): Argomenti da riga di comando come array di stringhe
  • env (object, opzionale): Variabili d'ambiente come coppie chiave-valore

Restituisce: boolean - true se la connessione è riuscita

var client = new MCPClient("my-server");
var connected = client.connect("python", ["-m", "mcp_server"], {"API_KEY": "secret"});

disconnect()

Si disconnette dal server MCP e arresta il processo.

getTools()

Restituisce un array di tutti i tool disponibili dal server MCP collegato.

Restituisce: array - Array di oggetti tool con le property name, description e schema

callTool(toolName, arguments?)

Chiama un tool MCP direttamente, senza creare un'istanza di tool.

Parametri:

  • toolName (string, obbligatorio): Nome del tool da chiamare
  • arguments (object, opzionale): Argomenti del tool come oggetto

Restituisce: Risultato della tool call (convertito da JSON ai tipi MALDA)

createTool(toolName, registeredName?, register?)

Crea un wrapper MCPToolInstance per un tool specifico.

Parametri:

  • toolName (string, obbligatorio): Nome del tool sul server MCP
  • registeredName (string, opzionale): Nome personalizzato per la registrazione del tool (default: mcp:serverName:toolName)
  • register (boolean, opzionale): Se registrare il tool in ToolRegistry (default: false)

Restituisce: MCPToolInstance - Un'istanza di tool che si può aggiungere agli agenti

refreshTools()

Riscopre i tool dal server MCP. Utile se i tool sono cambiati dopo la connessione.

Restituisce: boolean - true se il refresh è riuscito

createWrapperAgent(name, role, instructions, llmClient?)

Crea un'istanza Agent con tutti i tool MCP già aggiunti. È un metodo di convenienza che unisce creazione dell'agente, scoperta dei tool e registrazione.

Parametri:

  • name (string, obbligatorio): Nome dell'agente
  • role (string, obbligatorio): Descrizione del ruolo dell'agente
  • instructions (string, obbligatorio): Istruzioni / system prompt dell'agente
  • llmClient (opzionale): Istanza di LLMClient, LlamaCppClient o LLMClientBridge. Se omesso, il default è un LLM locale (Qwen/Qwen2.5-0.5B-Instruct, scaricato automaticamente come build GGUF da Hugging Face al primo uso).

Restituisce: Agent - Un agente già configurato, con tutti i tool MCP già aggiunti

// Connect to MCP server
var mcpClient = new MCPClient("data-analyst");
mcpClient.connect("./data_analyst_server.exe", [], {});

// Create wrapper agent with all MCP tools automatically added
var agent = mcpClient.createWrapperAgent(
    "DataAnalyst",
    "Data Analysis Specialist",
    "You analyze data and provide insights using MCP tools."
);

// Agent is ready to use - all tools are already added!
var response = agent.think("Analyze sales data: Q1=$100k, Q2=$150k");
print(response.content);

Proprietà

  • serverName (string): L'identificatore del nome del server
  • isConnected (boolean): Se il client è al momento collegato a un server MCP

Esempio completo: creazione dinamica di un agente

// Step 1: Create and compile an MCP agent server (using SPLCodingAgent)
var agentBuilder = new SPLCodingAgent(
    "AgentBuilder",
    "Agent Creation Specialist",
    "You create, compile, and test MCP agent server scripts.",
    client,
    "./agents"
);

// Step 2: Create an MCP server script
var result = createMcpAgentScript(
    "DataAnalyst",
    "Data Analysis Specialist",
    "You analyze data and provide insights.",
    [
        {"name": "analyze_data", "description": "Analyzes data"},
        {"name": "generate_report", "description": "Generates reports"}
    ],
    "./agents/data_analyst_server.malda",
    "openai/gpt-4"
);

// Step 3: Compile the script
var compileResult = compileMALDA(result.outputPath, "./agents/data_analyst_server.exe");

// Step 4: Connect to the MCP server
var mcpClient = new MCPClient("data-analyst");
var connected = mcpClient.connect("./agents/data_analyst_server.exe", [], {});

if (connected) {
    // Step 5: Create wrapper agent with all tools automatically added
    var agent = mcpClient.createWrapperAgent(
        "DataAnalyst",
        "Data Analysis Specialist",
        "You analyze data and generate reports."
    );
    
    // Agent is ready to use!
    var response = agent.think("Analyze this data: Q1=$100k, Q2=$150k, Q3=$180k");
    print(response.content);
    
    // Cleanup
    mcpClient.disconnect();
}
