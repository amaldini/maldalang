37. Appendice: biliardo GPU

Questa appendice ospita il JavaScript compilato di Examples/Games/three_shader_billiards.malda così il tavolo è giocabile dal manuale. Il kernel resta GLSL @shader(); il MALDA host fa la fisica 2D e invia le uniform di palle e stecca. Vedi 26.10.1 Kernel shader e 33.15.1 Materiali shader.

37.1 Tavolo giocabile

Serve WebGL. Clicca dentro il frame così mouse e tastiera raggiungono il demo. Tieni premuto click o Spazio per caricare, poi rilascia per tirare. L'interfaccia del demo resta in inglese.

Il tavolo interattivo è omesso dalla stampa. Apri questo capitolo nel browser, oppure compila il sorgente sotto.

37.2 Controlli

  • Il mouse sul tavolo mira la stecca; A/D raffinano.
  • Tieni premuto click o Spazio per caricare; rilascia per tirare.
  • R rimette in triangolo. Le frecce orbitano. C o Stop camera azzera la velocità di orbita.
  • [ ] o + − zoomano. Gli slider impostano cushion e, ball e e l'attrito del feltro.

37.3 Rigenerare lo script committato

Non modificare a mano ReferenceManual/three_shader_billiards.js. Cambia il sorgente .malda e compila in una cartella temporanea — malda compile --mode js -o scrive anche index.html accanto allo script, quindi non puntare direttamente a ReferenceManual/:

malda compile Examples/Games/three_shader_billiards.malda --mode js -o artifacts/billiards-appendix/three_shader_billiards.js
cp artifacts/billiards-appendix/three_shader_billiards.js ReferenceManual/three_shader_billiards.js

Un content guard fallisce se quel file diverge da un transpile fresco (il commento source-map aggiunto dalla CLI viene ignorato). In locale dalla root del repo three.min.js e malda-js-runtime.js arrivano da Examples/Web/wwwroot/. GitHub Pages copia quei due file accanto a questo capitolo.
