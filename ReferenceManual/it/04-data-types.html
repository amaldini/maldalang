4. Tipi di dati

MALDA è un linguaggio a typing dinamico, con supporto per tipi primitivi, array e oggetti. Le variabili possono contenere valori di qualsiasi tipo, e i tipi vengono inferiti dai valori.

4.1 Tipi primitivi

MALDA supporta quattro tipi di dati primitivi:

Intero (int)

Interi con segno a 32 bit. Esempi:

42
-10
0
12345

Float (float)

Numeri in virgola mobile a 64 bit. Esempi:

3.14
-0.5
2.0
1e-5

Stringa (string)

Sequenze di caratteri racchiuse tra virgolette doppie ("...") o virgolette singole ('...'). Le due forme sono equivalenti. Esempi:

"Hello, World!"
'Hello, World!'
"Line 1\nLine 2"
'Line 1\nLine 2'
"Tab\tseparated"
"It's a test"        // Using double quotes when string contains single quote
'He said "hello"'    // Using single quotes when string contains double quote

Booleano (bool)

Valori logici: true o false.

4.2 Sistema di tipi

Typing dinamico

Le variabili in MALDA sono a typing dinamico: possono contenere valori di qualsiasi tipo, e il tipo viene determinato a runtime:

var x = 10;        // x is an integer
x = "Hello";      // x is now a string
x = 3.14;         // x is now a float
x = true;         // x is now a boolean

Inferenza di tipo

I tipi delle variabili vengono inferiti automaticamente dai valori iniziali:

var name = "Alice";     // Inferred as string
var age = 25;          // Inferred as integer
var pi = 3.14159;     // Inferred as float
var isActive = true;   // Inferred as boolean

Type coercion

MALDA converte automaticamente tra tipi compatibili in certi contesti:

Conversione Integer ↔ Float

Gli interi vengono convertiti automaticamente in float quando serve:

var x = 10;        // integer
var y = 3.14;     // float
var sum = x + y;   // x is converted to float, result is 13.14

Concatenazione di stringhe

Quando si usa l'operatore + con le stringhe, i valori non stringa vengono convertiti in stringhe:

var name = "Alice";
var age = 25;
var message = "Name: " + name + ", Age: " + age;
// message = "Name: Alice, Age: 25"

Conversione di tipo esplicita

Usa le funzioni built-in per la conversione di tipo esplicita (vedi Funzioni built-in):

var num = int("123");      // Convert string to integer
var floatVal = float("3.14");  // Convert string to float
var str = string(42);     // Convert number to string

4.3 Tipi oggetto

Istanze di classe

Gli oggetti sono istanze di classi. Si creano con la keyword new:

class Person {
    public var name;
    public var age;
    
    function Person(name, age) {
        this.name = name;
        this.age = age;
    }
}

var person = new Person("Alice", 25);  // person is an object

Vedi Classi e oggetti per maggiori informazioni.

Null

null è un valore speciale che rappresenta l'assenza di un oggetto. Può essere assegnato a qualsiasi variabile oggetto:

var obj = null;

if (obj == null) {
    print("Object is null");
}
Attenzione: accedere ai membri di null causa un errore a runtime.

Tipi riferimento

Gli oggetti sono tipi riferimento: quando assegni un oggetto a una variabile, entrambe le variabili si riferiscono allo stesso oggetto:

var person1 = new Person("Alice", 25);
var person2 = person1;  // person2 refers to the same object
person2.name = "Bob";
print(person1.name);    // Prints "Bob" (same object)

4.4 Dizionari

I dizionari sono mappe chiave–valore mutabili con chiavi stringa e valori di qualsiasi tipo. Sono utili per oggetti di configurazione, mappe dinamiche e aggregazione di dati.

Letterali dizionario

I dizionari si creano con la sintassi letterale dict { ... }:

var d = dict { "a": 1, "b": 2 };
print(d["a"]);
print(d["missing"] == null);

Metodi dei dizionari

I dizionari sono oggetti con metodi built-in:

var d = dict { "x": 10 };

// get(key) – returns value or null
print(d.get("x"));        // 10
print(d.get("missing"));  // null

// set(key, value) – sets and returns the same dictionary
d.set("y", 20);
print(d["y"]);            // 20

// remove(key) – removes entry and returns true/false
print(d.remove("y"));     // true

// containsKey(key) – membership test
print(d.containsKey("x"));   // true

// keys() – array of string keys
var keys = d.keys();
print(keys.length);

// values() – array of values
var values = d.values();
print(values.length);

// entries() – array of [key, value] pairs
var entries = d.entries();
var first = entries[0];   // [key, value]
print(first[0]);          // key
print(first[1]);          // value

Negli eseguibili transpile, i letterali dizionario usano Dictionary<string, object?> come backing ma espongono lo stesso comportamento dell'interprete.

4.5 Tipi somma (unioni etichettate)

I tipi somma consentono di definire un valore che può essere una di diverse varianti, ciascuna con dati di payload opzionali. Sono utili per risultati strutturati (es. successo vs errore) e dati in stile protocollo.

Dichiarazione di tipo

Dichiara un tipo somma con type, un nome di tipo e uno o più costruttori separati da |. Ogni costruttore ha un nome e parametri opzionali. I parametri possono essere solo nome oppure portare un tipo di payload (la stessa forma SchemaType dei campi schema: primitivi, [], ?, nomi di schema o di tipo somma):

type Result = Ok(value) | Err(message);
type Intent = Search(query: string) | Buy(sku: string, qty: int) | Help();

I costruttori solo-nome restano validi (Search(query)) e restano non tipizzati nello JSON Schema generato. Mescolare bracci tipizzati e non tipizzati in un unico type è consentito. I tipi di payload non sono typing dei parametri di prompt — scrivi prompt greet(name), mai prompt greet(name: string) — vedi 10. Prompt.

I nomi dei costruttori (es. Ok, Err) diventano funzioni globali che costruiscono valori di quella variante. Lo stesso nome non può essere anche uno schema. validate("Result", taggedDict) controlla la forma JSON sul filo ({"tag":"Ok","value":…}) senza trasformare il dict in una variante — vedi validate(). Quando un payload è tipizzato, validate e i prompt tipizzati rifiutano JSON che non corrisponde (per esempio qty: "x" contro qty: int).

Costruire valori

Chiama un costruttore come una funzione. Restituisce un valore etichettato che porta gli argomenti come payload:

var r = Ok(42);           // variant Ok with payload 42
var e = Err("failed");    // variant Err with payload "failed"
var n = None();           // variant None with no payload

Match sulle varianti

Usa match con pattern di variante: ConstructorName(binding, ...). Il pattern corrisponde se il valore è quella variante e lega il payload ai nomi dati. Un nome di costruttore nudo (case None:) corrisponde a quella variante senza legare i payload (_ implicito per ogni slot).

type Result = Ok(value) | Err(message);
function divide(a, b) {
    if (b == 0) return Err("divide by zero");
    return Ok(a / b);
}
var r = divide(10, 2);
var result = match r {
    case Ok(v): "ok: " + v;
    case Err(msg): "error: " + msg;
};
print(result);   // "ok: 5"

Vedi 8. Strutture di controllo per la sintassi completa di match. I moduli della libreria standard result e option incapsulano gli stessi tag Ok/Err e Some/None senza una dichiarazione type — vedi 13.19.1.

4.6 Controllo dei tipi

Anche se MALDA è a typing dinamico, puoi ispezionare i tipi a runtime con gli helper built-in (vedi Funzioni built-in):

var x = 10;

// Preferred: type tag from typeOf()
if (typeOf(x) == "int") {
    print("x is an integer");
}

// Any numeric value (integer or float)
if (isNumber(x)) {
    print("x is a number");
}

// Check for null
if (x == null) {
    print("x is null");
}

typeOf() restituisce tag di kind canonici come "int", "float", "string", "bool", "array", "dict" (per dict { }), "object" (istanze di classe), "variant" (valori di tipo somma), "task", "function", "class", "actor" o "null". I nomi dei costruttori (es. Ok) non sono tag di typeOf — usa match. Usa isTag(x, "integer") durante la migrazione se sono ancora in uso i nomi letterali più vecchi.
