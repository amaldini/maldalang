10. Classi e oggetti

10.1 Dichiarazione di classe

class ClassName {
    public var field1;
    private var field2;
    
    function ClassName(param1, param2) {
        this.field1 = param1;
        this.field2 = param2;
    }
    
    public function method1() {
        field1 = "value";  // Implicit member access
    }
    
    private function method2() {
        // method body
    }
}

10.2 Modificatori di accesso

  • public: accessibile da qualsiasi punto (default per i metodi)
  • private: accessibile solo all'interno della classe
  • I campi sono private se non si specifica un modificatore

10.3 Costruttori

I costruttori hanno lo stesso nome della classe e vengono chiamati automaticamente quando si creano gli oggetti:

class Point {
    public var x;
    public var y;
    
    function Point(x, y) {
        this.x = x;
        this.y = y;
    }
}

10.4 Metodi

I metodi sono funzioni definite all'interno delle classi. Possono accedere ai campi della classe con this o in modo implicito:

class Calculator {
    public var result;
    
    function Calculator() {
        result = 0;  // Implicit member access
    }
    
    public function add(value) {
        result = result + value;
        return result;
    }
}

10.5 Istanziazione degli oggetti

var obj = new ClassName(arg1, arg2);
var person = new Person("Alice", 25);

10.6 Accesso ai membri

var person = new Person("Bob", 30);
person.name = "Charlie";
var age = person.age;
person.setAge(31);

10.7 La keyword this

this indica l'istanza corrente dell'oggetto. È opzionale quando si accede alle variabili membro (è supportato l'accesso implicito):

class Counter {
    private var count;
    
    function Counter() {
        count = 0;  // Implicit member access
    }
    
    public function setCount(count) {
        this.count = count;  // 'this.' required due to name conflict
    }
}

10.8 Ereditarietà

Le classi possono ereditare da una classe padre con extends:

class Animal {
    public var name;
    
    function Animal(name) {
        this.name = name;
    }
    
    public function speak() {
        print(name + " makes a sound");
    }
}

class Dog extends Animal {
    function Dog(name) {
        super(name);  // Call parent constructor
    }
    
    public function speak() {
        super.speak();  // Call parent method
        print($"{name} also barks");
    }
}

10.9 Membri static

I membri static appartengono alla classe, non alle istanze:

class MathUtils {
    static var PI = 3.14159;
    
    static function add(a, b) {
        return a + b;
    }
}

var pi = MathUtils.PI;
var sum = MathUtils.add(5, 3);

10.10 Overload degli operatori

Le classi possono fare overload di operatori selezionati definendo metodi con nomi riservati. Per gli operatori binari, MALDA prova prima l'overload dell'operando sinistro (__add__, __sub__, ecc.). Se quell'overload non c'è, prova l'overload invertito dell'operando destro (__radd__, __rsub__, ecc.) passando l'operando sinistro come argomento. Per gli operatori unari, l'unico operando è il receiver.

/__div__(other)__rdiv__(other)

Se non esiste un metodo di overload corrispondente né a sinistra né a destra, MALDA usa il comportamento built-in dell'operatore.

class Value {
    public var data;

    function Value(data) {
        this.data = data;
    }

    public function __add__(other) {
        return data + other.data;
    }
}

var a = new Value(2);
var b = new Value(3);
print(a + b); // 5
class RightValue {
    public var data;

    function RightValue(data) {
        this.data = data;
    }

    public function __radd__(other) {
        return other + data;
    }
}

var rhs = new RightValue(7);
print(5 + rhs); // 12

10.11 Costruttori primari

Una lista di parametri dopo il nome della classe è un costruttore primario. Ogni parametro diventa un campo public con lo stesso nome, e MALDA sintetizza un costruttore che assegna quei campi. Il corpo opzionale è un corpo di classe normale (metodi, campi extra, membri static, overload degli operatori). Non c'è una keyword aggiuntiva: class Name( è distinto da class Name { e da class Name extends.

class Point(x, y);

class Point(x, y) {
    function distance() {
        return math.sqrt(this.x * this.x + this.y * this.y);
    }
}

var p = new Point(3, 4);
print(p.x);
print(p.distance());

Le forme sopra si espandono in una classe classica: campi public, un costruttore con lo stesso nome della classe che assegna this.x = x (e così via), poi gli eventuali membri del corpo. I type hint opzionali sui parametri vengono memorizzati su quei campi: class Point(x: float, y: float).

  • Solo dati: class Point(x, y); oppure class Point(x, y) { }.
  • Non dichiarare function Point(...) nella stessa classe (costruttore duplicato).
  • Non dichiarare var x nel corpo quando x è già un parametro primario.
  • extends non si può combinare con un costruttore primario. Usa una classe classica e chiama super(...).
  • Le istanze usano ancora l'uguaglianza per identità, a meno che tu non definisca __eq__.
class Point(x, y);
var p = new Point(3, 4);
print(p.x + p.y);
class Point(x, y) {
    function total() {
        return this.x + this.y;
    }
}
print(new Point(3, 4).total());
