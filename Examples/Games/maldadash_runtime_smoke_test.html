Maldadash

Loads the MALDA runtime and the compiled maldadash.js sample. Compile first:

malda compile Examples/Games/maldadash.malda --mode js -o Examples/Games/maldadash.js

Arrows / WASD / left stick / d-pad / click / touch to dig. SPACE or A starts. P or Start pauses. [ ] zoom, 0 resets, hold B to look. R restarts the cave. High score survives reload.
