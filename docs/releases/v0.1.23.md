# MALDA 0.1.23

Second Brain ASK: cookie JWT auth, multi-user registration, admin tools, retrieval quality, and ops endpoints.

## Highlights

- **ASK auth** — cookie JWT login on by default (`--no-auth` / `MALDA_ASK_AUTH=0` to disable). Bootstrap credentials via `MALDA_ASK_USER` / `MALDA_ASK_PASSWORD` (or `MALDA_ASK_PASSWORD_HASH`); default demo `admin` / `password`.
- **Multi-user registration** — `users.json` in the brain folder (or `.malda/ask_users.json` for embed). Open self-registration with `--allow-register` / `MALDA_ASK_ALLOW_REGISTER=1`.
- **Per-user history** — conversation state scoped as `u:{sub}:{convId}` when auth is on.
- **Admin UI** — `/admin/users` (role, enable/disable, reset password, delete) and `/admin/upload` (sync UPDATE into `sourceFolder`; not available for embedded packs).
- **Retrieval quality** — tag filters in the composer, minimum-score “no source” answers, optional **Force answer**.
- **Ops** — `GET /health`, append-only `ask_audit.jsonl`, thumbs feedback → `ask_feedback.jsonl`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.23-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.23-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.23
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
