# MALDA 1.0.6

Patch after 1.0.5: interpret debugger pause on a function's last expression.

## Highlights

- **Breakpoints on trailing `io.print`** — last-expression-wins no longer
  skips the interpret debug pause gate, so a breakpoint on a function's
  last expression statement (for example `io.print(...)`) stops in Desktop
  IDE, DAP, and the shared `DebugSession`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.6-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.6-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.6
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
