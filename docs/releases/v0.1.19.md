# MALDA 0.1.19

Web framework maturity: HTTP sessions with flash, form helpers, single-port RestServer mounting, and a lightweight SQLite job queue.

## Highlights

- **Sessions** — `enableSession` / `disableSession` on HttpServer and RestServer; `req.session` with `get` / `set` / `delete` / `clear` / `flash` / `getFlash` / `getFlashes` (signed session-id cookie; memory or SQLite store).
- **Form helpers** — `csrfField`, `bindForm`, `formErrors`, and `pageLayout` builtins for CSRF-aware HTML forms and simple `@PAGE` chrome (prefer `ui.layout` for rich layouts).
- **Unified host** — `HttpServer.mount(restServer)` serves API and UI on one listener; `new RestServer()` defers the port for mounted fullstack apps.
- **Jobs** — `enqueueJob` / `claimJob` / `completeJob` / `failJob` / `getJob` / `listJobs` on `./.malda/jobs.db`, separate from durable workflows.
- **Fullstack template** — single port `8080`, sessions, form helpers, and mount wiring; auth cookie example uses session flash instead of query-string errors.
- **Docs / LLM pack** — Reference Manual chapters 11, 16, 17, and 31 updated; `docs/llm/malda-builtins.tsv` synced; gotcha for `csrfField` vs `enableCsrf` cookie matching.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.19-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.19-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.19
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
