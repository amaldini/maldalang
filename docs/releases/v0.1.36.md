# MALDA 0.1.36

Second Brain ASK header brand alignment: left logo, product name, and right logo
share one vertical center; “Powered by …” stays under the title column.

## Highlights

- **ASK brand grid** — left logo aligns with the title + right-logo row (no longer
  centered against title + powered-by). Class `has-left-logo` places powered-by
  under the product name only.
- **Robust height host var** — missing `ASK_LOGO_RIGHT_HEIGHT` in older harnesses
  no longer breaks page render (defaults to 48px).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.36-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.36-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.36
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
