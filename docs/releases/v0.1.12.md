# MALDA 0.1.12

Patch release: semantic Second Brain ASK restores non-zero vector scores after load by fixing VectorDB serialization of GraphMemory payloads.

## Highlights

- **VectorDB preserves JsonObject payloads** — `serialize` no longer writes GraphMemory index data (`nodeId`, description, …) as `{}`. After load, `searchSimilar` can map hits again so hybrid ASK sources show real `vec` scores alongside `lex`.
- **Load repair for older brains** — if a saved `.vectordb.bin` has vectors but no mapped `nodeId`s, GraphMemory rebuilds the vector index from metadata on `load` (first ASK may re-embed once).
- **Hybrid ranking** — BM25 blend reuses any existing vector score for the same node instead of forcing `0.0`.
- **Hit extraction** — `TryExtractSearchHit` accepts both `JsonObject` and `DictionaryInstance` payloads from deserialized VectorDB entries.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.12-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.12-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.12
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
