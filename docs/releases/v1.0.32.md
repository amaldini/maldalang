# MALDA 1.0.32

Patch after 1.0.31: a `function` declared inside a block is local to that
block. The body sees the enclosing variables, and the name is gone when
the block ends.

## Highlights

- **Nested functions** — a `function` inside a block, another function, a
  loop, or a `match` arm is visible only in that block. The body reads
  parameters and variables from the enclosing scopes, including values
  assigned before the call. Call it after the declaration. You can pass it
  as a value, the same way as a top-level function.
- **Backends** — the interpreter, C# transpile
  (`malda compile --mode transpile`), and JavaScript agree. Chapter 9
  documents the shared block scope.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.32-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.32-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.32
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
