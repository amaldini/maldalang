# MALDA 1.0.8

Patch after 1.0.7: rename and find-references see identifiers inside
string interpolation, plus Reference Manual Pages and Italian STATUS
fixes that landed after 1.0.7.

## Highlights

- **Rename inside `$"..."`** — rename, find-references, highlights, and
  prepare-rename now include identifiers in interpolated strings
  (`$"hello {name}"` and `$"""...{name}..."""`), including when the
  cursor is on the name inside the braces. Plain strings that only
  look like `{name}` are left alone.
- **GitHub Pages manual links** — Reference Manual `.md` hrefs resolve
  to GitHub blob URLs on Pages so they are not 404s.
- **Italian STATUS hashes on Windows** — `it/STATUS.md` hashes
  LF-normalized English HTML so CRLF checkouts match.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.8-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.8-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.8
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
