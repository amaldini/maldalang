# MALDA 0.1.0

First public drop of the open-source MALDA core.

## Highlights

- Language runtime, C# / JS transpiler, CLI (`malda`), Web IDE, Desktop IDE (Windows), LSP, VS Code extension
- AI primitives (`prompt`, agents, tools, MCP), durable workflows, REST / `@PAGE` / `@AIPAGE`
- Dual licence MIT OR Apache-2.0, plus a runtime exception for compiled programs
- Linux CI builds the cross-platform projects and runs `hello_world.malda` through the CLI

## Requirements

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.0-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.0-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.0
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

## Notes

- This is **0.1.0**, not a 1.0 language release. The language specification remains **Draft 1.0** (`docs/spec/malda-language-1.0.md`).
- AI features without `OPENROUTER_API_KEY` fall back to a local ~500 MB GGUF download on first use; see the README.
- Product apps built with MALDA privately (CRM, SchoolPrep, etc.) are **not** in this repository.
