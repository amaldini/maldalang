# MALDA 0.1.20

Quality roadmap release: onboarding/docs alignment, literal type-hint warnings, backend capability matrix, examples catalog, and macOS CI smoke.

## Highlights

- **Literal type warnings** — IDE/LSP Warning when a type hint disagrees with a literal initializer (`var n: int = "abc"`); runtime remains dynamic.
- **Backend capability matrix** — product-facing Interpreter / C# / JS support table with a guard against drift from `BackendCapabilityMatrix`.
- **Examples catalog** — `Examples/README.md`, folder READMEs, optional `requires` metadata, fullstack sessions/auth/jobs tutorial, `job_queue_basic.malda`, `schema_validate.malda`.
- **LLM pack** — synced to this release (sessions, CSRF, mount, jobs, validate gotchas); planning docs banner as historical.
- **Ops** — `macos-latest` CI smoke (CLI + guards); micro-benchmark script (`scripts/run-micro-benchmarks.ps1`); soft freeze policy for new builtins in `AGENTS.md`.
- **Web IDE** — Offline-friendly example filter using metadata `requires`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS now has a CI smoke job)

## Install without sources

Download `malda-0.1.20-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.20-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.20
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
