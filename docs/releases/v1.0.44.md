# MALDA 1.0.44

Patch after 1.0.43: `@shader()` functions the host can call, and a 3D maze
chase on the SDF interpreter shader.

## Highlights

- **Host-callable `@shader()` functions (G23)** — a pure shader kernel that
  host code calls by name is also emitted as JavaScript, so an SDF game no
  longer keeps a hand-written host copy of each distance function. Kernels
  read top-level MALDA `const` values (the compiler writes them into the
  GLSL, so a `consts:` list is no longer needed), `glsl.host("name", material)`
  binds a kernel to a material so it reads that material's uniforms and data
  textures, and `out` parameters work between host-called kernels. GPU-only
  constructs in a host-called kernel are compile errors. See
  `docs/javascript-backend.md` and `docs/roadmap-games.md`.
- **SDF examples on one source** — `three_sdf_interpreter.malda` picks through
  `glsl.host`, and `three_sdf_invaders.malda` tests its shields with the
  shader's own `sdShield` and `cutDistance`. Both declare opcodes and shape
  kinds once, as MALDA consts.
- **SDF Pac-Man** — `Examples/Games/three_sdf_pacman.malda` is a 3D maze chase
  on the same bytecode shader. Three mazes take turns as the levels go up,
  rising out of the floor and sinking when cleared. V switches between the
  whole maze, a close follow and a chase camera. The muncher, the ghosts and
  the power dots light the floor and the walls, and a power dot sends a
  shockwave ring across the floor. Collisions call the shader's own
  `sdGhostBody` and `sdGem`. The music is a chiptune written in the file as
  note lists and played with `game.audioPlayPattern`; it changes with the
  game. Run it with `malda play`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.44-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.44-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.44
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
