# MALDA 1.0.24

Patch after 1.0.23: a neural-nets kit students can run without a
training framework, a playable chess example, and JS `array.pop` so
undo no longer freezes the game loop.

## Highlights

- **Neural-nets kit** — `math.dot` / `matmul` / `transpose`, activations
  (`relu` / `sigmoid` / `tanh`), and `math.mse` on interpreter, C#, and
  JS. The AI_Theory track adds perceptron, softmax, 2D hash embeddings +
  VectorDB neighbors, and host-only `new OnnxModel(path)` inspect +
  forward (`Examples/AI_Theory/`). `malda play
  Examples/Games/xor_decision_boundary.malda` draws the XOR surface
  (sigmoid applied once so the map is not a single color).
- **Chess** — `Examples/Games/chess.malda` is a turn-based rules
  showcase: Staunton silhouettes, named piece/square/move constants, and
  a CPU depth picker (1–3 ply) instead of a hardcoded 2-ply search.
- **JS `array.pop`** — the JavaScript backend implements `pop`, so
  chess undo no longer throws and freezes the game loop.
- **Docs** — function arguments are passed by sharing (callers are not
  aliased). The reference manual cites the Windows `win-x64` zip and
  `MaldaDesktop.bat` as the install path.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.24-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.24-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.24
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
