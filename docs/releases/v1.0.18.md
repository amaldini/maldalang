# MALDA 1.0.18

Patch after 1.0.17: agentic-run constructs as a first-class surface,
IDE recognition of `@pure` / `@effects`, and Reference Manual chapter 23.

## Highlights

- **Agentic runs** — Test, record, time-limit, remember, restrict, and
  diagnose prompt/agent programs: `suite` / `evalPrompt` / `expect`,
  LLM cassettes (`MALDA_RECORD` / `MALDA_REPLAY`), `trace.journal()`,
  `within`, declared `context`, file-level `policy`, `AgentError`,
  `stream` + `for await`, `grounded.wrap`, and `malda check --fix`.
  Interpreter and C# transpile agree on the offline examples; JavaScript
  is host-only. Reference Manual §23. Examples under
  `Examples/Prompts/` and few-shots `43_`–`48_`.
- **Language service** — `@pure` and `@effects` are recognized so the
  IDE/LSP does not flag them as unknown attributes.
- **Reference Manual** — Chapter 23 teaches the constructs in the same
  second-person voice as the rest of the book.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.18-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.18-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.18
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
