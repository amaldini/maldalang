# MALDA 1.0.0

Toolchain **1.0.0** — the CLI and Desktop IDE now share the Spec Final 1.0
number. Interpret stays dynamic. Publish is the type contract boundary.

## Highlights

- **Version** — `<Version>1.0.0</Version>` in `MaldaLang.csproj` and
  `MaldaLang.DesktopIDE.csproj`. Zip names from `build-oss-dist.ps1` follow
  the CLI csproj (`malda-1.0.0-win-x64.zip` / `malda-1.0.0-linux-x64.zip`).
- **Publish contract** — `malda compile --mode transpile` and `publish`
  run `StrictTypesAnalysis` (`Enabled`) and refuse emit on Errors
  (`var n: int = "abc"` does not produce an `.exe`). Escape: `--lenient-types`.
  `malda run` stays opt-in `--strict-types`.
- **Smoke** — README shippable examples are in `TranspileSmokeTests` or
  marked `n/a` (Second Brain, RalphWiggum). One interpret/transpile pair
  checks the same stdout.
- **Loud gotchas** — IDE `malda-interp` warns on plain `{ident}` strings
  outside prompt bodies; `parseJson` / `parseJSON` arity errors name the other
  builtin.
- **`function` only** — `fn` / `def` are syntax errors (Unreleased spec MAJOR).
- **First impression** — `Examples/Basics/first_look.malda` is the lead file;
  the review prompt binds `-> Review`.
This is not a full static type system, a Temporal cluster, or JS/Desktop
parity. Remaining honesty items stay in [`docs/announcement.md`](../announcement.md).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.0-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.0-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.0
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
