# MALDA 0.1.49

Second Brain ASK can hide or rewrite the header “Powered by …” line from the CLI.

## Highlights

- **`--no-powered-by`** — clears `ASK_POWERED_BY` / `ASK_POWERED_BY_URL` so the ASK
  header omits the powered-by line (useful for internal deployments).
- **`--powered-by <text>`** / **`--powered-by-url <url>`** — override the line and
  optional link; empty URL clears the link while keeping custom text.
- **`MALDA_ASK_POWERED_BY=0`** (also `false` / `off` / `no`) — same hide behavior via
  environment; CLI flags win over env.
- **Tests** — CLI parse coverage and host wiring guards for the new flags.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.49-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.49-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.49
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
