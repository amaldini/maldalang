# MALDA 1.0.28

Patch after 1.0.27: a fixed stack of dense layers can be defined and
trained in a few lines. The from-scratch neural track is cited on the
README and the manual home.

## Highlights

- **`Dense` and `Sequential`** — host classes. `forward` / `backward`
  call `nn.dense` / `nn.denseBackward`. `sgd` applies the stored
  gradients. `Sequential.fit` is online SGD and returns the mean loss
  of the last epoch. `loss` is `"mse"` (default) or `"crossEntropy"`.
  There is no autograd tape and no Adam.
- **`nn.sequential`** — the same stack from rows
  `[in, out, activation?, scale?]`. Default scale is `1/sqrt(in)`,
  drawn with the `math.seed` generator.
- **`Examples/AI_Theory/sequential_xor.malda`** — the 2-4-1 XOR net.
  `xor_neural_net.malda` and `nn_dense.malda` stay handwritten.
- **Reference Manual 14.9** — signatures for `Dense`, `Sequential`,
  and `nn.sequential` (Italian: the same section). The README and
  both manual homes point at the AI theory track in Start Here.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.28-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.28-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.28
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
