# MALDA 0.1.51

P0 maturity horizon closed: Spec **Final 1.0**, tighter types/tooling, workflow ops,
backend contracts, AI/UI/packages, and `export type` / `export schema`.

## Highlights

- **Spec Final 1.0** — Tier 0 conformance green; post-Final gaps owned in
  [`docs/spec/CHANGELOG.md`](../spec/CHANGELOG.md) (async env race remains doc-only).
- **Types / IDE** — call-site + Tier-1 return inference; type mismatches are **Errors**
  by default in LSP/Desktop (`malda.types.strict` / View menu opt-out); nested schema
  IDE diagnostics.
- **Workflows** — `malda workflow report`, HA single-writer note, WF1001/WF1002
  determinism (incl. `sleep`) with IDE static checks.
- **Backends** — product capability matrix rows; curated `TranspileSmokeTests` in CI.
- **AI / UI** — tools vs `response_format` Modes A/B/C; agent governance golden;
  UI1001–UI1003 event-loop and state-lifecycle diagnostics.
- **Modules / packages** — selective `import { … } from`; workspace `packages/` story;
  **`export type` / `export schema`** (constructors expand on selective import).
- **Toolchain** — transpile debug guide + CLI hint; micro-benchmarks sample; LSP
  schema/type hover + symbols; Linux/macOS contributor path without Desktop.
- **Docs** — P0 roadmap marked complete; gotchas for async race and export surface.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.51-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.51-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.51
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
