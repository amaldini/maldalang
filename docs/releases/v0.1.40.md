# MALDA 0.1.40

HttpServer can bind all interfaces and terminate TLS with a certificate, and
Second Brain ASK exposes matching CLI flags for LAN / Internet HTTPS.

## Highlights

- **`HttpServer` bind host** — optional host / `setHost`, property `.host`, env
  `MALDA_HTTP_HOST`. Use `0.0.0.0` or `*` to listen on all interfaces (not only
  localhost).
- **HTTPS** — `enableHttps(certPath, password?)` / `disableHttps()`, properties
  `.https` / `.certPath`, env `MALDA_HTTP_HTTPS` / `MALDA_HTTP_CERT` /
  `MALDA_HTTP_CERT_PASSWORD`. Accepts `.pfx`/`.p12` or `.pem`/`.crt` with a
  sibling `.key`. Kestrel terminates TLS and proxies to the loopback
  `HttpListener`; secure cookies / sessions honor `X-Forwarded-Proto`.
- **Second Brain ASK** — `--host`, `--https --cert <path> [--cert-password]`;
  Open URL uses `https://` and auth cookies set `Secure` when HTTPS is on.
- **Docs / tests** — Reference Manual §16; filtered `HttpServerTests` and
  `SecondBrainAskFeaturesTests` coverage.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.40-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.40-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.40
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
