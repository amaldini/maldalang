# MALDA 1.0.19

Patch after 1.0.18: specialized agent kinds documented as tool bundles,
and Reference Manual REST chapters aligned with the runtime.

## Highlights

- **Agent kinds** — `CodingAgent` / `GitAgent` / `DevAgent` /
  `MALDACodingAgent` are tool bundles, not sandboxes. Constructors do
  not take `cap.*`; `workingDirectory` is a string prefix; `policy { }`
  does not gate their default string-path tools. Reference Manual §18,
  gotchas, and the LLM syntax pack. No runtime change.
- **REST manual** — Chapter 28 documents the real `RestServer` pipeline
  and APIs, plus a self-contained web-concepts primer (REST, middleware,
  auth, JWT, CSRF, CORS, HTTPS). Chapters 29–30 document `RestClient`
  and `mount` to match the host. Section numbers in chapters 24–38 now
  follow `chapters.json`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.19-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.19-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.19
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
