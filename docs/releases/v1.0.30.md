# MALDA 1.0.30

Patch after 1.0.29: chapter 14 says who the neural-nets chapter is for,
walks one policy step, and the canvas demos train a driving net, a digit
conv net, and a reward the user can rename in a sentence. The Desktop IDE
lists those classes in completion and docks program output on the right.

## Highlights

- **Chapter 14** — the opening says the chapter is optional: skipping it
  leaves prompts, agents, and the rest of MALDA unchanged. Section 14.5.2
  walks one policy update. The scale on `nn.softmaxGrad` is the return
  minus a baseline.
- **`reinforce_bandit.malda`** — one-step REINFORCE. The state is `+1` or
  `−1`, the hidden layer is `tanh`, and the two logits are `linear`.
- **`conv_classifier.malda`** — the 5×5 dashes from `conv_stroke.malda`
  through `new Conv(3)` and a sigmoid `Dense`. The map is flattened, and
  the dense input gradient is reshaped into `Conv.backward`.
- **Canvas demos** — `grand_prix_neural.malda` fits one 12-20-2 net to a
  pure-pursuit coach on eight circuits. `digits_cnn.malda` trains a
  four-filter conv net, then classifies a digit drawn on a 16×16 page.
  `spoken_reward.malda` fits a 4-12-1 net to a reward painted or named in
  a sentence; the creature follows the net, so it keeps the old hill for
  a moment after the sentence changes.
- **Desktop IDE** — completion lists neural-net classes and `nn` members.
  Program output docks on the right by default. Dialogs, the command
  palette, and keyboard-shortcut chrome follow the IDE theme.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.30-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.30-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.30
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
