# MALDA 0.1.53

Reference Manual reading order, filenames, and stdlib catalog cleanup, plus class
primary constructors and Web UI event-loop fixes that landed after 0.1.52.

## Highlights

- **Reference Manual** — chapters sit in contiguous menu categories; HTML filenames
  match display numbers (`02-tools.html`, `23-web-ui.html`, `34-grammar.html`);
  `result` / `option` are documented; Built-in Functions `12.20`–`12.24` are named
  indexes into Agent Orchestration, Durable Workflows, Functions, .NET Interop, and
  Web UI. Chapter headers stamp the CLI version.
- **Language** — `class Name(params)` desugars to public fields and a constructor
  (cannot combine with `extends` or an explicit constructor of the same name).
- **Web UI** — `ui.dispatchEvent` honors `sessionId` in the three-argument form; the
  event-loop snippet dispatches on the named session; hub/docs cover UI models and
  control props.
- **Toolchain** — Linux CI finds the Unix apphost after transpile publish; the bound
  manual uses a replaceable full-bleed SVG cover.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.53-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.53-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.53
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
