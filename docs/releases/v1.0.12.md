# MALDA 1.0.12

Patch after 1.0.11: the JS `game.*` / `three.*` kit through G17, Desktop
IDE JavaScript and full-stack debug, `malda check --json`, and host-side
prompt/agent scaffolding.

## Highlights

- **Games kit G0–G17** — JavaScript `game.*` now covers images / atlas /
  camera / zoom / `drawImageEx`, key edges + touch + gamepad, AABB and
  swept collision (`sweepRect` / `sweepRects` / `sweepTiles`), sample SFX
  with pan and playback rate, `startFixed` plus origin save/load, tint and
  blend modes, and tile helpers (`drawTiles` / `tileAt`). `three.*` loads
  textures and glTF and has `lookAt`. Scaffolds: `malda new game`,
  `malda play`, and `malda new game --fullstack`. Showcases:
  `malda_platform`, Maldanoid, and Maldadash.
- **Desktop IDE debug** — F5 on `dom.*` / `game.*` / `three.*` uses the
  WebView2 Chromium debugger with JS source maps. Full-stack files start
  interpret on the host partition and WebView2 on the client. Web preview
  and the AI panel can maximize/restore; preview assets resolve from the
  open `.malda` file.
- **`malda check --json`** — Parse and diagnose a program without
  executing it. `--json` is the generate → diagnose → patch report
  (`ok`, `executed: false`, 1-based `diagnostics[]`).
- **`asVariant`** — Coerce a tagged dict into a sum-type variant for
  `match`. `validate()` stays non-coercing. Interpreter, C# transpile,
  and JS share the path.
- **Prompts and agents** — In-process GGUF sampling uses schema GBNF for
  Mode A / Mode C extract. Mode B sends `response_format` with tools when
  the backend allows it. `evalPrompt` fixtures, `program(Api)` few-shots,
  `runProgram` inside a durable `step`, and `malda new agent` with
  host-minted `cap.*` file tools.
- **Runtime** — Overlapping `async` user tasks that `sleep` no longer
  share interpreter state. `result.andThen` / `option.andThen` sequence
  Result and Option.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.12-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.12-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.12
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
