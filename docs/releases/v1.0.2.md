# MALDA 1.0.2

Patch after 1.0.1: Second Brain ASK 0.2 — live draft, citations, rerank,
incremental GraphMemory UPDATE, and a public-bind credential gate.

## Highlights

- **ASK live draft** — `think()` streams answer tokens as `{ phase: "draft" }`
  when `onAgentProgress(liveChannel)` is set. The ASK UI shows the draft over
  the existing SSE channel.
- **Clickable citations** — ASK rewrites `[nota: slug]` to in-page source
  links, marks cited chips, and opens a note preview.
- **GraphMemory rerank** — semantic ASK reranks hybrid hits with
  `rerankMode: cross` by default (local). Optional ONNX when `model.onnx` +
  `vocab.txt` are present. CLI: `--rerank off|cross|onnx`.
- **Incremental UPDATE** — unchanged notes keep `memoryNodeId` and are
  skipped; new/changed notes are upserted; deleted notes are forgotten.
- **Shared `sb/` includes** — BUILD/ASK helpers live under
  `Examples/Agents/sb/` (i18n, LLM, text, distill, build, ask-common, memory).
- **Public-bind gate** — ASK refuses public binds with default credentials.
- **Retrieval eval** — offline lexical gold set and hit@K runner
  (`Examples/Agents/sb/eval/run_retrieval_eval.malda`, no LLM).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.2-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.2-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.2
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
