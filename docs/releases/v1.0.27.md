# MALDA 1.0.27

Patch after 1.0.26: neural-net helpers live on `nn`, and the reference
manual teaches one dense layer instead of leaving that model in the
builtin catalog.

## Highlights

- **`nn` namespace** — activations, local derivatives, `nn.dense` /
  `nn.denseBackward`, and the loss gradients `nn.mseGrad` /
  `nn.softmaxGrad`. `nn.dense` returns `{ pre, out }`. `pre` is
  `xW + b` before the nonlinearity; `out` is `activation(pre)`. There
  is no autograd tape: the backward step uses the saved `pre`.
- **`relu`, `mse`, and `crossEntropyFromLogits` are only on `nn`.**
  `sigmoid`, `tanh`, and `softmax` stay on both `math` and `nn`.
  `dot`, `matmul`, and `transpose` stay on `math`.
- **Reference Manual chapter 14** — Neural Nets (Italian: Reti neurali),
  with runnable snippets for one forward and one backward step.
  Former chapters 14–38 are now 15–39. Signatures remain in 13.3.3.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.27-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.27-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.27
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
