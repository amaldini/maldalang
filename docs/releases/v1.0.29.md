# MALDA 1.0.29

Patch after 1.0.28: convolution, embedding, a recurrent step, layer norm,
and one attention head follow the same `forward` / `backward` / `sgd`
contract as `Dense`. Chapter 14 works the dense step on checkable numbers.

## Highlights

- **`Conv`, `Embedding`, `Rnn`, `LayerNorm`, `Attention`** — host classes
  on the interpreter, C# transpile, and JavaScript. Each owns its
  parameters. `forward` remembers the input, `backward` stores gradients,
  `sgd(lr)` subtracts in place. There is no autograd tape and no Adam.
- **`Conv`** — one channel, square kernel, valid convolution, no bias.
- **`Embedding`** — table lookup. The gradient lands only on the selected
  integer row.
- **`Rnn`** — a sequence. The hidden state starts at 0 on each `forward`.
  Backward is BPTT from the last step. The default activation is `tanh`.
- **`LayerNorm`** — gamma starts at 1, beta at 0. Epsilon is `0.00001`
  inside the square root.
- **`Attention`** — owns query and key. Value and an optional mask are
  `forward` arguments. A mask entry below `0.5` fills that score with
  `-1e9` and blocks its gradient. The default score scale is `1/sqrt(dim)`.
- **Reference Manual 14.10** — one runnable numeric probe for each layer
  (Italian: the same section). Chapter 14 also walks the dense step, the
  losses, and `Sequential.fit` on checkable numbers.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.29-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.29-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.29
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
