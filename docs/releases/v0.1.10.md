# MALDA 0.1.10

Patch release: GraphMemory gains native multi-tags, automatic lexical floor when vectors are weak, and non-breaking query diagnostics; Second Brain explorer and chunk limits are hardened.

## Highlights

- **GraphMemory tags** — `remember` metadata `tags` (array or CSV; normalized), query filters `tags` / `tagsMode` (`any`|`all`), and `forgetByTag`. Tags are appended to the indexed description so BM25/vector search can see them. Semantic Second Brain indexes `note.tags` alongside `category`.
- **`lexicalMinScore: "auto"`** — with `hybridLexical`, uses floor `0` when the vector channel is empty/failed, otherwise `0.15` (numeric default unchanged).
- **Query diagnostics** — `query` still returns an array; `getLastQueryDiagnostics()` reports candidate/drop counts and applied lexical mode. `explain: true` includes node `tags` / `tagsMatched`.
- **Second Brain BUILD** — explorer prompts + JSON coercer for thinking models (DeepSeek empty content); `MAX_CHUNKS` raised 3 → 15 for long documents.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.10-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.10-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.10
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
