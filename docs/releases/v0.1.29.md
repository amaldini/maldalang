# MALDA 0.1.29

Desktop and Web IDE AI now use the embedded `docs/llm/` language pack instead of a hardcoded language specification.

## Highlights

- **IDE AI ← language pack** — Ask / AskMalda sessions materialize `docs/llm/` into a per-session `llm/` directory (syntax, gotchas, grammar, builtins, few-shots) plus live `DECORATORS.md` from `LanguageService`.
- **Single source of truth** — the pack is embedded in `malda.dll` (`MaldaLang.LanguagePack.*`); no checkout path required at runtime. Web Ask mode boots with syntax + gotchas via `GetInlineBootContext()`.
- **Guard** — `IdeLanguagePackEmbedGuardTests` keeps embedded resources aligned with on-disk `docs/llm/`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.29-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.29-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.29
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
