# MALDA 1.0.43

Patch after 1.0.42: a 3D space-invaders game on the SDF interpreter shader, and
a refreshed README.

## Highlights

- **SDF Invaders** — `Examples/Games/three_sdf_invaders.malda` is a 3D
  space-invaders game raymarched by one shader. Invaders, the cannon, shots,
  the saucer, goo explosions and shockwaves are instructions in a float data
  texture that the host rewrites every frame; the shader is compiled once and
  never changes. A shield hit appends a CUT instruction that carves a glowing
  crater, and the host runs the same shield bytecode to decide whether a shot
  hit material or flew through an old hole. A post pass adds FXAA (X) and an
  optional CRT mode (C). Run it with `malda play`.
- **README** — the front page now covers the JavaScript platform (`import js`,
  ES modules, typed buffers, worker actors, client-side `ui.*`, `io.store*`),
  games and graphics, and the `fmt` / `lint` / `test` / `debug-adapter`
  commands, with an SDF Invaders screenshot. License, scope and project notes
  are shorter.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.43-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.43-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.43
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
