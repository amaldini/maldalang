# MALDA 0.1.42

A PowerShell helper updates a local Windows x64 install from the latest GitHub
Release zip.

## Highlights

- **`scripts/update-local-win-x64-release.ps1`** — downloads
  `malda-*-win-x64.zip` from GitHub Releases and merges it into a local install.
  Defaults to `$env:MALDA_HOME` or the parent of the script folder
  (`<install>\scripts\..`); optional `-Tag`, `-Force`, `-WhatIf`. Preserves
  extra local files, replaces `bin/`, and records the tag in `.malda-release`.
- **Win-x64 dist** — the update script is shipped under `scripts/` in the
  Windows zip so you can run it from the install folder.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.42-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.42-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Later, update in place from the install folder:
powershell -File scripts\update-local-win-x64-release.ps1

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.42
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
