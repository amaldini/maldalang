# MALDA 0.1.7

Patch release: typed transpile for Agent / CodingAgent / OpenRouterClient construction, optional `Agent` client, and void-safe last-expression returns so Second Brain examples compile in transpile mode.

## Highlights

- **Agent construction in transpile** — `new Agent` / `CodingAgent` / `GitAgent` / `HumanAgent` / `MALDACodingAgent` coerce object-typed parameters and resolve optional clients the same way the interpreter does; `OpenRouterClient(model)` coerces the model string.
- **Optional `Agent` client** — `new Agent(name, role, instructions)` uses the default local LLM (parity with CodingAgent); documented in the Reference Manual and LanguageService.
- **Void-safe last-expression-wins** — functions ending in `print` / `io.print` / `AnsiConsole.markupLine` no longer emit `return void` (CS0029).
- **Second Brain transpile** — `Examples/Agents/secondbrain.malda` and `secondbrain_semantic.malda` compile successfully with `--mode transpile`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.7-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.7-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.7
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
