# MALDA 0.1.31

Tighten announcement and README copy so the “how it was built” story is not restated
three times.

## Highlights

- **Announcement / README** — drop repeated “built heavily with coding agents / grammar is
  mine” blocks; keep one origin story, then guard tests and the agent-written showcases.
- **Show HN short version** — same trim: background and Huntley without reopening on
  “heavily with agents.”

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.31-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.31-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.31
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
