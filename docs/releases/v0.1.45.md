# MALDA 0.1.45

Second Brain ASK live tool/LLM round progress stays visible on smartphones.

## Highlights

- **ASK live rounds on mobile** — `#ask-live-dock` stays outside the panel
  fragment and floats fixed above the sticky Ask composer instead of mounting
  inside it (where tall phone layouts hid “Round N”).
- **Round-only SSE updates** — progress refresh no longer requires a message
  body; round changes repaint the dock and in-answer live status.
- **Viewport sync** — dock position tracks resize / scroll / `visualViewport`
  so the soft keyboard does not cover rounds.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.45-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.45-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.45
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
