# MALDA 0.1.9

Patch release: portable semantic Second Brain ASK packs LLamaSharp correctly, and GraphMemory / ASK UX recover more reliably when embeddings are weak or the LLM is still running.

## Highlights

- **Auto-include LLamaSharp on compile** — sources that use `LlamaEmbedder` (including `secondbrain_semantic.malda` PACK / `compileMALDA`) publish with LLamaSharp + CPU backend so a `.gguf` beside the `.exe` can load instead of silently falling back to `embedHash`.
- **`getProgramDirectory()` for portable exes** — ignores the transpiled placeholder path and prefers the running executable directory, so assets next to the `.exe` (BGE-M3 GGUF) resolve even when the process CWD differs.
- **GraphMemory `lexicalMinScore`** — query option (default `0.15`); semantic Second Brain ASK uses `0` so hybrid BM25 still contributes when vector scores are weak.
- **Semantic ASK hardening** — catalog note mapping by normalized path/slug, GraphMemory cache across turns, louder LlamaEmbedder warmup/failure logs, and ASK web UI pending-turn placeholder if the page is refreshed while the LLM runs.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.9-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.9-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.9
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

Portable semantic ASK after a BUILD has produced `secondbrain_semantic/`:

```bash
malda compile Examples/Agents/secondbrain_semantic.malda -o dist/secondbrain_semantic.exe --mode transpile --embed-folder secondbrain_semantic
# copy bge-m3-Q4_K_M.gguf next to the .exe for neural retrieval
```
