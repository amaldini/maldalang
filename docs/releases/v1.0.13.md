# MALDA 1.0.13

Patch after 1.0.12: MCP tool schemas with host validation, prompt
attachments for HTTP vision clients, Second Brain ASK abort/source/upload,
and Reference Manual SQL chapter alignment.

## Highlights

- **`@MCPTool` / `@Tool` schema names** — The third argument can be a
  MALDA schema name (`"AddArgs"` or the identifier `AddArgs`). Advertised
  `inputSchema` comes from that schema. The host validates args before the
  body on `callTool` / `tools/call` / `execute` / agent invoke. JSON object
  strings remain valid for enums and defaults. Example:
  `Examples/MCP/mcp_schema_tool.malda`.
- **Prompt attachments** — `attachments:` on a prompt send images and
  PDFs as OpenAI content parts on HTTP vision clients. In-process GGUF
  stays text-only and throws rather than stripping. Example:
  `Examples/Prompts/multimodal_attachments.malda`.
- **Second Brain ASK** — `cancelThink` aborts in-flight GGUF and HTTP
  generation. `res.json` flushes so POST handlers can return before slow
  work. Admin upload accepts PDF and DOCX. `GET /source` plus
  `res.sendBase64` opens the original file. Live docs snapshot into
  `brain/sources` so UPDATE still works when the original folder is gone.
  Weak retrieval retries with prior questions.
- **SQL Reference Manual** — Chapter 16 covers the SQL clients, query
  builder, and `malda db`. Chapter 29 reads the new SQLite key with
  `last_insert_rowid()` instead of a fictional `lastInsertId`.
- **Games and IDE** — The GPU raytracer example hits cubes, prisms,
  cylinders, and cones. Desktop IDE Syntax Helper covers landed constructs.
  Maldanoid keeps the HUD off the playfield and uses exact collision for
  falling pickups.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.13-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.13-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.13
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
