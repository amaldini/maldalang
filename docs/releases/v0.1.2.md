# MALDA 0.1.2

Patch release: semantic Second Brain example (GraphMemory + multilingual embeddings) and `getProgramDirectory()`.

## Highlights

- **`Examples/Agents/secondbrain_semantic.malda`** — sibling of `secondbrain.malda` for A/B comparison. Same BUILD distillation; ASK retrieves via GraphMemory hybrid search (vector + BM25). UI hints when GraphMemory returns notes outside the lexical top‑K.
- **Local multilingual embedding GGUF** — expects `bge-m3-Q4_K_M.gguf` (~438 MB, BGE-M3, 1024‑dim, 100+ languages) next to the `.malda` or compiled `.exe`. If missing, falls back to `embedHash` and shows the Hugging Face download link.
- **`getProgramDirectory()`** — returns the directory of the running `.malda` script (interpreter) or of the compiled executable (`AppContext.BaseDirectory`). Documented in the Reference Manual and agent builtins table.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.2-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.2-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.2
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

Lexical vs semantic Second Brain:

```bash
dotnet run --project MaldaLang -- Examples/Agents/secondbrain.malda
dotnet run --project MaldaLang -- Examples/Agents/secondbrain_semantic.malda
```

For neural / multilingual ASK, place the GGUF beside the example (or beside a compiled exe):

```text
https://huggingface.co/gpustack/bge-m3-GGUF/resolve/main/bge-m3-Q4_K_M.gguf
→ Examples/Agents/bge-m3-Q4_K_M.gguf
```
