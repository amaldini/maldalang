# MALDA 0.1.11

Patch release: portable Second Brain ASK (transpile/embed exe) keeps answers and GraphMemory hybrid retrieval working after LLM completion; logo/header layout and pack `-o` naming from the previous commit are included.

## Highlights

- **ASK page updates after the answer** — transpiled `ui.state` arrays now round-trip through a stable `List<object>` bridge so `append` / replace + `ui.setState` persist. ASK history helpers rebuild the list before `setState`. HttpServer redirects accept `DictionaryInstance` status payloads as well as `JsonObject`.
- **GraphMemory on portable/transpile** — query options and remember metadata accept `DictionaryInstance` (coerce to `JsonObject`); custom embedders via `TranspiledDelegate` are invoked; unary funcs passed to object methods stay callable. Richer empty-hit diagnostics in semantic Second Brain (`hybrid`, `lexMode`, `vec`, `bm25`, `embedReady`).
- **ASK branding** — logo CSS no longer forces width/background/border; main width can grow with a wide logo.
- **Pack `-o` naming** (also in the commit ahead of this tag) — multi-file LLamaSharp packs honor the named `-o` exe; Second Brain PACK defaults to `SecondBrain.exe`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.11-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.11-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.11
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
