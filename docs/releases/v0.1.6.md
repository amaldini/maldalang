# MALDA 0.1.6

Patch release: locale-safe C# transpile for float literals, safer Spectre markup, Second Brain PACK UX, and release version guards.

## Highlights

- **Invariant float literals in transpile** — `0.5` no longer becomes `0,5` under Italian (and other comma-decimal) locales, which broke mode-4 PACK with CS1001.
- **Safer `AnsiConsole.markup` / `markupLine`** — unparseable markup (e.g. MSBuild paths in `[...]`) prints literally instead of aborting with Spectre “Could not find color or style”.
- **Second Brain PACK (mode 4)** — directory output paths resolve to `<dir>/<default>.exe`; compile errors escape Spectre brackets.
- **Release version guard** — CLI/Desktop `<Version>` must match the latest `docs/releases/v*.md`; tag pushes must match both csproj files before zips are built.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.6-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.6-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.6
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
