# MALDA 0.1.16

Second Brain ASK multi-conversation: isolated browser threads via `?c=` + cookie, per-conversation SSE progress, and concurrent asks that no longer share a global agent-progress channel.

## Highlights

- **ASK multi-conversation (no auth)** — each browser thread uses a conversation id in `?c=` (canonical URL) and cookie `malda_ask_c`. History, language, tools toggle, and flash errors are per conversation; catalog, session meta, and branding stay shared for the ASK process.
- **Per-conversation live progress** — SSE / `onAgentProgress` use channel `ask-{c}` so concurrent asks from different clients stay isolated.
- **Concurrent progress runtime** — agent progress live channel is stored in `AsyncLocal` (with a static fallback for single-threaded hosts/tests).
- **UI** — “New conversation” / “Nuova conversazione” mints a fresh `c`; Clear resets only the current thread.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.16-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.16-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.16
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

- Still **0.1.x**, not a 1.0 language release. Spec remains **Draft 1.0** (`docs/spec/malda-language-1.0.md`).
- Conversation state is in-memory for the ASK process lifetime (no disk persistence / auth). Anyone who knows `?c=` can open that thread on the same host.
- Recompile portable Second Brain ASK exes after upgrading so they pick up multi-conversation isolation.
