# MALDA 0.1.24

Second Brain ASK fixes: login redirect when unauthenticated, and tag-filter form handling.

## Highlights

- **ASK login redirect** — unauthenticated visitors to ASK are redirected to `/login` again. `WebRuntimeException` is now a catchable `RuntimeException`, so `askRequireAuth` can catch a missing session cookie and call `res.redirect("/login")` instead of surfacing a raw 401.
- **Tag filters** — form checkbox `tags` no longer crash with `for-in loop requires an array` (strings were mistaken for arrays because they have `.length`). Repeated form keys such as `tags=a&tags=b` are collected into arrays.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.24-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.24-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.24
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
