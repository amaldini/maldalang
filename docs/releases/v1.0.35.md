# MALDA 1.0.35

Patch after 1.0.34: the Desktop IDE can play a showcase reel, and
`malda agent` shows one live activity line while a turn is running.

## Highlights

- **Desktop IDE showcase** — a demo playlist drives examples and manual
  pages. `scripts/record-showcase.ps1` captures an offline reel. Games in
  the playlist play on their own, including Grand Prix in the chase
  camera. The IDE opens on a splash title card, and the reel does too.
- **Manual pane** — the Desktop IDE shows reference-manual pages beside
  the editor. The showcase opens examples and those pages from the
  playlist.
- **Agent activity line** — on an interactive terminal, `malda agent`
  rewrites one line while the model thinks and while tools run
  (`thinking… round N`, then `read_file src/App.malda · 120 lines`).
  A failed tool stays on its own line. The line is erased before the
  answer. `MALDA_AGENT_STATUS=off` disables it. Redirected stdout and
  `MALDA_AGENT_VERBOSE` leave the line off. The same carriage-return
  rewrite is used on Windows, macOS, and Linux. Chapter 19.5.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.35-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.35-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.35
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
