# MALDA 1.0.14

Patch after 1.0.13: Desktop IDE can update a zip install from GitHub
Releases, host-wrapped agent tools land for Ralph-style loops, and the
GPU billiards showcase plus C# transpile coverage for tools and VectorDB.

## Highlights

- **Desktop IDE update** — **Help → Update Installation** checks
  `amaldini/maldalang` for the latest `malda-*-win-x64.zip`, downloads it,
  and replaces the zip install after a restart. Source checkouts are left
  alone. Extra local files stay; `bin/` is swapped wholesale and the tag
  is recorded in `.malda-release` (same layout as
  `scripts/update-local-win-x64-release.ps1`).
- **Host-wrapped agent tools** — `check_malda`, `web_fetch`,
  `validate_json`, `test_malda`, `update_plan`, `mark_step`, `delete_file`,
  `copy_file`, and `ensure_dir` sit next to the existing file tools.
  Ralph Wiggum uses the host-wrapped set. C# transpile now runs
  `create*Tool.execute` (including glob) and VectorDB search/retrieve.
- **GPU billiards** — Ray-traced showcase with cue aim, hold-to-charge
  power, zoom, orbit stop, and physics sliders. Reference Manual appendix
  walks through the demo.
- **Onboarding and examples** — Start With MALDA student path is linear
  and reopenable. Offline XOR neural-net and linear SVM samples sit
  before microgpt. ASK form AJAX still intercepts after an SSE panel
  replace.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.14-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.14-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.14
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
