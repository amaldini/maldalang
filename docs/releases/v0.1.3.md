# MALDA 0.1.3

Patch release: GraphMemory can load `embed:` artifact paths read-only for portable semantic Second Brain ASK.

## Highlights

- **GraphMemory / VectorDB embed load** — `memory.load("embed:alias/brain_memory")` reads `.graph.json`, `.metadata.json`, and `.vectordb.bin` from folders staged with `malda compile --embed-folder`. No disk extract.
- **Writes stay rejected** — `save`, `exportBundle`, and VectorDB `serialize` on `embed:` paths throw a clear read-only error (same policy as other `embed:` I/O).
- **`secondbrain_semantic.malda`** — compile comment notes that an embedded brain includes GraphMemory artifacts for hybrid ASK; place `bge-m3-Q4_K_M.gguf` beside the `.exe` for neural retrieval (GGUF is not embedded).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.3-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.3-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.3
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

Portable semantic ASK after a BUILD has produced `secondbrain_semantic/`:

```bash
malda compile Examples/Agents/secondbrain_semantic.malda -o dist/secondbrain_semantic.exe --mode transpile --embed-folder secondbrain_semantic
# copy bge-m3-Q4_K_M.gguf next to the .exe for neural retrieval
```

## Notes

- Still **0.1.x**, not a 1.0 language release. Spec remains **Draft 1.0** (`docs/spec/malda-language-1.0.md`).
- ASK does not call `memory.save`; only in-memory access metadata may bump during `query` within a session.
- Rebuild the semantic brain after changing the embedding model; GraphMemory vector artifacts are not portable across dimensions/models.
- Second Brain ASK web UI and `markdownToHtml` landed in [`v0.1.4`](v0.1.4.md).
- See also [`docs/releases/v0.1.2.md`](v0.1.2.md) (semantic Second Brain), [`v0.1.1.md`](v0.1.1.md) (`--embed-folder`), and [`v0.1.0.md`](v0.1.0.md).
