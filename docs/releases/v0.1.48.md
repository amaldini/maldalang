# MALDA 0.1.48

In-process PDF and Word text extraction, wired into Second Brain BUILD/UPDATE.

## Highlights

- **`pdf.extractText(path, password?)`** — extract digital text from PDFs via PdfPig
  (`ContentOrderTextExtractor`). CallBuiltIn name: `extractPdfText`. No OCR for
  scanned/image-only PDFs.
- **`doc.extractText(path)`** — extract body paragraph text from Word `.docx` via
  DocumentFormat.OpenXml. CallBuiltIn name: `extractDocxText`. Legacy binary `.doc`
  is not supported.
- **Second Brain** — lexical and semantic hosts glob `**/*.pdf` and `**/*.docx` and
  route them through the new builtins during BUILD/UPDATE.
- **Transpile** — published executables include PdfPig and Open XML package references
  so packed ASK/BUILD binaries can call the extractors.
- **Docs / notices** — Reference Manual, LLM pack gotchas, and third-party notices for
  PdfPig and Open XML.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.48-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.48-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.48
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
