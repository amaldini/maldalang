# MALDA 0.1.37

Fix Desktop IDE **Preview web** in the downloadable win64 zip: ship the missing
`program.html` host page so examples like Maldanoid open in the WebView panel.

## Highlights

- **Web preview host** — add root `program.html` (query-driven JS host) and
  `host.html` fallback, ported from the private tree; OSS dist packaging now
  requires and copies `program.html` into the zip root.
- **Desktop IDE resilience** — if the root host pages are absent, Preview web
  writes a generated loader under `.malda-preview/` and resolves script paths
  relative to the host file.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.37-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.37-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.37
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
