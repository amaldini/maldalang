# MALDA 0.1.8

Patch release: incremental UPDATE mode for Second Brain examples so an existing brain can refresh from new or changed source files without a full rebuild.

## Highlights

- **Second Brain UPDATE** — menu mode `2` in `Examples/Agents/secondbrain.malda` and `secondbrain_semantic.malda` re-distills only new/changed `.md`/`.html` sources (content hashes in `brain.json`), with optional cleanup of notes for removed files.
- **Catalog fingerprints** — `brain.json` is version 2 and stores `sourceKey` + `contentHash` per note so later updates stay incremental; legacy catalogs without hashes re-distill once.
- **Semantic reindex** — UPDATE rebuilds GraphMemory from the full note set after the markdown tree is merged.
- **Menu renumber** — ASK is now mode `3`; language `4`; PACK `5`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.8-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.8-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.8
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
