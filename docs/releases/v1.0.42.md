# MALDA 1.0.42

Patch after 1.0.41: two new examples, a 3D neural race in traffic with a city
circuit, and a Levenberg-Marquardt curve fit.

## Highlights

- **Neural race in traffic** — `Examples/Games/three_shader_race_traffic.malda`
  puts the eight neural racers among up to 56 road cars. Every vehicle lives in
  a float data texture that the shader walks as a small program of cars and
  bounding-sphere groups, so one compiled shader draws any number of cars and
  skips whole groups a ray cannot reach. Road cars keep their lane, slow for
  bends and the car ahead, and move aside for a blue flag.
- **Car rays** — each racer casts three rays at the other cars. The distances
  and the closing speed join the net's inputs (19 of them), and the coach
  steers toward the side with more room when the time to contact drops under
  2 s. The net learns the overtake from those labels.
- **Malda City** — a street circuit on a grid of blocks with buildings, parks,
  zebra crossings, and traffic lights that stop the road cars at red. Reach it
  with Q from Monza.
- **Curve fit** — `Examples/Algorithms/levenberg_marquardt.malda` fits
  `y = a * exp(-b * x)`, prints each step and its lambda, and shows plain
  Gauss-Newton diverging from the same start. `Examples/Games/lm_valley.malda`
  draws the same fit for `malda play`: the cost map over (a, b), the step
  curve, and a comparison with Gauss-Newton and gradient descent.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.42-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.42-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.42
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
