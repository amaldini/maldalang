# MALDA 1.0.23

Patch after 1.0.22: a standalone Learn MALDA course, a reorganized
reference manual, `math.anneal`, and a few REPL/CLI fixes before
anyone else uses the tools.

## Highlights

- **Learn MALDA** — [`ReferenceManual/learn.html`](../../ReferenceManual/learn.html)
  is a lesson-order course (Desktop Start With MALDA / Web IDE student
  track / Start Here). It stands alone through classes, errors, `malda
  check`, `include`, and offline prompt eval, then first-read hub
  stops. AI theory adds `chain_rule.malda` before the XOR net.
- **Manual and CLI** — schema syntax lives in chapter 4; chapter 13 is
  a stdlib catalog (JWT, jobs, AI pipeline, and `webFetch` how-tos
  moved home). Chapter 18 splits runtime vs kits and surfaces browser
  games; chapter 34 is an Examples catalog. Chapter 2 indexes every
  CLI verb. Snippet `--eval` is `--exec` (no collision with `malda
  eval`). `malda play` reloads on file change.
- **`math.anneal`** — simulated annealing: `cost` and `neighbor` are
  lambdas; optional `steps` / `temp` / `cooling` / `schedule` /
  `maximize` / `copy`. Seeded via `math.seed`.
- **REPL** — a blank line submits a multiline buffer and returns to
  the prompt (EOF still exits). Lambdas bind a name so `drop` /
  `replace` can target them.
- **Declared context** — `context` `.add` dispatches after C# transpile
  (interpreter already did). Offline recipe:
  `Examples/Prompts/context_turns.malda`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.23-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.23-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.23
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
