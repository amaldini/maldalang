# MALDA 1.0.37

Patch after 1.0.36: the 3D neural race is easier to read, and pixel art
can be written with `io.writePng` and `io.readPng`.

## Highlights

- **3D neural race** — cars have shaped bodies and tires on their axles,
  bump like billiard balls, and are shown from moving cameras. The
  showcase keeps the timing strip along the bottom. Track edges are red
  and white kerbs; the yellow center line is gone. Ray tests that cannot
  change the picture are skipped.
- **PNG helpers** — `io.writePng` and `io.readPng` write and read pixel
  art without a hand-rolled encoder. Game atlases use them. The
  platformer is drawn from the feet so it stands on the grass.
- **Maldadash** — the lamp is softer, and actors slide between tiles
  instead of snapping.
- **Showcase recording** — a release zip launches the packaged Desktop
  IDE. The Mandelbrot zoom stays near 10^-7 on a faster GPU.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.37-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.37-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.37
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
