# MALDA 1.0.9

Patch after 1.0.8: Desktop IDE undo restores Rename Symbol and other
in-place buffer edits.

## Highlights

- **Undo after Rename Symbol** — Desktop IDE rename no longer assigns
  AvalonEdit `TextEditor.Text` (that setter clears the undo stack in
  6.3). Edits go through `TextDocument.Replace`, and every occurrence
  of a rename is one undo unit. Format, replace-all, and AI apply use
  the same path. Switching tabs still resets undo (one editor, one
  stack).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.9-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.9-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.9
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
