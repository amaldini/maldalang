# MALDA 1.0.21

Patch after 1.0.20: class fields win over enclosing vars in methods, and
REPL sessions augment an already-defined class instead of replacing it.

## Highlights

- **Implicit fields** — bare names in methods and constructors resolve
  locals/parameters, then class fields, then the enclosing module. A
  top-level `var x` no longer shadows field `x` (`return x + y` means
  `this.x + this.y`). Parameters still shadow (`this.x = x`). Interpreter,
  C#, and JS agree.
- **REPL class augmentation** — a later `class Name { … }` in the same
  session appends members to the class already bound, using the same
  merge rules as a later declaration in one file. Previously the
  interpreter replaced the class. Instances created before the later
  entry see the new methods.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.21-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.21-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.21
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
