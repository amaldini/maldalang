# MALDA 1.0.20

Patch after 1.0.19: class augmentation and compact methods, inheritance
fixes, a usable REPL session, and tighter IDE/LSP module tooling.

## Highlights

- **Class augmentation** — a later `class Name { … }` appends members
  to the first declaration (interpreter, C#, JS). Compact method bodies
  (`function total() this.x + this.y;`) and brace-less one-line classes
  (`class Point(x, y) function total() this.x + this.y;`).
- **Inheritance** — `super` resolves from the declaring class; private
  members and static access match across interpreter and C# transpile;
  constructor args and instance field initializers run on subclasses.
- **REPL** — one interpreter for the session (variables, functions, and
  classes persist). Bare expressions echo. `help` is no longer dropped.
  `vars` / `defs` / `who` lists user definitions (optional kind filter).
- **IDE / LSP** — `include` / file `import` paths navigate and warn when
  missing (`malda-import` plus a create-file quick fix). Rename follows
  typed receivers and does not rewrite unrelated same-name identifiers.
  Desktop IntelliSense stays off the UI thread. Syntax Helper templates
  for landed post-1.0.13 constructs.
- **Small language** — `math.zeros`, array `except()`, `const BUY;`
  name-as-string shorthand, `match` treats in-scope const names as
  equality, `toJSON` dumps public class fields.
- **Ship contract** — fullstack / ASK / jobs / Tier 0 C# smoke oracles
  on CI.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.20-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.20-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.20
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
