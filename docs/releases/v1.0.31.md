# MALDA 1.0.31

Patch after 1.0.30: chapter 14 opens with what a neural net is and walks
one two-unit chain-rule step. Spatial layers share the dense contract, and
a `Sequential` can hold smaller nets. `game.stop()` halts the canvas loop.

## Highlights

- **Chapter 14.1** — a net is a function from a list of numbers to another
  list. One unit, a hidden layer, and training are written before any
  library call. The two-unit walk uses the derivative of half the squared
  error, `pred − target`.
- **Spatial layers** — `Conv2D`, `MaxPool2D`, `AvgPool2D`, `Flatten`,
  `GlobalAvgPool2D`, `GlobalMaxPool2D`, `BatchNorm2D`, `Dropout2D`, and
  `Activation`. Same `forward` / `backward` / `sgd` contract as `Dense`.
  One picture stays CHW. One extra list around it is a batch, and
  `forward` then returns NCHW. Interpreter, C# transpile, and JavaScript.
- **Nested `Sequential`** — a `Sequential` is a layer. An outer net calls
  `forward`, `backward`, and `sgd` on each child, including a child that
  is itself a `Sequential`. `nn.sequential` still builds only `Dense` rows.
  A conv block is `new Sequential([...])`.
- **Examples** — `cnn_basic_layers.malda` calls the layers one at a time.
  `cnn_composable.malda` trains two conv blocks and a classifier as three
  nets inside one outer `Sequential`.
- **`game.stop()`** — a zero-arg stop on the canvas game loop. The
  JavaScript transpile no longer treats that call as an actor.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.31-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.31-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.31
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
