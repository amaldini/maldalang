# MALDA 1.0.1

Patch after toolchain 1.0.0: Second Brain generate-document, Graph Labyrinth
showcase, ASK HEAD handling, and Distiller write jail.

## Highlights

- **Second Brain generate** — ASK toggles Ask vs Generate. Retrieval stays the
  same; Generate writes a standalone Markdown/HTML document from indexed
  examples and offers download. CLI `generate` requires `--prompt` and writes
  the file without starting the web UI. Example chips and prompts are
  domain-neutral (briefs, summaries, checklists, agendas).
- **Graph Labyrinth** — `Examples/Web/maze.malda` generates a maze, solves it
  with graph BFS, and serves it from `HttpServer`.
- **ASK HEAD** — `HttpListener` no longer writes a body on HEAD, so ASK no
  longer throws `ProtocolViolationException`.
- **Distiller jail** — Second Brain BUILD writes cannot escape the brain folder.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.1-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.1-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.1
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
