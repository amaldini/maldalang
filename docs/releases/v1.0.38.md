# MALDA 1.0.38

Patch after 1.0.37: the 3D neural race lines the road with signs, trees,
and buildings that stay visible down a straight, and each kind can be
toggled. The showcase reel ends a little sooner.

## Highlights

- **3D neural race scenery** — signs, trees, and buildings sit off the
  asphalt in a second, wider grid. A ray reads at most 18 of those
  cells, far enough to see down a straight, then a sphere skips the
  real shape. Shadow rays still test cars only.
- **Scenery toggles** — keys 1, 2, and 3 hide signs, trees, and
  buildings. A hidden kind is skipped before its shape test, and
  hiding all three skips the roadside march. The timing panel shows
  on or off.
- **Showcase timeline** — the reel ends earlier, and the CartPole,
  3D Grand Prix, and Chess cues start a little sooner.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.38-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.38-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.38
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
