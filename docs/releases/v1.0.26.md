# MALDA 1.0.26

Patch after 1.0.25: the REPL prints line numbers before an edit, so
`editline` and `insert` can target a recorded line without counting.

## Highlights

- **Numbered `source <name>`** — `source add` prints the definition
  with line numbers starting at 1. Those are the numbers `editline`
  and `insert` use. A kind filter or a full `source` dump stays the
  original text, so it can be re-entered.
- **Listing before the edit** — `editline add` or `insert add` without
  a line number prints that same listing and returns to the prompt.
  Giving a line prints it again above `..>`, so the numbers stay
  visible while the replacement is typed.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.26-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.26-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.26
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
