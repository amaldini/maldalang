# MALDA 0.1.50

Typed prompts gain schema-in-prompt text, sum-type intent returns, and closed `api` /
`runProgram` program translation.

## Highlights

- **Schema appendix** — typed prompts without tools append a `MALDA_OUTPUT_SCHEMA`
  block so local / text-only models see the expected JSON shape (interpreter +
  transpile).
- **Sum-type prompt returns** — `prompt … -> Intent` (or any registered sum type)
  accepts wire JSON `{ "tag": "Buy", … }` and coerces to `RuntimeValue.Variant` for
  `match`.
- **Closed `api` + `runProgram`** — declare callable surfaces with `api Name { … }`,
  return `program(ApiName)` from typed prompts, then execute steps deterministically
  with `runProgram(program)` (no agent tool loop). Wire JSON uses `@api`,
  `steps[{call,args,as}]`, and `return`.
- **Docs / examples** — `Examples/Prompts/sum_type_intent_prompt.malda`,
  `Examples/Prompts/api_program_calc.malda`, few-shots `20` / `21`, Reference Manual
  and LLM pack updates (`runProgram` builtin inventory sync).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.50-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.50-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.50
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
