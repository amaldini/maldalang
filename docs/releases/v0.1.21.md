# MALDA 0.1.21

Post-0.1.20 sprint: stronger literal type checks at call/return sites, form validate + flash example, nightly Tier 0 CI, and session method dispatch fix.

## Highlights

- **Typecheck 4b** — Warning when literal arguments or `return` values disagree with parameter/return hints; `--strict-types` elevates those mismatches to Error (blocks run).
- **Form → validate → flash** — `Examples/Web/form_validate_flash.malda` (port 8082): CSRF, `bindForm`, `schema`/`validate`, session flash; tutorial links updated.
- **Session dispatch fix** — Interpreter routes `req.session.*` (`getFlash` / `flash` / …) through `RequestSessionContextInstance` (was throwing “Unknown built-in method”).
- **Tier 0 nightly** — `.github/workflows/tier0-nightly.yml` (`schedule` + `workflow_dispatch`, Windows interpret + C#); push/PR smoke filter unchanged.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.21-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.21-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.21
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
