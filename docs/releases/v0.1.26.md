# MALDA 0.1.26

Second Brain ASK tag filters are a compact combo instead of a tall checkbox wall.

## Highlights

- **ASK tag picker** — many brain tags no longer expand the sticky composer over answers. Tags open from a one-line combo (`details`), checklist scrolls upward, and the panel closes on outside click or Ask submit. Selected tags stay visible as a short summary (`Tag (n) · …`).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.26-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.26-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.26
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
