# MALDA 0.1.22

Patch release: Second Brain non-interactive CLI, working `new Tool` handlers, and GraphMemory neighbor tool for semantic ASK.

## Highlights

- **Second Brain CLI** — `build` / `update` / `ask` / `help` from the command line (`--docs`, `--brain`, `--taxonomy`, `--remove-orphans`, `--lang`, `--port` / `-p`) without menu prompts; shared `secondbrain_cli_lib.malda` for lexical and semantic hosts.
- **ASK HTTP port** — override via `--port` / `-p` (interactive menu, `ask` CLI, or packed ASK exe).
- **`new Tool` handlers** — `new Tool(name, description, schema, handler)` wires the handler for `tool.execute` and agent loops (interpreter + transpile); documented in the Reference Manual.
- **`find_related_notes`** — semantic Second Brain ASK (tools on) exposes GraphMemory `findRelated` via a `new Tool` example.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.22-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.22-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.22
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
