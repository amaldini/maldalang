# MALDA 1.0.25

Patch after 1.0.24: the REPL can change one recorded definition in
place, so a function or class does not have to be retyped.

## Highlights

- **REPL `editline`** — replace one line of a recorded definition.
  Lines are counted from `source add`, starting at 1. A successful
  patch prints the definition with those numbers. Omit the replacement
  text to type several lines; a blank line on `..>` finishes, and an
  immediate blank line deletes that line. The result has to stay a
  definition of the same name, or the previous definition is kept.
- **REPL `insert`** — insert one or more lines after a source line.
  `insert add after 2` opens the continuation prompt. On a one-line
  function, `insert add after 1` wraps it in a block, places the new
  lines first, and keeps the original expression as the final
  `return`.
- A class patched this way is dropped and defined again, so existing
  instances keep the previous class object.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.25-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.25-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.25
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
