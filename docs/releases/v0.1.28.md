# MALDA 0.1.28

Informational type hints now recognize declared class/schema names and built-in host classes, including simple `new ClassName()` compatibility checks in the IDE / `--strict-types` pipeline.

## Highlights

- **Class and schema type hints** — names from `class` / `schema` declarations in the current unit, plus built-in host classes (`RestServer`, `LLMClient`, …), are known type-hint names. They no longer produce “unknown type hint” diagnostics (or `--strict-types` errors for that reason alone).
- **Completions** — after `:` / `->`, type-hint completion offers Tier 0 names together with declared and host class names.
- **Compatibility** — mismatches such as `var p: Person = 1` warn (error under `--strict-types`); `var p: Person = new Person()` and identifier-to-identifier matches with the same class hint do not. Still informational only — nothing enforces hints at runtime. No inheritance or cross-file `include` resolution.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.28-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.28-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.28
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
