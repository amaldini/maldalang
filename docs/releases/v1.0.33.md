# MALDA 1.0.33

Patch after 1.0.32: the same input can feed more than one neural branch.
`add` sums them. `concat` joins them. A residual is that sum with `Identity`
as the skip.

## Highlights

- **Parallel branches** — `new Parallel([branch, ...], "add")` gives every
  branch the same input, sums same-shaped outputs, and sends the same
  upstream to each branch. `"concat"` joins vectors end to end, and joins
  CHW or NCHW maps on the channel axis. `backward` splits that axis.
  `new Identity()` is the skip, so a residual is
  `new Parallel([block, new Identity()], "add")`. The interpreter, C#
  transpile (`malda compile --mode transpile`), and JavaScript agree.
  Example: `Examples/AI_Theory/parallel_compose.malda`. Chapter 14.10.2.
- **Convolutional backpropagation** — chapter 14 writes the kernel gradient
  and the image gradient for `Conv` and `Conv2D`. Each window adds the
  upstream times the pixel under that weight, and overlapping windows add.
- **CNN examples** — `cnn_basic_layers.malda` and `cnn_composable.malda`
  are in the example browser, between `conv_classifier.malda` and
  `residual_dropout.malda`. Those helpers return `Sequential`.
  `color_image_cnn.malda` classifies RGB 32×32 shapes (red circles, green
  squares, blue triangles). A residual step is
  `new Parallel([conv, new Identity()], "add")`.
- **`malda agent`** — graph-memory option arguments accept `dict { }` as
  well as `{ }`. A reply that passed a dictionary into `prune`,
  `consolidate`, `reflect`, and the other option calls no longer throws.
- **Directory walks** — recursive `glob`, `grep`, and agent file indexing
  skip directory junctions and symbolic links. An error that still occurs
  keeps a short path instead of the whole unresolved chain.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.33-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.33-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.33
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
