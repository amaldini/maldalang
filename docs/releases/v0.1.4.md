# MALDA 0.1.4

Patch release: Second Brain ASK as a local web UI, `markdownToHtml`, and chat-only ASK when the brain is empty.

## Highlights

- **`markdownToHtml(markdown)`** — core builtin (Markdig) for safe Markdown → HTML in HttpServer pages; raw HTML in input is disabled. Documented in the Reference Manual and agent builtins table.
- **Second Brain ASK web UI** — mode 2 in `secondbrain.malda` (port **39018**) and `secondbrain_semantic.malda` (port **39019**) opens a local HttpServer thread (history, EN/IT, stop → console menu). Shared page code lives in `Examples/Agents/secondbrain_ask_ui_lib.malda`.
- **Empty-brain chat** — if `brain.json` is missing or has no notes, ASK still starts as direct chat with the model; retrieval resumes once a brain is built. No relevant notes also falls back to chat.
- **LLM answers as Markdown** — reader/chat agents are instructed to answer in Markdown; the UI renders via `markdownToHtml`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.4-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.4-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.4
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

ASK web UI (build a brain with mode 1 first for retrieval, or open mode 2 empty for direct chat):

```bash
malda Examples/Agents/secondbrain.malda
# menu 2 → http://localhost:39018/

malda Examples/Agents/secondbrain_semantic.malda
# menu 2 → http://localhost:39019/
```

## Notes

- Still **0.1.x**, not a 1.0 language release. Spec remains **Draft 1.0** (`docs/spec/malda-language-1.0.md`).
- HttpServer isolates each request: ASK session state uses `ui.state` / `ui.setState`, not top-level vars.
- Stopping the server from `/stop` is deferred so the HTTP response can finish before the listener closes.
- See also [`docs/releases/v0.1.3.md`](v0.1.3.md) (GraphMemory `embed:` load), [`v0.1.2.md`](v0.1.2.md) (semantic Second Brain), [`v0.1.1.md`](v0.1.1.md) (`--embed-folder`), and [`v0.1.0.md`](v0.1.0.md).
