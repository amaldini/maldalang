# MALDA 1.0.39

Patch after 1.0.38: the three backends agree on more programs (recursion,
truthiness, actors, lambdas, `all()`), `three.*` gains a fixed-step loop,
instancing, shadows, fog, render scaling, and 3D sound, and the 3D neural
race uses all of them.

## Highlights

- **Interpreter fix for recursion** — block, while, and function frames
  are popped on every exit. A frame left behind by `return` made the outer
  call of a recursive function return the inner call's value.
- **0 is truthy on every backend** — conditions on C# and JS now match the
  interpreter.
- **Actors call their own helpers** — handlers and constructors can call
  the actor's functions by name and see program globals on the
  interpreter, C#, and JS. Stateful JS actors work again (bare
  `count = ...` used to throw), and JS constructors may call sync helpers.
- **C# lambdas and arrays** — lambdas of any arity get a matching delegate
  shape and `f(a, b, ...)` forwards every argument; `map` / `filter` /
  `reduce` / `forEach` / `find` / `findIndex` / `some` / `every` work on
  arrays. The generated program pins the invariant culture, so
  `float("0.5")` and printed decimals no longer depend on the OS locale.
- **JS `all()` / `error()`** — `all()` waits for every branch and turns a
  failure into an `Upstream(0, message)` slot, as on the other backends;
  `error(message)` is available; `var t = async f();` stores the task.
  JS also gains `str.text` / `str.trimText` and dict `keys()` / `values()` /
  `containsKey()`.
- **`three.*` loop and input** — `three.startFixed` / `getFixedAlpha` give
  a 60 Hz fixed step; key, mouse, and gamepad edge calls use the `game.*`
  names.
- **`three.*` rendering** — uniform arrays in shader materials;
  instanced meshes (`createInstancedMesh`, `setInstance`,
  `setInstanceCount`); shadows and fog; `setRenderScale` /
  `setAutoRenderScale`; a stats overlay (`getStats`, `showStats`,
  `#malda-stats`); `createCylinderGeometry`, `render(..., { clear: false })`,
  and an up vector on `lookAt`. Mouse coordinates are renderer units, which
  fixes aiming on HiDPI screens. New example: `Examples/Games/three_forest.malda`.
- **3D audio** — `game.audioCreateVoice` / `audioSetVoice` /
  `audioStopVoice` play continuous voices that glide without clicks; a
  `position` option and `game.audioSetListener` add HRTF 3D sound.
- **3D neural race** — tire grip, a cockpit view, and a corner pace the net
  learns; fixed-step training; one positioned engine voice per car; the
  roadside drawn as instanced meshes over the ray-traced track.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.39-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.39-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.39
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
