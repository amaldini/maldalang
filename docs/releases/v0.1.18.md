# MALDA 0.1.18

Onboarding examples and LLM few-shots for errors/`match`, `include`, unit asserts, HTTP client, Bearer JWT, and durable workflow retry/inspect.

## Highlights

- **Basics** — `Examples/Basics/errors_and_match.malda` and `modules_include.malda` (with `helpers/greet_lib.malda`) cover try/catch/finally, tagged catch, `match`, and `include` splice.
- **Testing** — `Examples/Testing/unit_test_basics.test.malda` shows assert-based unit checks discovered by `malda test` (before property tests).
- **Web** — `http_client_json.malda` (local echo + `httpGet`/`httpPost`) and `rest_bearer_jwt.malda` (login + `authenticateBearerJwt` / `requireRole` on port 8081).
- **Workflows** — `Examples/Workflows/retry_and_inspect.malda` runs a flaky retry job, catches terminal failure, and inspects steps/events/dead letters on local SQLite; folder gains `metadata.json`.
- **LLM pack** — few-shots `11`–`16` mirror those surfaces with preferred `io.` / `math.` / `str.` style; `docs/llm/few-shot/README.md` updated.
- **IDE metadata** — Basics / Testing / Web example chains point at the new files (CRM `next` still deferred).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.18-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.18-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.18
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
