# MALDA 0.1.44

Second Brain ASK web UI adapts to smartphone viewports instead of forcing a
desktop column width that overflowed horizontally.

## Highlights

- **ASK mobile layout** — `@media (max-width:640px)` stacks header actions,
  shrinks logos, full-width composer buttons, and 16px textarea (no iOS focus zoom).
- **No phone overflow** — brand `min-width:min-content` and always-on
  `main.has-logo { width:fit-content }` are gone; desktop logo widening is gated
  behind `@media (min-width:641px)`.
- **Safe areas & wrapping** — notch insets, word-wrap on titles/answers, and
  horizontally scrollable markdown tables / admin grids.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.44-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.44-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.44
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
