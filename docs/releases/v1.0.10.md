# MALDA 1.0.10

Patch after 1.0.9: Desktop IDE theming and editor UX, LLM `program()`
JSON that actually runs, and JS pixel/shader ray tracers.

## Highlights

- **Desktop IDE editor UX** — Ctrl+. Quick Fix at the caret (lightbulb,
  Edit menu, Apply All as one undo), a right-click editor context menu,
  and the missing-semicolon fix landing on the current statement instead
  of the next one.
- **Theme-aware chrome** — IntelliSense, the quick-fix menu, the Rename
  Symbol dialog, and the theme ComboBox follow the active IDE theme.
  The Run button stays readable on Blue, Dark, and Light.
- **LLM `program()` JSON** — Re-running `api` examples no longer hits
  “already registered”. `program(Api)` coerces nested calls and numeric
  strings; optional `SchemaType` hints on api parameters. Calc programs
  map `add`/`+` onto declared methods such as `_add`.
- **JS ray tracers** — `game.*` pixel-buffer blit plus a CPU tracer
  example, and `three.createShaderMaterial` / uniforms plus a GPU
  fullscreen tracer. Prompts are their own Reference Manual chapter.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.10-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.10-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.10
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
