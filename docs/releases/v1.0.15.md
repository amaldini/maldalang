# MALDA 1.0.15

Patch after 1.0.14: Reference Manual search and glossary, capability-token
how-to, and an infinite Mandelbrot zoom on `three.*` shaders with BigInt
perturbation.

## Highlights

- **Reference Manual search** — Sidebar search (`/` or `Ctrl`+`K`) plus a
  concept [glossary](../../ReferenceManual/glossary.html). Short names such
  as `cap` jump to capability-token headings. Italian pages share the same
  index.
- **Capability tokens as a how-to** — Chapters 12, 13, and 18 explain how
  to declare and use `cap` on prompts, agents, and I/O, not only list the
  API. Gotchas call out the same tokens.
- **Infinite Mandelbrot zoom** — `Examples/Games/three_shader_mandelbrot.malda`
  dives Seahorse Valley on `@shader()` / `three.createShaderMaterial`. The
  host builds a BigInt reference orbit (`three.mandelbrotOrbit`, decimal
  strings for C) and the kernel applies scaled perturbation so deep frames
  stay sharp past float32 ulp. Sliders set iterate budget and wrap decades
  (defaults 1024 / 8). Hold Space to pause; `[` `]` change speed.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.15-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.15-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.15
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
