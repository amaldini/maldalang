# MALDA 1.0.16

Patch after 1.0.15: declarative agent teams with typed hops, a CS101
close-out plus Algorithms student track, and a host ship-contract with
HTTP-trace parity.

## Highlights

- **Declarative agent teams** — `agents.define` / `agents.team` bind role
  specs to a directed graph. `executePlan(plan, team)` requires `step.role`,
  honors declared `handoff` / `delegate` / `review` / `consult` / `reject`
  edges, and branches `reject` hops on the predecessor `approved` verdict.
  `team.handoff` / `team.review` / `team.reject` / `team.consult` are typed
  hops (`think: true` to call the model). Specialized `kind` values
  (`CodingAgent`, `HumanAgent`, …) construct offline and do not download a
  default local GGUF. Reference Manual § 18.17. Examples under
  `Examples/Agents/agent_team_*.malda`.
- **Student tracks** — CS101 closes out and a short Algorithms path
  (`Examples/Algorithms/`) follows. The examples catalog publishes only
  after a complete scan.
- **Ship contract and HTTP traces** — Host programs that claim to ship
  register an oracle (`docs/spec/ship-contract.md`). Interpret and C#
  `result.map` wrap agree. `Templates/webapi` health is an HTTP-trace
  pair; RestServer transpile holes that blocked traces are closed.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.16-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.16-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.16
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
