# MALDA 0.1.34

Second Brain ASK dual header logos and light/dark theme (cookie-persisted), plus
OpenRouter app-attribution properties on `OpenRouterClient`.

## Highlights

- **Second Brain ASK** — optional right-of-title logo (`ASK_LOGO_RIGHT` /
  `logo_right.*`) beside the existing left logo; light/dark theme toggle in the
  header with persistence via the `malda_ask_theme` cookie.
- **OpenRouterClient** — `httpReferer`, `appTitle`, and `appCategories` object
  properties map to OpenRouter attribution headers so usage can be split per app
  in OpenRouter analytics.
- **Docs** — Reference Manual OpenRouter section and language-pack note for the
  new client properties.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.34-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.34-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.34
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
