# MALDA 0.1.47

Null-safe string/env helpers, `??` null coalescing, and usable `import` modules for apps like Second Brain.

## Highlights

- **`str.text` / `str.trimText`** — null-safe coerce and trim (`null` → `""`, unlike
  `string(null)` → `"null"`). Prefer these at env / JSON / CLI boundaries.
- **`io.getEnvOr(name, default?)`** — env lookup that never returns `null` (default
  empty string). Safer than `str.trim(io.getEnv(...))` when the variable is unset.
- **`??` null coalescing** — `a ?? b` uses `b` only when `a` is `null`; keeps `0`,
  `false`, and `""`. Works with `?.` / `?[`. Interpreter + C#/JS transpile.
- **Modules see stdlib** — `import` file modules keep `math` / `str` / `io` via an
  enclosing environment; exports no longer accidentally re-export those parents.
- **Second Brain** — CLI parse helpers are `import`/`export`; host apply/help stays
  `include`. ASK and distill paths adopt the null-safe helpers and `?.` / `??`.
- **Examples / docs** — `Examples/Basics/modules_import.malda`, reference manual and
  LLM pack updates for the new surface.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-0.1.47-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.47-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.47
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
