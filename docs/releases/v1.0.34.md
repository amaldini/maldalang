# MALDA 1.0.34

Patch after 1.0.33: `malda agent develop` starts a coding session in the
working directory. `develop malda` is the MALDA coding agent.

## Highlights

- **`malda agent develop`** — generic coding agent (`DevAgent`) in the
  current directory. It has file, git, and `run_command` tools, plus
  `remember_progress` / `recall_progress`. Memory is stored under
  `~/.malda/memory/develop` with scope `code:<folder>`.
- **`malda agent develop malda`** — MALDA coding agent
  (`MALDACodingAgent`): edit `.malda` files and call `run_malda` /
  `compile_malda`. Memory is stored under
  `~/.malda/memory/develop-malda`. `--kind generic` and `--kind malda`
  select the same split. `-m`, `-b`, and `--workdir` work on both.
- **Personal script stays personal** — develop mode skips
  `~/.malda/assistant.malda` unless `MALDA_AGENT_SCRIPT` points at a
  script that honors `MALDA_AGENT_KIND`. Chapter 34.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.34-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.34-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.34
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
