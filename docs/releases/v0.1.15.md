# MALDA 0.1.15

Second Brain ASK logo branding: auto-load from the brain folder in normal (non-embedded) ASK, clearer path docs, and a console warning when `ASK_LOGO` is missing.

## Highlights

- **ASK logo from brain folder** — with `ASK_LOGO = ""`, ASK auto-loads `logo.png` / `.svg` / `.jpg` / … from the brain root (disk or embed). Relative values like `"logo.png"` resolve under the brain folder. Absolute disk paths work in normal ASK (not pack-only); prefer `/` or `\\` in Windows string literals.
- **Missing logo warning** — if `ASK_LOGO` is set but the file cannot be opened, ASK prints a yellow console hint before starting the server.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.15-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.15-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.15
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
