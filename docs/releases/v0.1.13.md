# MALDA 0.1.13

Second Brain ASK web UI: in-place panel updates, live LLM/tool progress over SSE, optional note-search tools (default off), and no web control to stop the server.

## Highlights

- **Partial ASK updates** — `HttpServer` injects the AJAX helper for normal `@PAGE` HTML documents (not only AI pages). ASK `/ask` and `/clear` return `componentFragment("ask-panel", …)` so the shell stays mounted.
- **Live agent progress** — new builtins `onAgentProgress(handler|channel)` and `clearAgentProgress()`. Events (`round_start`, `tool_calls`, `tool_done`, `continue`, `done`) stream to `@LIVE("/ask/live")` while a turn runs. The live dock sits under the latest turn (not stuck at the top) and shows total + per-round elapsed timers.
- **Tools toggle** — composer checkbox (sticky in session, default off). Off uses `newPlainAgent` on retrieved excerpts only; on uses `newReaderAgent` with `read_file` / `grep` / `list_directory`.
- **Multi-user safe stop** — removed **Ferma server** from the ASK page and the `/stop` route. Operators stop the process from the console (Ctrl+C).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.13-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.13-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.13
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
