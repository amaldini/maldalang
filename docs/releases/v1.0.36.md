# MALDA 1.0.36

Patch after 1.0.35: the showcase reel is timed to a soundtrack, with a
timeline editor in the Desktop IDE. The catalog adds a 3D neural race
and an interactive Towers of Hanoi.

## Highlights

- **Showcase soundtrack** — cues are timed from the splash, the reel
  ends on the splash for an outro whose length you can edit, and the
  IDE status bar shows the current lyric. Help opens the reel in
  another IDE window. Recording uses `showcaseTrack1`; the local
  soundtrack file stays out of git. Stereo Mix capture is documented.
- **Timeline editor** — edit cue times, scene order, and the song
  prompt together, reorder every tour, and preview the soundtrack
  from each cue.
- **Showcase scenes** — the splash and cover are a prompt-to-agents
  flow. Mandelbrot dives deeper in the short preview, billiards still
  breaks when the pointer moves, chess pieces slide into place, and
  Maldanoid learns the paddle before handing play to the net. CartPole,
  the GPU raytracer, Mandelbrot, and billiards fit the side pane. The
  manual tour shows declarative agent teams. The reel stays in the
  split view.
- **3D neural race** — `three_shader_race_car_neural.malda` ray-traces
  cars that learn from a pure-pursuit coach on Monza, Spa, and Monaco.
  The track follows the curved circuit, lap length matches the 2D
  coach, and a timing panel matches the 2D race. The keyboard-only 3D
  race is no longer in the catalog.
- **Towers of Hanoi** — click the towers, auto-solve, and change the
  disk count. The animated game is in the examples browser and in the
  showcase.
- **Develop-agent traces** — tool calls from a develop session can be
  recorded for replay, and browser games are checked with the
  JavaScript compile.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.36-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.36-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.36
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
