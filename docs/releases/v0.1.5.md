# MALDA 0.1.5

Patch release: portable Second Brain ASK branding, menu PACK, and `compileMALDA` embed support.

## Highlights

- **Portable ASK startup** — when a second brain is embedded (`--embed-folder` / menu PACK), `secondbrain.malda` and `secondbrain_semantic.malda` skip the console menu and open ASK immediately (UI language is chosen in the web page).
- **ASK header branding** — customize `ASK_PAGE_TITLE`, optional `ASK_LOGO` (file path, `embed:…`, `http(s):`, or `data:`), and a “Powered by MALDA…” line linking to the GitHub repo.
- **Menu PACK (mode 4)** — compile a portable ASK-only `.exe` with the brain embedded, without remembering CLI flags. Uses a stable embed alias so the packed exe auto-starts ASK.
- **`compileMALDA(source, output?, mode?, embedFolder?)`** — optional fourth argument accepts `path` or `path=alias` (same as CLI `--embed-folder`). Documented in the Reference Manual and agent builtins table.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.5-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.5-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.5
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

Pack a portable ASK exe after BUILD (menu **4**), or via CLI:

```bash
malda compile Examples/Agents/secondbrain.malda -o dist/secondbrain.exe --mode transpile --embed-folder secondbrain
```
