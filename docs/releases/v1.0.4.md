# MALDA 1.0.4

Patch after 1.0.3: Second Brain ASK Ctrl+C shutdown and Live dock idle state.

## Highlights

- **Ctrl+C stops ASK** — `HttpServer` handles console cancel, closes SSE
  streams, and sets `isRunning` false so the ASK wait loop can exit instead
  of hanging on `HttpListener` teardown.
- **Idle Live dock** — ASK ignores SSE `connected` / `heartbeat` events so
  the Live round UI does not appear before a question is submitted.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.4-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.4-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.4
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
