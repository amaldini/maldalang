# MALDA 1.0.41

Patch after 1.0.40: the SDF interpreter example is brighter, and JavaScript
preview loads three.js for programs that call `three.*`.

## Highlights

- **SDF example** — `Examples/Games/three_sdf_interpreter.malda` uses more
  saturated shape colors, a fill light, tighter soft shadows, a lighter
  floor and sky, and fog that starts farther from the camera.
- **three.js on the generated host page** — `malda compile --mode js`,
  `--mode esm`, `--mode pwa`, and `malda play` copy
  `Examples/Web/wwwroot/vendor/three.min.js` beside the page and load it
  before `malda-js-runtime.js` when the program calls `three.*`. A
  hand-written host page still loads the bundle first.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.41-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.41-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.41
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
