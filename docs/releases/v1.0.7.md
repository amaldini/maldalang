# MALDA 1.0.7

Patch after 1.0.6: Desktop IDE debugger inspect trees keep their expansion,
plus JavaScript backend parity work that landed after 1.0.6.

## Highlights

- **Debugger Variables and Watch stay expanded** — Desktop IDE remembers
  which inspect-tree nodes the user opened and restores them after each
  step. Watch is an expandable tree (same lazy children as Variables).
  Expansion is keyed by stable name paths because DAP handles reset on
  every pause.
- **JavaScript backend closer to interpret/C#** — interpolated strings,
  destructuring, `class` extends/super, `math`/`str`/`io` namespaces,
  JSON, schema `validate()`, dates, env, client HTTP, `@within`, and
  `receive()` map onto `mlRuntime`, with interpret/JS stdout pair tests
  in CI.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.7-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.7-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.7
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
