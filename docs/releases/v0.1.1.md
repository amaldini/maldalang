# MALDA 0.1.1

Patch release after the first public drop: embed folders into compiled executables, and a Second Brain agent example.

## Highlights

- **`--embed-folder`** on `malda compile` / `publish` — pack a host directory into the `.exe` as `embed:<alias>/…` assembly resources (no extract-to-disk). Works in interpreter and transpile modes.
- Runtime VFS for embedded trees: `io.readFile` / `hasFile` / `listDirectory` / `grep` / `pathJoin`, plus `io.hasEmbeddedFolder` and `io.embeddedFolderRoot`. Agent file tools accept an `embed:<alias>` working directory.
- **`Examples/Agents/secondbrain.malda`** — CodingAgents distill `.md`/`.html` docs into a linked note tree (BUILD) and answer questions from it (ASK); bilingual English/Italian UI; ASK can use an embedded brain when compiled with `--embed-folder secondbrain`.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.1-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.1-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.1
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```

Second Brain example:

```bash
dotnet run --project MaldaLang -- Examples/Agents/secondbrain.malda
```

Optional portable ASK-only build (after a BUILD has produced a `secondbrain/` folder):

```bash
malda compile Examples/Agents/secondbrain.malda -o dist/secondbrain.exe --mode transpile --embed-folder secondbrain
```

## Notes

- Still **0.1.x**, not a 1.0 language release. Spec remains **Draft 1.0** (`docs/spec/malda-language-1.0.md`).
- Writes to `embed:` paths are rejected; BUILD mode of Second Brain still uses a normal disk folder.
- GraphMemory artifact load from `embed:` (read-only) is supported for portable semantic ASK; see [`v0.1.3`](v0.1.3.md).
- See also [`docs/releases/v0.1.0.md`](v0.1.0.md) for the first public drop.
