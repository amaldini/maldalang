# MALDA 0.1.17

Auth hardening for HttpServer and RestServer: rate limiting after auth middleware, public-path skips on `use()`, JWT issuer/audience/nbf options, and a cookie-login example.

## Highlights

- **Rate limit after auth** — `verifiedSub` / `verifiedSubOrIp` keying now sees subjects set by `req.auth.authenticateBearerJwt` / `authenticateCookieJwt` (and route `@Use` guards).
- **`use(middleware, { except })`** — skip public paths such as health, readiness, and metrics; trailing `*` prefixes are supported.
- **JWT options** — `createJwt` / `verifyJwt` accept options for `expiresInSeconds`, `issuer`, `audience`, and `notBeforeSeconds` (`nbf` enforced on verify).
- **Templates** — webapi and fullstack starters load secrets from `MALDA_JWT_SECRET` / `MALDA_CSRF_SECRET` and except probe routes from global auth.
- **Example** — `Examples/Web/auth_cookie_login.malda` shows password hash + signed JWT cookie + `authenticateCookieJwt` on HttpServer.
- **Docs** — Reference Manual chapters 11, 16, and 17 document `req.auth.*` and the primary `authenticate*` recipe.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.17-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.17-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.17
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
