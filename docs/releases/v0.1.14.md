# MALDA 0.1.14

Second Brain rebranding via `PRODUCT_NAME` / `product_name.txt`, and stricter string escapes (`\r` supported; unknown escapes are lexer errors).

## Highlights

- **Second Brain rebranding** — set `PRODUCT_NAME` in `secondbrain*.malda` (default `"Second brain"`), or put `product_name.txt` (first line) in the brain folder (disk or embed). `PRODUCT_NAME` may also be a path/`embed:…` text file, like `ASK_LOGO`. Auto-loaded when the brain root is known; refreshes `ASK_PAGE_TITLE` when it still follows `ASK_TITLE_SUFFIX`. Pair with `ASK_LOGO` / footer as before.
- **String escapes** — `\r` (carriage return) is supported in `"…"`, `'…'`, `$"…"`, and `$"""…"""`. Unknown escapes (e.g. `\x`) are a lexer error instead of silently dropping the backslash (`"\r"` used to become `"r"`). Plain `"""…"""` remains literal (no escapes).

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does (macOS is not CI-verified yet)

## Install without sources

Download `malda-0.1.14-win-x64.zip` (CLI + Desktop IDE) or `malda-0.1.14-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\hello_world.malda
MaldaDesktop.bat

# Linux
./malda Examples/Basics/hello_world.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v0.1.14
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/hello_world.malda
```
