# MALDA 1.0.17

Patch after 1.0.16: typed `executePlan` step outputs, capability tokens
beyond files, and sum-type constructor namespaces.

## Highlights

- **Typed plan step outputs** — `step.out` names a schema, sum type, or
  `program(Api)`. Think JSON (or `step.fixture`) is coerced like
  `await prompt … -> Type` / `evalPrompt`. Failed extract fails the step
  and skips dependents. Example: `Examples/Agents/agent_team_plan_out.malda`.
- **HTTP / MCP / shell capability tokens** — `cap.httpGet` / `cap.mcpCall`
  / `cap.shell` mint unforgeable handles. `cap.fetch` / `cap.invoke` /
  `cap.run` (and `webFetch` / `callTool` / `runCommand`) consume matching
  tokens only. Forged dicts and escapes throw before HTTP, MCP, or a
  process starts. Example: `Examples/Tools/capability_http_mcp_shell.malda`.
- **Sum-type constructor namespaces** — `type Result = Ok(value) | Err(msg)`
  binds `Result.Ok` / `Result.Err`. `import { Result }` no longer flattens
  constructors into the importer.
- **Desktop IDE** — current-statement highlight while stepping.
- **Algorithms** — Towers of Hanoi is the first `Examples/Algorithms/`
  sample.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.17-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.17-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.17
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
