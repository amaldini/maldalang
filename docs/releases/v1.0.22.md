# MALDA 1.0.22

Patch after 1.0.21: the REPL can reprint entered definitions as source
and drop or replace a previous binding (needed because a later class
only augments).

## Highlights

- **REPL `source`** — `source` (alias `src`) prints user definitions as
  they were typed. Filter by kind (`source functions`) or by name
  (`source add`). Complements `vars` (live signatures and values).
- **REPL `drop` / `replace`** — `drop` (alias `undef`) removes a user
  definition. `replace` (alias `edit`) drops it and reprints the
  recorded source so you can re-enter it. After dropping a class, a
  later `class Name` is a first declaration again. Host names such as
  `math` cannot be dropped. Existing instances keep the old class
  object.

## Requirements

Same as 0.1.0:

- .NET 8 SDK
- Windows for the Desktop IDE; CLI / Web IDE / LSP are intended to work wherever .NET 8 does

## Install without sources

Download `malda-1.0.22-win-x64.zip` (CLI + Desktop IDE) or `malda-1.0.22-linux-x64.zip`
(CLI only) from the GitHub Release assets, unzip, and run:

```bash
# Windows
malda.bat Examples\Basics\first_look.malda
MaldaDesktop.bat

# Update an existing win-x64 install in place:
powershell -File scripts\update-local-win-x64-release.ps1 -Force
# or, in the Desktop IDE: Help → Update Installation...

# Linux
./malda Examples/Basics/first_look.malda
```

## Quick start (from source)

```bash
git clone https://github.com/amaldini/maldalang.git
cd maldalang
git checkout v1.0.22
dotnet build MaldaLang
dotnet run --project MaldaLang -- Examples/Basics/first_look.malda
```
